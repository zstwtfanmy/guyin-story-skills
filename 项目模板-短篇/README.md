# 项目模板-短篇（delta）

> 用法：先复制 `项目模板/` 到新短篇项目根目录，再把本目录**叠加**进去（`大纲/` 下多出内涵三件）。

## 内涵三件（短篇骨架，替代卷纲/细纲）

- `大纲/情节节点.md` —— 节点序列：事件/功能（钩压给转收）/情绪目标/关联反转
- `大纲/情绪曲线.md` —— 拉扯设计：强度 1-10 / 压给交替 / 峰值位置 / 落点
- `大纲/反转表.md` —— 每条反转：位置/铺垫/揭示方式/信息差来源/兑现状态

节点是骨头，曲线是血，反转是雷。三件交付 = 短篇的「细纲交付」停靠点。

## 方向层（沿用 `项目模板/`，轻量维护）

- `追踪/时间线/`：短篇常用插叙/倒叙，更需登记故事内时间；
- `追踪/伏笔.md`：伏笔当篇回收，不留「下卷再说」；
- `追踪/上下文.md`、双台账（灵感/豁免）：照旧；豁免限额短篇每篇 ≤1 处；
- `设定/角色/`：1-3 个核心角色，各一卡即可。

## 可留空的长篇件

- `大纲/卷纲_*.md`：短篇无卷；
- `追踪/角色状态/`：角色少且弧光单篇完成时，角色卡内记一节足矣。
