# guyin-short-write：隐笔短篇写作（极简流）

> 与 [../guyin-write/SKILL.md](../guyin-write/SKILL.md) 同一条五步流：写作知识六条、隐杀声线锚协议（写前读锚、写后三问自审、出帖）全同——本文件只写短篇差异，未写的按长篇。

## 五步流（短篇差异）

| 步 | 做什么 |
|---|---|
| 1 读 | 骨架三件（若有；设想不是考卷，缺件不拦）＋已写出的部分正文＋涉角色卡＋`追踪/上下文.md`。首篇另通读锚包全部。 |
| 2 写 | 直接写入 `正文/{篇名}.md`。写完即是正文，无候选区、无草稿版本号、无发布动作。 |
| 3 自审 | 持锚三问＋短篇三查（见下），至多一轮，原地改。 |
| 4 记账 | 一分钟 markdown：`追踪/{上下文,伏笔}.md`、`追踪/角色状态/` 中受影响角色；反转表逐项勾「铺垫已埋/揭示已写/余波已落」。 |
| 5 交用户 | 用户唯一验收者，要改原地改、要重写原地重写；没有"发布授权"。 |

## 短篇写作知识（六条之上，只加这四条）

1. **开头定处境**：前 300 字出钩子＋具体人物处境——能整体换到任意同题材文＝重写；不强制首场多版、不固定丢弃前两版。
2. **拉扯看整体**：蓄力段可以平，判据是读者获得不是曲线形状；全篇核「该压的压了、回报给够了」。
3. **反转必登记**：每条有铺垫/揭示/信息差来源/兑现状态；无铺垫不许写，末场后逐项核。
4. **伏笔不过夜**：当篇回收，不留「下篇再说」。

## 骨架三件（可选；设想不是考卷）

- 情节节点：节点事件一句＋功能五选一（钩/压/给/转/收）；首节点钩、末节点收。
- 情绪曲线：全篇参照，不规定每场升降；强度≠音量。
- 反转表：大反转 ≤2；揭示方式优先物件/动作。
- 无完整骨架也可起笔：方向与事实从用户原话提取。骨架与成稿冲突以成稿为准（更可信处整拍替换，不用先改骨架再写）。

## 文件契约

```
读：大纲/{情节节点,情绪曲线,反转表}.md（有才读）、设定/角色/*.md、
    追踪/{上下文,伏笔,角色状态}/**、作者性/**（可选，存在才读）、
    references/（方法论按需查 consult/INDEX.md，不照搬成逐条指令）
写：正文/{篇名}.md、追踪/{上下文.md,伏笔.md,角色状态/*.md}、大纲/反转表.md（兑现状态勾选）
新项目先 /guyin-setup 选短篇；同项目多篇不支持自动映射，开第二篇默认另建目录。
```

## 边界

- 不自动 git commit/push；不删未知来源文件。
- 声线锚边界同长篇：只迁移声音不迁移内容；学声音机制不学情绪基调；锚库 `声线锚库/` 或对应书目录不存在时向用户索要。
- 声线锚抬高的是方向与下限，不保证上限。
