# guyin-short-write：短篇单模型自主执笔

> 创作主体、授权分层、默认文风、候选隔离与恢复纪律全同 [../guyin-write/SKILL.md](../guyin-write/SKILL.md)——本文件只写差异，未写的一律按长篇。

## 继承 / 不继承

- **继承**：当前会话连续场景执笔（beat 只是节奏标签，不切字数桶、不逐拍验收）、完整篇审读、默认 profile（短篇题材按短篇回报选，见 默认叙事风格.md）、候选隔离 `.guyin/work/{run_id}/` 与 publish 唯一通道、drafts 版本化与中断恢复、默认单稿（多候选须先约定数量费用）。
- **不继承**：卷纲、黄金三章/第 4 章试读门（trial-gate 不跑）、卷末作者性事项、章号类检查（opening-retention/hook-rotation/outline-deliver 不适用）。
- **保留短篇自身的篇幅与回报期限**：字数与回报位置由情节节点定（wordcount `--min/--max`，不套长篇 3000 下限）；情绪曲线只作全篇参照，不做机械升降。

## 单元号映射（固定）

- **固定整数单元号 1**：首发 `mode=append, chapter=1`；修订重发 `mode=revision, chapter=1`。
- **显式贯穿**：清单 target.chapter=1、`destination=正文/{篇名}.md`；发布器自动 `--unit 1`，手动复读检测也显式 `--unit 1`——**不从文件名反解章号**。
- **同项目多篇不支持自动映射**：开第二篇前先另定稳定单元映射与状态隔离（默认另建目录）；禁止第二篇也提交单元 1。

## 入口与停止点

| 意图 | 动作 | 停止点 |
|------|------|--------|
| 写短篇/写一篇 | 部署（/guyin-setup 选短篇）→ 定题材方向＋一句话故事核＋profile → 骨架三件（情节节点/情绪曲线/反转表） | 停在骨架交付，正文须显式点名 |
| 继续写 | 先恢复未完成 run，再按情节节点连续场景推进 | 到授权终点/阻断即停 |
| 改这篇/重写/去味 | revision 候选（单元 1），明确修订目标与硬锁，不把去味扩成剧情重写 | 未获发布授权停 ready |

裸调用只诊断列选项；无完整骨架也可起笔（锁与事实从用户原话提取）。

## 写篇流程（差异版，其余同长篇阶段门）

1. **prepared**：查在途发布/未完成 run/pending；读骨架三件、涉角色与追踪（伏笔/时间线/上下文）、上一场已存全文；冻结 input（profile＋篇幅上下界）。
2. **drafting→drafted**：连续场景执笔写完整篇，候选只落 `R/drafts/`；输出中断按自然段存盘 checkpoint。完整篇审读：先初读后对骨架（反转铺垫、回报给够、信息差是否成立），结论绑候选哈希。
3. **ready**：篇检子集对显式候选（`--project --chapter 1`，篇名文件加 `--unit 1`）：tracking-commit check → strip、beat、integrity、degeneration、ai-patterns（无兄弟单元，跨章窗口空）、`repetition --unit 1`（库空＝首篇）、outline-copy（有骨架才查）、authority-leak、wordcount `--min/--max`、foreshadow-id。hard/verify 登待审；修复改候选重跑、证据重绑哈希。
4. **published**：清单 `target={mode,chapter:1,title:篇名}`、`destination=正文/{篇名}.md`，candidate/transaction/证据/baseline 齐备；preview→publish；exit3 只 recover，exit2 重建清单。

## 短篇军规（差异全在这里）

1. **开头定处境**：前 300 字出钩子＋具体人物处境——能整体换到任意同题材文＝不合格重写。多采样须先约定，不强制首场多版、不固定丢弃前两版。
2. **拉扯看整体**：蓄力段可以平，判据是读者获得不是曲线形状；全篇核对「该压的压了没有、回报给够没有」。
3. **反转必登记**：每条有铺垫/揭示/信息差来源/兑现状态；无铺垫的反转不许写；末场后逐项核对。
4. **伏笔不过夜**：当篇回收，不留「下篇再说」。

## 验收检查点（短篇形态）

无第 4 章门；检查点＝**全文交付后**（或作者选定的含起因-兑现-余波的连续段），登 `追踪/读者信号.md·验收检查点`（单元 1＋版本哈希）。来源限用户验收/独立读者，模型审读不顶替人；缺件/空答/未处置均拦；可「延期@时点」并登记下一检查点；旧反馈不冒充当前版本验收。

## 文件契约

- 读：`大纲/{情节节点,情绪曲线,反转表}.md`（有才读）、`设定/角色/*.md`、追踪（伏笔/上下文/时间线/三台账）、作者性素材（可选）。
- 写：`.guyin/work/{run_id}/`（input/session/drafts/证据；publish 前不写正式正文）、`正文/{篇名}.md`（仅 publish 安装，单元显式=1）、`追踪/*`（经 tracking-commit，chapter=1）。
- 豁免同长篇五终态，须有用户授权，每篇 ≤1 处，登 `追踪/豁免台账.md`。
