# guyin-short-write：隐笔短篇（你是编排层）

> 四卡、执行层协议、铁律与 guyin-write 全同——本文件只写差异，未写的一律按 [../guyin-write/SKILL.md](../guyin-write/SKILL.md)。

## 不变式（承 guyin-write，一条不少）

1. 对话要么推进事件，要么揭示人物；两者都不占的删掉。
2. 一次只向执行层下发一张卡；执行层永不见全局。
3. 每步产出落盘，下一步读盘。
4. 检查脚本报警**永不自动删**，一律拦为待审（改写卡或豁免）。
5. 宁留三分糙，不磨十分滑；lint 只清确定性错误。

## 继承 / 不继承（F1）

- **继承**：连续场景执笔（beat 只是节奏标签，不切字数桶、不逐拍验收）、完整篇审读、候选隔离与 publish 唯一通道（D2，闸门同长篇第 3/4/4a/6/7 步）、默认单稿（多候选须先约定数量费用）。
- **不继承**：卷纲及其门、黄金三章/第 4 章试读门（trial-gate 不跑）、卷末气卡口述、章号类脚本（opening-retention/hook-rotation/outline-deliver 不适用）。
- **保留短篇自身的篇幅与回报期限**：字数与回报位置由情节节点定（wordcount `--min/--max`，不套长篇下限）；情绪曲线只作全篇参照，不是每场必升降的配额。

## 单元号映射（F1 最小方案）

- **固定整数单元号 1**：首发 `mode=append, chapter=1`；修订重发 `mode=revision, chapter=1`。
- **显式贯穿**：清单 `target.chapter=1`、`destination=正文/{篇名}.md`；发布器自动 `--unit 1`，手动跑复读检测也显式 `--unit 1`——**不从文件名反解章号**。
- **同项目多篇不支持自动映射**：开第二篇前先另定稳定单元映射与状态隔离（默认另建目录）；禁止第二篇也提交单元 1。

## 场景路由

| 场景 | 触发 | 动作 |
|------|------|------|
| 开写 | 「写短篇/写一篇」 | Phase A 建（/guyin-setup 选短篇）→ B 定（题材/对标＋作者性四件逐件口述；不在场默认档落盘、篇尾提示；**进 C 前气卡「气句」仍占位 → 取默认落盘标「默认档·未口述」**）＋**一句话故事核** → C 骨架三件，**停在骨架交付** |
| 续写 | 「继续写/写下一段」 | 按情节节点推进连续场景循环 |
| 大修 | 「改这篇/重写」 | L1 段改/L2 场景改/L3 全篇重写须确认，重发走 revision 单元 1；guyin-review 输出按 level 直接进入 |

**停靠纪律**：裸调用只诊断列选项；骨架交付后不自动写正文；正文须显式点名。

## 写篇循环（差异版，其余同长篇）

1. **读盘**：骨架三件＋涉角色卡＋追踪（伏笔/时间线/上下文）＋作者性五件（**气卡永不下发**）＋上一场结尾 300 字（开篇免）。
2. **切场景**：按情节节点切连续场景（一卡一场，承载得住一卡整篇），标本场意图/体验目标。
3. **执笔到发布**：完全走长篇第 3→7 步（连续执笔＋check-beat → strip/normalize 拼接，**候选只落 `.guyin/work/{run_id}/`** → 完整读全篇先初读后对骨架，记录落 `追踪/运行记录/单元001.md` 重提交不覆盖 → 摘要卡 ≤900 字节 → 篇检 → publish）。
4. **篇检子集（对工作区候选）**：tracking-commit check → strip、degeneration、integrity、ai-patterns（无兄弟单元，跨章窗口空）、`repetition --unit 1`（库空＝首篇）、outline-copy（短篇平铺）、authority-leak、wordcount `--min/--max`。报警处置同长篇（hard/verify 登待审；修复改候选重跑、证据重绑 hash12）。
5. **清单**：`target={mode, chapter:1, title:篇名}`、`destination=正文/{篇名}.md`，candidate/transaction/证据/基线齐备；exit 3 只 recover，exit 2 重建清单。
6. **灵感**：骨架外新元素登 `追踪/灵感台账.md`。

## 短篇军规（差异全在这里）

1. **开头定生死**：前 300 字必须出钩子＋具体人物处境——能整体换到任意同题材文＝不合格重写。多采样须先约定（不强制首场多版、不固定丢弃前两版）；已约定的走长篇同一证据制判词。
2. **拉扯看整体，不做机械升降**：全篇审读核对「该压的压了没有、回报给够没有」；蓄力段可以平，判据是读者获得不是曲线形状。
3. **反转必登记**：每条有铺垫/揭示/信息差来源/兑现状态；**无铺垫的反转不许写**；末场后逐项核对。
4. **伏笔不过夜**：当篇回收，不留「下篇再说」。

## Craft / Muse

判据同 guyin-write，追加升档：反转 beat（反转表登记位置）。外选/回落纪律同长篇；情绪峰值不自动升档（F1）。

## 验收检查点（E1，短篇形态）

无第 4 章门；检查点＝**全文交付后**（或作者选定的含起因-兑现-余波的连续段），登 `追踪/读者信号.md·验收检查点`（单元 1＋版本）。来源限用户验收/独立读者，模型审读不顶替人；缺件/空答/未处置均拦；可「延期@时点」并登记下一检查点；旧反馈不冒充当前版本验收。

## 执行层调用协议 / 文件契约 / 豁免

- 执行层同长篇：`guyin-beat-writer`；无 subagent 降级 solo 须先声明；气卡只在编排层在场。
- 读：`大纲/{情节节点,情绪曲线,反转表}.md`、`设定/角色/*.md`、追踪（伏笔/上下文/时间线/三台账）、作者性五件、exemplars 题材弹药。
- 写：`.guyin/work/{run_id}/`（候选/事务/证据；publish 前不写正式正文）、`正文/{篇名}.md`（仅 publish 安装，单元显式=1）、`追踪/*`（经 tracking-commit，chapter=1）。
- 豁免五测试同长篇，限额**每篇 ≤1 处**，登 `追踪/豁免台账.md`。
