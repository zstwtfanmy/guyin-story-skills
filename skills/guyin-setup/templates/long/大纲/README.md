# 大纲

> 卷纲_第X卷.md + 细纲_第NNN章.md，**都是可选规划件**：没有完整细纲也可以起笔。
> 细纲是设想不是考卷：前三组（可能交付什么／人为何这样行动／场景如何承接）可整拍删改；第四组（不能擅改）只认用户原话与已发生事实。
> 字段定义唯一权威在技能库 [guyin-write/references/细纲协议.md]（本表仅速查）。细纲落盘前后不跑任何脚本门。

## 细纲速查（仅当你实际创建/修订完整细纲时适用）

| 区块 | 性质 | 一行式要求 |
|------|------|-----------|
| ①可能交付什么 | 设想 | 核心事件/读者承诺/字数目标（软建议，首三章不设下限）；不写资产档位、不写复沓锚句锁 |
| ②人为何这样行动 | 设想 | 本章主角每件事是"他此刻想做/不得不做"，不为交付台账而行动 |
| ③场景如何承接 | 设想 | 每场一行起点/意图/前后变化；不预写逐句动作，标注"可整拍删改" |
| ④哪些不能擅改 | 硬锁 | 仅限：用户锁定原话（注来源＋日期）＋已发生事实；模型自创"点题宣言句"没有资格当锁 |

- 字数目标是软建议：内容撑不起长度就短，禁止填水；
- 执行偏差/工序提示/资产档位等旧字段一律不写；
- 工艺词在叙述层直接用叙述者的说法写出来，不搞"括注翻译"。
