# 大纲

> 卷纲_第X卷.md + 细纲_第XXX章.md。细纲是**契约层**（字段协议），beat 是运行层（编排层切分产物）——细纲文件禁把 beat 切分写成细纲格式。

## 细纲字段速查（槽位清单）

字段定义唯一权威在技能库 [guyin-write/references/细纲协议.md]（本表仅速查，老项目同样读得到）：

| 槽位 | 级别 | 一行式要求 |
|------|------|-----------|
| 章尾钩子 | blocking | 五型之一 + 实体非空 + 承接第X章（完结章可「无（完结收束）」）——情绪钩子合法（有实体），情绪收束句不合法（无实体） |
| 字数与场景下限 | blocking | 字数目标行含数字（单值 T 或区间 X-Y 均合法，全角－～也认）；章检下限双口径：区间取下限 X（不再打折）、单值取 T×90%、缺省 3000；场景与对手戏下限行（默认 ≥2 场 / ≥1 对手戏，低压/过场章可声明豁免） |
| 多线节拍 | blocking | 情节安排节：主线行 + 感情线/关系线行（值可「无显性，但…」） |
| 时序自检三查 | advisory | 情节安排节末行存在：①章内时间轴走查 ②插叙显式标注 ③跨章签名句归属核对（outline-slots 查行存在，P1/K2） |
| 情绪落点 | advisory | 行存在（值可「无」）：①情绪@点N 格式 ≥3 个，低压/过场章 ≥2 并声明豁免——章内情绪分布，写前可见写后可查（Q1） |
| 复沓锚句 | blocking | 字段行存在（值可「无」）；仅限世界内实体语句，作者性语句禁登记；须一字不差进正文（outline-deliver 查落地，R1） |
| 禁止提前释放 | blocking | 字段行存在（值可「无」）——防「靠卷纲兜底」的隐性放空 |
| 涉及场景清单 | advisory | 字段行存在（喂 cards {{场景锚点行}}） |
| 术语锚点 | advisory | 字段行存在；新术语首现须带台词级锚定 |
| 写作指令区 | 无硬门 | 区推荐存在（值可「无」，≤5 行）：执行方式/步数约束/落位要求收进本区——**区内容禁入正文、禁进写作卡{{必须发生}}**（可提炼为{{禁止}}），K1 |
| 本章唯一解密位 | 走查纪律 | 谁在哪一点说出关键解密（人声版），无解密写「无」；全批只允许一个点破位，其余载体只铺垫不提前解码（无机械检查，细纲走查拦重复解码，P3） |
| 执行偏差（检测驱动回填） | 提醒 | 区必须在、值可「无」：变体/未落实两行；补纲落盘时预置，**写章第 7 步章检后按 outline-deliver 检测回填**（修=改写卡对齐，认=登记偏差；未落实行必含顺延章号，R1）；tracking-commit 提交发现缺区/未落实无章号 stderr 提醒不阻断（P2/R1） |
| 契约风险行 | advisory | 结论行存在（判定标准=七检⑥⑦，见协议文件） |

细纲落盘前过硬门：`guyin-check-outline-slots.js`（槽位完整性）+ `guyin-check-authority-leak.js`（作者性字面）+ `guyin-check-outline-verdict.js`（资产档位）；批次末跑 `guyin-check-hook-rotation.js`（钩子轮换）；正文落盘后跑 `guyin-check-outline-deliver.js`（细纲承诺交付：术语锚点兑现/钩子实体压尾/锚句落地/钩子引语一致/跨章签名句归属，R1/K2）＋ `guyin-check-strip.js`（成稿剥离门：多标题/大纲尾巴 blocking、工序词泄漏 advisory，K3）。工艺词入叙述层字段须括注叙述者措辞（如「社会脸（写成：…）」）。

## 资产影响档位（细纲声明行，引用既往章/事件时必填）

细纲引用既往章节编号或已登记事件名（如「复盘旧局（ch3）」，含「不是A，是B」翻转句与全称量词复盘表述）时，必须有档位声明行——高潮/爽点章兑付给读者的情感是**已支付的资产**，没收（否定前文高潮）必须显式声明并支付代价。落盘前由 `guyin-check-outline-verdict.js` 机械仲裁，缺声明即拦。

| 档 | 定义 | 支付条件 |
|----|------|---------|
| 0 纯叠加 | 既往关键事件定性不变，新信息叠加 | 无 |
| 1 部分动用 | 事件部分维度重估，资产重定价不没收 | 无 |
| 2 全盘否定 | 事件定性被推翻，资产没收 | 同章兑付等值或超值补偿 + 作者确认，缺一阻断 |

- 声明行写法：`资产影响档位：1 部分动用——重估说明一句`（示例：`资产影响档位：1 部分动用——重估拆神那局（ch26-27）：赢是真的，被利用的是专注度`）；档 2 声明行内须写明「补偿」及补偿方式；
- 辅助字段（行动成本/人心节拍等）含限定语（如「认它一半是送的」）而情节点为全盘表述 → 档位冲突，停作者仲裁，机械判档不替作者定性。
