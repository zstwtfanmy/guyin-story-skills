## 文件结构

- `设定/` — 世界观/ 与 角色/（每角色一卡）
- `大纲/` — 卷纲_第X卷.md + 细纲_第NNN章.md（细纲是设想不是考卷：可整拍删改；exact 锁只认用户原话与已发生事实）
- `正文/` — 第NNN章_标题.md（三位章号补零），写完即正文：直接写入、原地修订
- `追踪/` — 连续记忆：上下文 / 伏笔 / 角色状态/；其余台账想记才记，不记不拦
- `灵感池/` — 口述采集落点（只注入不强插）
- `作者性/` — 指纹 / 偏执点 / 魂档案等可选素材；不提供不拦写

## 项目约定（不变式）

1. **单模型自由执笔**：只有当前会话一个创作主体——读前文、定走向、写完整章、全文回看；框架不选 model/provider，不分发 writer/checker 执行层 agent，无检查链 gate。
2. **写完即正文**：章节直接写入 `正文/第NNN章_标题.md`，无候选区、无草稿版本号、无发布动作；修订原地改。
3. **声线学锚包**：写前读声线锚包原文（示范>规则）；首章通读，其后按本章场景类型选读 1–2 段；写后持锚自审四个声音问题，至多一轮原地改。
4. **每步落盘、下一步读盘**：compact / 新会话后先读 `追踪/上下文.md` 恢复状态。
5. **选题不走扫榜**——开书 Phase B 走「魂谱对表」。
6. **用户是唯一验收者**：模型审读不顶替人；前三章完成后停一次听整体感受，这不是机械门。
