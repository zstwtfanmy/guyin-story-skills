# guyin-story：隐笔主入口

> 笔不造文，隐术显天。框架不挡光：约束管下限，示范管上限，选择权归作者。

## 路由

| 用户意图 | 去向 |
|---------|------|
| 开书 / 写第X章 / 日更 / 续写 / 回炉 | **guyin-write**（长篇写作编排） |
| 写短篇 / 写一篇 / 盐言 / 番茄短篇 | **guyin-short-write**（短篇写作编排） |
| 拆这本书 / 拆文 / 分析黄金三章 | **guyin-analyze**（长篇拆文管道） |
| 拆短篇 / 拆这篇短文 | **guyin-short-analyze**（短篇拆文） |
| 审查 / 帮我审一下 / 这章怎么样 | **guyin-review**（对抗式诊断，只诊不改） |
| 去AI味 / 这篇太AI了 | **guyin-deslop**（lint + 陌生化改写） |
| 打擂台 / 跑基准 / Arena | 仓库根 `arena/` 协议（见 arena/基准/README.md） |

## 项目状态诊断（裸调用 / 模糊意图时先做）

扫描当前目录，报告四层状态并给下一步选项（不自动执行）：

1. **设定/大纲**：有无卷纲、细纲到第几章；
2. **正文**：最新章节号；
3. **追踪**：伏笔/时间线/角色状态/双台账是否在维护；
4. **作者性**：指纹/偏执点/气卡/魂档案是否已建。

| 状态 | 建议命令 |
|------|---------|
| 空目录 | 「开书」（先复制 项目模板/） |
| 有纲无文 | 「写第1章」「只写1章」 |
| 有文有追踪 | 「日更2章」「续写」 |
| 缺作者性四件 | 提醒：开书 Phase B 补齐（写作循环会读它们） |

## 边界

- 不做扫榜/封面——选题走「魂谱对表」（docs/01-需求框架.md §10.4）；逆向导入半成品书为预留方向（§10.3，analyze 加模式）；
- 拆文库产物在 `拆文库/{书名}/`，写作项目引用视图在 `对标/{书名}/`（首次引用时从拆文库复制子集）。
