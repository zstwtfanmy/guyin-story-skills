# guyin-story：隐笔主入口

> 笔不造文，隐术显天。框架不挡光：约束管下限，默认审美管方向，选择权归作者。

## 路由

| 用户意图 | 去向 |
|---------|------|
| 开书 / 写第X章 / 日更 / 续写 / 试写 / 回炉 | **guyin-write**（当前会话单模型自主执笔长篇） |
| 写短篇 / 写一篇 / 盐言 / 番茄短篇 | **guyin-short-write**（短篇单模型自主执笔） |
| 拆这本书 / 拆文 / 分析黄金三章 | **guyin-analyze**（长篇拆文管道） |
| 拆短篇 / 拆这篇短文 | **guyin-short-analyze**（短篇拆文） |
| 审查 / 帮我审一下 / 这章怎么样 | **guyin-review**（对抗式诊断，只诊不改） |
| 去AI味 / 这篇太AI了 | **guyin-deslop**（lint + 陌生化改写） |
| 起书名 / 写简介 / 章节标题 | **guyin-pitch**（开书文案包） |
| 准备写书 / 搭环境 / 建项目 | **guyin-setup**（项目脚手架部署，模板随技能走） |
| 打擂台 / 跑基准 / Arena | 仓库根 `arena/` 协议（见 arena/基准/README.md） |

## 项目状态诊断（裸调用 / 模糊意图时先做）

按顺序查，报告并给下一步选项（不自动执行、不生成正文）：

1. **在途发布**：`追踪/_publication.json` 是否存在且非 complete——在途先 recover，不另开写；
2. **未完成 run**：`.guyin/work/*/author-session.json` 的 phase 与 next_action；多个 run 请用户指定，不按文件新旧猜；
3. **正式进度**：最新正文章号、细纲到第几章、追踪时滞与待审台账未决行、读者验收检查点；
4. **文风**：`设定/题材定位.md ## 叙事风格` 有无书级 profile；没有就在动笔时按题材自动选默认（见 guyin-write 默认文风节），不阻断。

| 状态 | 建议 |
|------|------|
| 空目录 | 「准备写书」（/guyin-setup 部署模板后再开书） |
| 有纲无文 | 「写第1章」（无完整细纲也可起笔） |
| 有未完成 run | 「继续」→ 先恢复该 run，从真实末尾接写 |
| 有文有追踪、无在途 | 「日更」「续写」 |

作者性素材（气卡/魂档案/私人经历）是可选私人材料，不再列为开写缺件；不因缺作者名或私人素材阻断。

## 边界

- 框架不选择宿主 model/provider，不分发 writer/checker；不做扫榜/封面；
- 拆文库产物在 `拆文库/{书名}/`，写作项目引用视图在 `对标/{书名}/`（首次引用时**手动**复制子集，不自动同步——拆文库更新后副本不跟随；召回登记以拆文库真实产物路径为准，E2）；
- 逆向导入半成品书为预留方向。
