# 范文切片库（references/exemplars/）

> 观：范文教学取代参数化文风卡——"像这样写"胜过一切句长参数。本库是写作卡"范文手感"段与改写卡"好坏对照例"的唯一取弹处。

## 采集协议

| 项 | 规则 |
|----|------|
| 来源 | 用户**合法持有**的对标书原文（通常在 `拆文库/{书名}/原文/`，拆文完成后采集） |
| 数量 | 每题材 3-5 段，每段 500-1000 字成品切片 |
| 选择标准 | 不是摘抄好句，是**手感样本**：对话场景 / 动作场景 / 氛围铺陈 / 情绪峰值 / 闲笔，各至少 1 段 |
| 切片纪律 | 切片只下发进任务卡供模仿节奏（卡面明写"禁抄内容"）；本库随项目保存，**勿公开分发原文切片** |
| 更新 | 开书 Phase B 采集一次；对标书更换时重采；同章内不重复使用同一切片 |

## 文件格式（每题材一份 `{题材}.md`）

```markdown
# {题材} 范文切片库

## 元信息
对标书：《{书名}》（作者）· 采集自 拆文库/{书名}/原文/
采集日期：YYYY-MM-DD · 切片数：N

## 切片
### 切片1：{场景类型}｜{用途标签：开场/对话/动作/氛围/峰值/闲笔}
> {500-1000 字原文切片}

### 切片2：……

## 好坏对照例（改写卡/陌生化取用）
### 对照1：情绪外化
坏例：{情绪直说句}
好例：{身体动作+环境反应}

### 对照2：公共比喻 → 人物之眼
坏例：{公共比喻句}
好例：{用角色行当经验重写}
```
