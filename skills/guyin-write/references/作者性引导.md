# 作者性引导（编排层交互协议）

> 触发：开书 Phase B / 用户说「定作者性」「填作者性」/ 状态诊断发现四件缺失。
> 三原则：**一次只问一件**（不甩问卷）；**问生活不问文学**（答什么都接得住）；**口述两句 > 圈默认 > 跳过**。
> 铁律：魂档案**没有默认值**——一生之问与私人切口只能从作者身上长出来；答不出是正常状态，标「未定稿」即可，不许代答。

## 判定缺什么

读 `作者性/` 四件（气卡/指纹/偏执点/魂档案），按"定稿列是否为空"判定缺口，**只问缺的件**。四件全齐时只做核对：逐件复述当前取值，问"换不换"，不换即退。

作者递来已填的 `作者性/口述定稿单.md` 时：按单落盘（含「认」的默认值，一并注口述定稿日期）；只对空题走逐件引导，问完即退。

## 逐件引导（每件独立，可随时停）

### 第 1 件：气卡（气句 / 底色 / 收放）

- 开场一句：「不聊文风，聊口味——这本书读起来该是什么心情？」
- 问气句：报项目根 `作者性/参考-气质谱系.md` 的三个候选方向，问哪句最接近；**选中后必须请作者用自己的话重说一遍**（照抄即口号化）。答不上时用场景测：「写完最爽的一章，你会用什么口气跟朋友提它？」
- 底色/收放：直接给谱系默认，问"顺不顺手"，顺手即落。
- 落盘：`气卡.md`「三字段」表"本书取值"列。气句措辞禁对仗禁修辞。

### 第 2 件：指纹（比喻域 / 镜头 / 闲笔 / 标点）

一次只问一个参数：

1. 比喻域：「你平时熟哪个行当或领域？做饭、木工、账目、游戏、钓鱼……本书的比喻就从这口锅里捞。」
2. 镜头习惯：「一个场景的第一笔，你想先给一件东西，还是先给一张脸？」
3. 闲笔频率：给默认（每章 1 处 50-150 字）问认不认。
4. 标点癖好：给默认（对话少叹号、停顿用句号）问认不认。

- 落盘：`指纹.md`「掌纹参数」表"本书取值"列。

### 第 3 件：偏执点（≤2 条）

- 问法：「有没有想让这本书从头到尾死守的怪规矩？比如'暴力场面之后必接一个吃的细节'。没有也没关系。」
- 给不出：报谱系两条默认（峰值句 ≤10 字 / 每章一处闲笔），认哪条圈哪条；**想全要就砍到 2**。默认是**待认领的候选手法，不是普适审美**（v3-B1）——作者自报的规则（哪怕「情绪可直说」「峰值可用长句」）整条压过默认，不回填、不折中；作者明确选择的书级写法，批次模式与去味都不得越过。
- 落盘：`偏执点.md`「本书偏执」编号行。

### 第 4 件：魂档案（一生之问 / 私人切口）

- 开场声明：「这一件不用现在答对，试写 3 章后再回填完全合法。」
- 问一生之问：「这几年你反复在想、绕不开的一个问题？跟钱无关的那种。」（例：一个人能不能靠手艺守住体面？）
- 问私人切口：「你亲身见过、别人编不出来的一个瞬间？」（例：见过父亲把退货的家具修到比原样好，没收钱。）
- 答不出：状态标「未定稿，试写后回填（第 3 章后）」，这是设计内状态，不是缺失。
- 落盘：`魂档案.md` 对应字段与状态行。

## 跳过与降级（默认档纪律）

| 情形 | 处理 |
|------|------|
| 作者拒绝 / 不在场 | 气卡/指纹/偏执点按谱系默认落盘并标注**「默认档」**；魂档案留空标「未定稿」；**Phase B 收尾有机械检查兑底**（guyin-write 开书场景：进 C 前气句仍为占位 → 按谱系就近取默认落盘，任何路径不许占位符进 Phase C，H3） |
| 默认档项目的持续提醒 | 写章循环**章尾报告**附一行：「作者性：默认档运行中（第N章）。说『定作者性』随时升级，约五分钟」——同章只提一次，不阻塞、不刷屏；**卷末升级为主动询问** |
| 中途补定 | 任何时候说「定作者性」进本引导，只问缺的件，问完即退 |
| 定稿标记 | 凡作者口述落盘的值，在值后注「（口述定稿 YYYY-MM-DD）」；默认档的注「（默认档）」——一目了然哪些是自己长的；默认档气句同样入 H2 检测词源（被正文抄了同样是泄漏） |

## 对话样例（编排层参考）

> AI：开书前定个调。不聊文风，聊口味——这本书读起来该是什么心情？这里有三句候选：①「再大的事，饭点儿也得吃饭。」②「笑完了，该算的账还得算。」③「玩笑开归开，他没真放下过。」哪句接近？
> 作者：第二句吧，但不 totally，我想说……账要算，但不着急那种。
> AI：好——用你自己的话重说一遍？越像你平时说话越好。
> 作者：账都记着呢，不急着翻。
> AI：（落盘气句：「账都记着呢，不急着翻。」（口述定稿 2026-08-18））底色我看用"暖，压着写"，收放"峰值处收"，顺手吗？
> 作者：行。
> AI：下一件，指纹。你平时熟哪个行当？做饭、账目、木工都行——本书比喻就从这口锅里捞。
