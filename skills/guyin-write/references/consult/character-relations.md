## 人物关系类型

查表确定角色间的关系类型，然后按原则执行。

| 关系类型 | 定义 | 功能 | 示例 |
|---------|------|------|------|
| 冲突型 | 双方利益/理念对立 | 制造张力，推动情节 | 宿敌、竞争对手 |
| 联盟型 | 双方有共同目标 | 提供助力，制造羁绊 | 战友、师徒 |
| 亲密型 | 情感纽带连接 | 制造软肋，提供情感支点 | 恋人、家人、兄弟 |
| 权威型 | 上下级/支配关系 | 制造压力，限制主角行动 | 师父、老板、监管者 |

**执行规则**：
- 考验可在处境需要时发生，不要求每个重要关系都有背叛、牺牲或误解
- 关系可变化，也可在共同生活中维持、加深或显露细微差别，不强制转向弧线
- 稳定亲近不等于反应雷同；从各自关注与相处分寸写出区别，不为制造波折硬加冲突
- 共同生活、被理解、陪伴与相处分寸本身有阅读价值，不必每次服务外部情节

## 感情流人设核心法

感情流中剧情为人设服务——每次剧情都要丰满人物或推动感情发展，否则就是无效剧情。

### 构建步骤

1. **确定人设核心**：写下最初出现在脑海里的角色特征（如"想登上皇位的皇子""病弱皇子"）
2. **围绕核心发散**：回答——为什么有这个核心？过去经历？环境影响？性格成因？
3. **延伸剧情线**：核心自带的剧情必须写（有目标→目标线；有伤痛→治愈线）

### 执行规则

- 俗套剧情配上丰满人设也能脱离套路感
- 两个主角都必须有闪光点和独立变化路线，不能一个人出彩另一个人黯淡
- 高光不等于装逼——所有让读者对角色印象深刻的时刻都是高光，包括痛彻心扉的时刻
- 生命不止恋爱——角色心里希望恋爱，但生命里不能只有恋爱，只有恋爱的角色立不住、很单薄

## 读者回报与爱情线选择

**结合所选 profile、作品承诺与具体读者反馈选择，不用男频/女频或人物性别一刀切。**

### 可并存的阅读回报

| 回报 | 写作落点 |
|------|----------|
| 被理解与被在乎 | 对方看见自己的困境、愿望与不便明说之处 |
| 相处的趣味与安心 | 聊天、共事、照顾、磨合与共享日常本身值得读 |
| 能力与人格欣赏 | 欣赏对方怎样做事、如何待人，不把优秀折算成占有的荣耀 |
| 吸引与情感连接 | 外貌、才华与共同经历都可影响吸引，连接在双方选择中形成 |
| 社会认可 | 可作为某些人物在意的回报，但不以旁人羡慕代替双方感受 |

不要求每场戏兑现全部回报，也不以追求者数量证明主角价值。

### 双方自主的关系依据

1. 恋爱对象不是奖杯或打脸工具；双方都有自己的生活、期待、判断与边界
2. 主动表达、接受、拒绝或暂缓均可由任何一方选择，不按性别分派主动权
3. 能力欣赏与情感连接可以并存，物质处境与私人关注也可持续影响关系，不必为了证明真爱将其清空
4. 过往经历与关系形式按具体人物和作品约定处理，不把初恋、唯一性等偏好当作普适条件

## 穿书/穿游戏角色选择法则

### 必须满足的条件

- 叙事主角必须对原世界有相当熟悉度（最核心的期待感来源）
- 确定穿越进熟悉的世界，一两句话交代清楚，不能超过一章还不知道身处何方
- 必须选择穿越后有强戏剧性或强矛盾的角色（如穿越成恶毒女配）

### 信息差设计

- 在原世界基础上适当设计信息差，为叙事主角提供探索空间
- 可以用原世界知识卡bug获取超额收益

## 修罗场收场策略

修罗场本质是一种矛盾，控制对抗烈度，不能让爱情线对象之间出现不可调和的矛盾。

| 收场方法 | 操作 |
|---------|------|
| 关联回事业线 | 让爱情线对象们把争风吃醋转化为"比谁对主角事业线贡献更大" |
| 插入事业线突发事件 | 对抗进入白热化时，用突发事件让所有人从内斗切换成一致对外 |
| 一笔带过 | 最多两人互相看不惯、说两句嘲讽话就过去，非常克制 |

## 傻白甜角色塑造避坑

### 六个必避之坑

1. 女主犯错不能是故意的，不能明知不能做偏要做
2. 女主犯错不能违反道德——傻白甜最重要的是天真小孩子般的高道德感
3. 不能站在道德高地指责他人（道德婊行为），自己却做不好
4. 不能因为道德婊行为和队友发生矛盾后还让队友认错赞美她
5. 正确做法：有更高道德标准 → 所作所为符合 → 为此显得与众不同和有点傻气
6. 可以写成长线：坐到被她指责的人的位置上后，发现原来那个做法已是最好的选择

### 反向用法

塑造傻白甜反派时，把以上六点全加在她身上，让读者一见就厌恶。

## 人设改变的双向翻转法

爱情线中关系发生变化时的人设调整方法。

### 核心思路

- 最好的改变是两个人都改变，且改变后恰好与之前两人之间的对应关系相反
- 改变要基于原人设做局部调整，和原人设保持密切联系，避免随意改造

### 执行规则

- 人设变化发生在爱隔山海阶段之后（尤其是面对最大阻碍之后），不要再设计新的矛盾，只要发糖
- 真正的阻碍已在前面解决，此时读者最迫切的渴望是多吃糖
- 发糖要用实在的CP行为和悉心照顾表达爱意，不是"我爱你"式的工业糖精

## 角色行为与感受的成稿观察

成稿后遇到反应突兀、人物被推着走等疑点时再选用，不要求写每段前设定情绪目标或角色使命，也不强制填因果表。

### 观察外部强推

看行为是否只有方便剧情的理由，而人物当时所知、所求与处境不足以支持。先结合上下文判断；动机未明说不等于没有动机，不因留白自动判为人设偏移。

### 观察混合动机

- 关心、嫌麻烦、顾面子、责任或私心可能同时存在，不必归并成一个纯粹目标
- 留意人物此刻顾着什么、误会了什么，以及关系和生活负担如何影响选择
- 不要求配角反应服从故事中的功能定位，也不要求人物感受与预设读者情绪一致

### 观察感受延迟与言行落差

- 人物可能先应付事情，过后才感到委屈、庆幸或害怕；情绪不必在事件发生时立即表达完整
- 嘴上答应却迟迟不动、口头嫌弃却仍帮忙，可以来自顾虑、习惯或关系分寸
- 看这些落差是否有处境依据，而非仅凭标签判错；也不为了显得细腻给每段添加矛盾

### 按疑点修订

确有断裂时，调整行为或补少量足以理解处境的线索；已有言行与细节能支撑的，不另加解释。允许迟疑、误读、未察觉的感受和未解开的心事留在文中，不追求情绪整齐或唯一因果。

## 配角攻略缓冲区

配角对主角态度的变化过程 = 主角攻略配角的过程，伴随巨大的期待感和爽点。

### 缓冲区类型

线上线下、背后议论、异地相处、地位差距、亲密度差距、信任程度、信息差等。

### 操作步骤

1. 始终保持缓冲区存在
2. 在卷纲中挑出事件拐点（5~7个）
3. 在每个拐点处标注配角状态和对主角的态度变化
4. 每次攻略到关键点位时，配角的态度变化必须写清楚
5. 态度变化本身就产生情绪波动和期待感

### 执行规则

- 配角不能像NPC一样站着等主角触发
- 配角要有自己的行动，由配角观点引出事件
- 正面角色也一样：和主角立场相同的人也应有自己的行动和动机

## 利用角色身份认知差制造冲突

同一个角色在不同人眼中的"声望"是动态变化的，不是恒定值。

| 视角 | 看重什么 | 对男主的评价 |
|------|----------|-------------|
| 世俗视角 | 家境对等，抗风险能力 | 综合条件匹配度 |
| 男主自身 | 赚钱养家+感情 | 相对门当户对 |
| 女主视角 | 感情+专一+爱 | 只要在乎的就门当户对 |
| 富二代 | 外貌家世匹配度 | 我才更门当户对 |
| 路人 | 综合条件对比 | 女主该嫁富二代 |

**操作要点**：
- 不同人对同一个角色的评价差异 = 天然的矛盾冲突来源
- 恋爱文的核心爽点之一：不同维度的评价差

## 亦敌亦友关系

最有魅力的人物关系类型。

### 执行规则

- 前提：两个角色本身都要有魅力，否则只是强行五五开的狗皮膏药
- 核心：高度认可 + 绝对冲突 → 惺惺相惜 → 缺一魅力全无
- 真正的宿敌 = 双方相互认可，外人盖章不算

## 竞争者定位与亲情线用法

### 竞争者（鲶鱼效应）

- 定位：给男主/女主增加紧张感上压力 → 推动攻略进度
- 剧情设置重点在"高潮节点前" → 属于铺垫环节
- 对高潮后续写剧情作用不大 → 不是续命手段

### 亲情线的四个方向

| 方向 | 作用 | 使用时机 |
|------|------|---------|
| 男方助力 | 提供金钱地位权力 | 高潮前发挥 |
| 男方阻力 | 设置障碍让主角得到认可 | 节点前后都能用 |
| 女方助力 | 温柔乡感情补给站 | 高潮前发挥 |
| 女方阻力 | 父母不同意→为了认可去努力 | 节点前后都能用 |

助力主要在高潮前，阻力节点前后都能用，阻力更好发挥。

## 恋爱文的相处与推进

### 读者为什么看恋爱文

| 价值 | 来源 |
|------|------|
| 情绪价值 | 被需要、被在乎、被理解，也能理解对方 |
| 相处价值 | 日常照应、打趣、默契与分寸，让共同生活值得期待 |
| 欣赏价值 | 看见彼此能力与人格，不以身份高低或旁人嫉妒替代关系 |

### 可选技法：从相处中积累关系

- 暧昧拉扯是一种吸引力，稳定亲密和共同生活也能提供回报
- 可观察信任、熟悉与好感的变化，不必把恋爱换算成等级进度条
- 事件后可以更亲近，也可以停留、退缩或感受混杂，不要求每次升级

### 一种可能的靠近路径

陌生 → 共事中欣赏能力 → 相处中理解彼此 → 逐渐觉察喜欢；也可从熟人或已有亲密关系写起，不必逐站打卡。

### 关键原则：主动与回应均由人物选择

- 主动追求不等于失去自我，被追求也不构成人格或价值更高的证明
- 双方都可主动表达、试探、拒绝或暂缓，按性格、处境与边界决定，不按性别定规则
- 帮忙可出于关心、责任或混合动机，不必伪装成举手之劳，也不自动换来爱意或回报义务

### 感情升级的不对称性

- 两条进度线：表面社会关系（路人→朋友→情侣）+ 实际情感好感度
- 两条线不应齐头并进 → 一条快一条慢 → 带来丰富的矛盾冲突
- 情感线快于社会线 → 辉夜大小姐模式（双方好感拉满但嘴硬不表白）
- 社会线快于情感线 → 赘婿/择天记模式（表面夫妻实际好感为零）

### 写女主对主角好

| 女主类型 | 付出方式 |
|---------|---------|
| 自卑社恐 | 偷偷帮忙塞东西但害怕被发现 |
| 傲娇型 | 用心做便当但嘴硬"做多了顺便带的" |
| 直率泼辣 | 大大方方送礼物或直球表白 |

### 善用对比

| 对比类型 | 操作 |
|---------|------|
| 时间线对比 | 女主刚认识主角时 vs 熟悉后的态度变化 |
| 双标 | 不允许别人摸头但主角可以 → 凸显特殊地位 |
| 信息差 | 男女主双重身份（网上vs现实）→ 期待揭穿时反应 |

## 好感度体系（通用框架）

### 四阶段

萍水相逢 → 爱情喜剧 → 爱隔山海 → 大结局

### 好感度 × 关系阶段对照表

好感度（负/零/半/满） x 关系阶段（熟悉/试探/暧昧/确认）

阶段匹配原则：**按低的一方计算**。好感度到了但关系阶段没到 = 行为突兀。

### CP行为三类门槛

| 行为类型 | 门槛 | 说明 |
|---------|------|------|
| 需容忍行为 | 半好感+ | 主动亲密、妥协，必须给补偿否则变舔狗 |
| 特殊对待行为 | 半好感+ | 主权、信赖、牺牲、特殊待遇、安抚 |
| 关联行为 | 双方半好感+ | 默契、分享、陪伴 |

好感度不足时写需容忍行为 = 油腻/性骚扰感。

### 5套感情线结构模板

| 模板 | 核心 |
|------|------|
| 好感度变化 | 可能升/降/已降 → 各自处理路径 → 余韵 |
| 受益 | 享受伴侣带来的好处 = 爱情线装逼核心 |
| 争风吃醋 | 多角色为主角争风，不是主角吃别人醋 |
| 发展受阻 | 阻碍→试图解决→解决→余韵 |
| 狗粮 | CP日常互动 |

## 角色目标的自主性与关系线设计

### 自主选择原则

- 帮别人实现目标也可以是自主选择，关心、责任、承诺或共同生活都能成为理由，不等于变成工具人
- 不必把帮助换算成自己的利益、认可或资源；人物可以付出，也可以犹豫、拒绝或调整边界
- 看选择是否来自人物自身与当下处境，而非只方便剧情；暂时等待、照应他人或没有明确目标，不自动判为被动棋子

### 感情线的层次设计

- 关系可积累、停留、反复或悄然变化，不要求每个情感节点对应剧情高潮
- 社会关系与实质感受的错位可以有张力，一致时的安心与默契也有价值
- 节奏按具体关系选择；小事的余韵、过后才懂的关心可独立成立，不强制先慢后快或盛大仪式

### 配角在关系中的多重位置

| 关系位置 | 可能表现 | 自主性依据 |
|----------|----------|------------|
| 竞争者 | 竞争也能伴随欣赏、合作或退出 | 有自己的追求，不只为主角加压 |
| 提供帮助的亲友 | 支持、照顾，也会迟疑、拒绝或延迟 | 有自身生活、承诺与边界 |
| 持异议的亲友 | 担忧、误读、争执，也可能修正判断 | 不必等主角证明价值才改变，也不必最终认可 |

---

## 绿茶/负面角色

- 可以推动剧情但要谨慎使用
- 确认该角色是否有不可替代性
- 主角强势时任何角色都能变正反馈
- 主角弱势时负面角色会被读者恨

---

## 质量检查清单

成稿后按所用方法与具体疑点选查，不作为逐段预设任务单：

- [ ] **关系类型明确**：每个重要关系已归类为冲突/联盟/亲密/权威之一
- [ ] **关系自然**：稳定、变化与相处分寸有处境依据，未为凑考验或外部情节功能硬加波折；共同生活本身的回报得到保留
- [ ] **人设有核心**：主角人设有明确的核心特征和发散依据
- [ ] **选择自主**：帮助、付出、等待或拒绝出自人物处境，不强制折算自身利益，也不因没有主动目标就判为工具人
- [ ] **反应有依据**：混合动机、感受延迟与言行落差能由上下文理解，不追补情绪目标、使命定位或因果表
- [ ] **好感度匹配**：CP行为与当前好感度阶段匹配（按低的一方计算）
- [ ] **读者回报适配**：按 profile 与作品承诺选择被理解、相处、能力欣赏等回报，不将对象奖杯化或按性别规定主动权
- [ ] **情感节奏自然**：容许停留、细微变化与余韵，不要求每个情感节点有高潮
- [ ] **配角有自主性**：配角有自己的生活、期待、判断与行动，不只等待触发或为主角提供助力
