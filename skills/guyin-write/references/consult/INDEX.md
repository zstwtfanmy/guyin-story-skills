# 咨询库索引（consult/INDEX.md）

> 本库是原项目 42 份方法论全文的归档。**纪律：按需查阅，永不进主流程，永不下发任务卡。**
> 当前会话在遇到具体问题时才来此检索；本库内容不向任何受管 agent 下发（受管 writer/checker 已退役）。
> 2026-09 v4：默认审美改由 `../默认叙事风格.md` 的 profile 承担；本库凡与新架构冲突的旧流程条款（严格消费细纲/情节点预算/给 narrative-writer 组卡/默认气卡三角等）一律以新架构为准，不得经“按需查阅”复活。
>
> 标注说明：
> - **[方法]** 通用创作方法，长期有效，按场景查阅
> - **[存档]** 原项目流程文档（编排/执行双层、beat 卡片等旧机制），现行单模型自主执笔架构不再按此执行，仅供理解原机制与查证细节
> - **[降级]** 原主流程权威，现已退出（负面清单/参数化路线），仅作参考，禁照搬
>
> **拆文产物路径口径（E2，权威）**：guyin-analyze v0.5 产物在 `拆文库/{书名}/` 书根——`章节/第XXX章.md`（逐章摘要）、`节奏.md`、`情绪模块.md`、`设定/`、`角色/`、`拆文报告.md`、`文风.md`、`原文/`。`章节/*_摘要.md` 与 `剧情/`（含 `剧情/节奏.md`、`剧情/情绪模块.md`、`剧情/{单元}.md`）为旧布局，已停用、无人生产。本库任何文件残留旧路径仅供查证历史，[存档] 文件顶部已加停用横幅，**不得据此重新激活召回**；`对标/` 是首次引用时手动复制的子集视图，不与拆文库自动同步。召回机制以 [方法] `cross-book-recall.md` 为准。
