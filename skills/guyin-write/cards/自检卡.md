# 自检卡模板（cards/自检卡.md）

> 编排层专用：每个 beat 回收后、拼接之前必跑。
> **P1 改造**：确定性题（Q1-Q6）已下沉 `guyin-check-beat.js` 零 token 检查，
> 模型只剩 Q7/Q8 两道常驻语义题＋Q9-Q11 留存题——先抄后判：每题先抄原文相关句、再答是/否。
> 抄写任务强制逐句过文本，判断寄生在抄写之后（低模型注意力从概率行为变机械行为）。

---

```
【自检 beat {{N}}/{{M}}】guyin-check-beat.js 已查 Q1-Q6（禁用词/禁止项/字数/跳写/对话连排/心理独白）。
脚本 blocking 不过的 beat 不进本卡——直接改写卡。以下只答语义题，先抄原文再判：

7. 必须发生的 ①{{事件1}} ②{{事件2}} ③{{事件3}} 是否都写到了？
   逐项先抄写到该事件的原文句，再答是/否：
   ① 抄原文：____ 是/否
   ② 抄原文：____ 是/否
   ③ 抄原文：____ 是/否

8. （非本章第 1 个 beat 时）开头两句是否顺着"前文"的语气续写？
   先抄开头两句原文：____
   再答是/否：无重新起腔、无场景重述、无总结重启？

── 留存题（Fw-05；组卡按章号实例化，非适用整块删）：Q9/Q10 ch1-3 每 beat、其后仅章末 beat；Q11 仅 ch1-3 ──

9. 主角本 beat **主动发起**了什么（追问/出手/定调，非应答旁观）？
   抄：____ 是/否（预标不在场准 N/A）

10. 有无一句对话给出**新信息**（新事实/意图/关系，非寒暄应答）？
    抄：____ 是/否（预标无对白准 N/A）

11. 读者能**记住**一个具体点吗（物件/狠话/动作，非气氛词）？
    抄：____ 是/否

逐项作答，格式：题号 + 抄写的原文 + 是/否/N/A + （答否时）补充说明。
```

## 编排层处置规则

| 自检结果 | 处置 |
|---------|------|
| 脚本 blocking 不过（禁用词/禁止项/跳写/字数不足） | 不进自检卡，直接组装[改写卡](改写卡.md)定向改 |
| 脚本 advisory（对话连排/心理独白超限） | 编排层判读：组改写卡或在自检卡附注行提示模型 |
| Q7 抄原文后答否（漏事件） | 缺的事件写进改写卡"必须补入"，禁止另起炉灶重写全文 |
| Q8 抄原文后答否（拼接断裂） | 改写卡只重写开头两句，对齐前文节奏与悬置，其余不动 |
| Q9 抄不出/答否（主角只应答旁观，Fw-05） | 改写卡补主角主动动作/台词（追问/出手/定调），内心独白不算 |
| Q10 抄不出/答否（对话零增量，Fw-05） | 加信息筹码（新事实/意图/关系）或删对话改动作 |
| Q11 抄不出/答否（ch1-3 无记忆点，Fw-05） | 不增设定，补一个具体物件/动作/狠话落点 |
| 全部通过 | 回收正文，进下一个 beat |

- **先抄后判**是低模型注意力锚定：开放判断（「写到没」）→ 机械行为（「抄出来」）+ 判断寄生；
- 自检卡问题可按题材增删，但**永远是先抄后判**，永不做开放式提问；
- 多采样外选时（同一 beat 抽 3-5 版），对每版分别跑 guyin-check-beat.js + 自检卡，先淘汰不过关的，再从过关版本中按"哪版更接近气句"外选——该判词只属于编排层与作者，不写入任何卡片。
