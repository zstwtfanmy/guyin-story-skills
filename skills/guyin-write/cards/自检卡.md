# 自检卡模板（cards/自检卡.md）

> 编排层专用：场景/章级审读辅助（任务书 §2.3）。拼章后与完整章审读（SKILL.md 4a）同用，**不再逐 beat 卡住**；
> 确定性检查已下沉脚本（check-beat + 章检链），本卡只做语义审读——先读出真实体验，再核对设计，最后锁定主缺陷路由。

---

```
【审读 第{{N}}章】先抄后判：每条结论先引原文段落，再下判断；可答「没感觉/不知道」，不猜正确答案。

── 第一步：全文初读（只给正文＋必要前文＋读者定位；不给细纲、设计解释或自评）──

从哪里开始想读/不想读：____（引原文）
期待什么、记住谁：____（引原文）
哪里得到兑现：____（引原文）

── 第二步：核对设计与事实（读细纲后）──

动机：人物为何此刻这么做（引正文证据，不引细纲意图当证据）____
能力依据/知情边界：凭什么能做、谁知道什么 ____
收益与承接：本章承诺兑现了吗？场景间承接成立吗 ____
（人物反应和后果可以隐含或延迟，不要求动作后立即补反应句、后果句）

── 第三步：锁定当前主缺陷（只锁一个）──

主缺陷：____ 证据：____（原文位置）
修订假说：改什么、凭什么能更好 ____
要保护的表达：____（修订不得磨平）

路由（按根因，不按报警计数）：
L1 段落修改｜词句失真、重复、局部表达不清——禁因句长/词频单独触发全文润色
L2 完整场景重写｜设计有价值、场景表达未兑现——禁拆成多个补句任务
L3 回章设计/中程规划再写候选｜人物选择无由、事件无价值、承接失效——禁先去AI味；禁不确认就改用户锁定结果
工程错误｜定位源头修复并复检——不得以「更有味」豁免错误
```

---

## 编排层处置规则

| 审读结果 | 处置 |
|---------|------|
| 初读无阅读失败、核对成立 | 过——进摘要（SKILL.md 步骤5），不追加润色 |
| 主缺陷 L1 | [改写卡](改写卡.md)段落级定向改，其他一个字不动 |
| 主缺陷 L2 | 整场景重写，改后重读完整受影响场景 |
| 主缺陷 L3 | 回细纲四组重走（B1），再写候选；拿不准登待审台账 |
| 工程错误 | 定位源头（细纲/状态/正文）修复并复检 |
| 无法完成全文审读 | 章记录标「本章审读未验收」，不伪装已读 |

- 默认一轮结构修订，必要时再一轮局部语言修订（可调成本上限）；没有新假说或净收益就停，允许平局、都差；
- 涉及结构或跨场承接时重读整章；
- 用户明示保留失败稿：记录「用户保留，质量未通过」，不改写成质量认证。
