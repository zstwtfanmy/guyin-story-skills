# 自检卡模板（cards/自检卡.md）

> 编排层专用：每个 beat 回收后、拼接之前必跑。逐项是非题，答"否"必须附句位。
> 是非题自检替代开放式自评——低模型对"你觉得如何"必然敷衍，对"是/否+句位"无法敷衍。

---

```
【自检 beat {{N}}/{{M}}】只回答是/否。任何一项答"否"，必须给出它所在的句子原文。

1. 正文里是否出现过"第X章 / 细纲 / 伏笔 / 读者 / 大纲"这些词？（是/否）
2. 是否有连续 4 句以上对话中间没有任何动作、表情或环境插入？（是/否）
3. 心理独白是否 ≤{{限额，默认2}} 句？（是/否）
4. "{{禁止项1}}"是否零出现？（是/否）
5. "{{禁止项2}}"是否零出现？（是/否）
6. 字数是否 ≥{{目标字数}}，且没有"此处省略 / 一番……之后"这类跳写？（是/否）
7. 必须发生的 ①{{事件1}} ②{{事件2}} ③{{事件3}} 是否都写到了？（是/否）
8. （非本章第 1 个 beat 时）开头两句是否顺着“前文”的语气续写——无重新起腔、无场景重述、无总结重启？（是/否）

逐项作答，格式：题号 + 是/否 + （答否时）句子原文。
```

---

## 编排层处置规则

| 自检结果 | 处置 |
|---------|------|
| 全部通过 | 回收正文，进下一个 beat |
| 第 1/4/5/6 题不过（确定性违规） | 组装[改写卡](改写卡.md)定向改，或整卡重发 |
| 第 2/3 题不过（节奏问题） | 组装改写卡，问题写成具体指令 |
| 第 7 题不过（漏事件） | 缺的事件写进改写卡“必须补入”，禁止另起炉灶重写全文 |
| 第 8 题不过（拼接断裂） | 组装改写卡只重写开头两句，对齐前文的节奏与悬置，其余不动 |

- 自检卡问题可按题材增删，但**永远是是非题 + 句位**，永不做开放式提问；
- 多采样外选时（同一 beat 抽 3-5 版），对每版分别跑自检卡，先淘汰不过关的，再从过关版本中按"哪版更接近气句"外选——该判词只属于编排层与作者，不写入任何卡片。
