# 自检卡模板（cards/自检卡.md）

> 编排层专用：每个 beat 回收后、拼接之前必跑。
> 确定性题（Q1-Q6）已下沉 `guyin-check-beat.js`；模型只答 Q7-Q11 语义题——**先抄后判**：每题先抄原文相关句、再答是/否，判断寄生在抄写之后（低模型注意力从概率行为变机械行为）。

```
【自检 beat {{N}}/{{M}}】guyin-check-beat.js 已查 Q1-Q6（禁用词/禁止项/字数/跳写/对话/独白）。
脚本 blocking 不过的 beat 不进本卡——直接改写卡。以下只答语义题，先抄原文再判：

7. 必须发生的 ①{{事件1}} ②{{事件2}} ③{{事件3}} 写到**完整结果**了吗（v3-B2）？
   每条找三样证据——动作（谁做了）／承受者反应／后果（此后什么变了）。抄台词不算结果——抄其后的反应句与后果句；抄不出答「未兑现」，不默认是：
   ① 动作：____ 反应：____ 后果：____
   ② 动作：____ 反应：____ 后果：____
   ③ 动作：____ 反应：____ 后果：____

8. （非本章第 1 个 beat 时）开头两句是否顺着"前文"的语气续写？
   先抄开头两句原文：____
   再答是/否：无重新起腔、无场景重述、无总结重启？

── 留存题（组卡按章号实例化）：Q9/Q10 ch1-3 每 beat、其后仅章末 beat；Q11 仅 ch1-3 ──

9. 本 beat 功能（从细纲功能标签抄，不造词）：____。
   要求主角主动吗（推进/出手/定调＝是；听取信息/蓄势/关系余韵/喘息/铺垫＝否）？
   · 要求主动：抄主角发起动作/台词的原文句 ____ 是/否（预标不在场准 N/A）
   · 不要求主动：抄功能落成的原文句（信息到手/张力蓄住/余韵落地）____ 是/否
   整体参与与回报的把关在拼章审读（SKILL.md 4a）；听取信息/蓄势/余韵是合法一拍（v3-B2）。

10. 有无一句对话给出**新信息**（新事实/意图/关系，非寒暄应答）？
    抄：____ 是/否（预标无对白准 N/A）

11. 读者能**记住**一个具体点吗（物件/狠话/动作，非气氛词）？
    抄：____ 是/否

逐项作答，格式：题号 + 抄写的原文 + 是/否/N/A + （答否时）补充说明。
```

## 编排层处置规则

| 自检结果 | 处置 |
|---------|------|
| 脚本 blocking 不过（禁用词/禁止项/跳写/字数不足） | 不进自检卡，直接组装[改写卡](改写卡.md)定向改 |
| 脚本 advisory（对话连排/心理独白超限） | 编排层判读：组改写卡或在自检卡附注行提示模型 |
| Q7 三要素缺任一（v3-B2） | 缺项写进改写卡"必须补入"（如「补反应句」「补后果句」），禁重写全文；证据不足标未兑现 |
| Q8 抄原文后答否（拼接断裂） | 改写卡只重写开头两句，对齐前文节奏与悬置，其余不动 |
| Q9 抄不出/答否（功能未落成，v3-B2） | 改写卡**按功能**补：主动拍补主角发起动作/台词（内心独白不算）；非主动拍补功能落点（信息到手/张力/余韵句），不硬改主动 |
| Q10 抄不出/答否（对话零增量，Fw-05） | 加信息筹码（新事实/意图/关系）或删对话改动作 |
| Q11 抄不出/答否（ch1-3 无记忆点，Fw-05） | 不增设定，补一个具体物件/动作/狠话落点 |
| 全部通过 | 回收正文，进下一个 beat |

- **先抄后判**是注意力锚定，永不做开放式提问；问题可按题材增删；
- 多采样外选：每版分别跑 guyin-check-beat.js + 自检卡，先淘汰不过关的，再按 SKILL.md 外选判词三问证据制——判词只属编排层与作者，不入卡。
