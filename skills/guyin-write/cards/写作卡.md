## 军规落点（编排层自查，组装时逐条过）

| 军规 | 本卡落点 |
|------|---------|
| 单轮单职责 | 一次只装一个 beat，M 个 beat 就是 M 张卡 |
| 填空优于生成 | 背景/必须发生/感官入口由细纲填死，执行层只填正文 |
| 人的落点 | （B5）空则不组卡，回细纲补 |
| 规格行 | 引号＋比喻域＋目从公约抄（B1/Y1） |
| 示例即规范 | 范文手感段 300 字，取自 exemplars 同题材切片 |
| 就近约束 | 禁止 ≤3 条贴着任务放，卡尾逐条复述 |
| 短输出单位 | 按粒度配置档位，章由 beat 拼接 |
| 防敷衍 | 字数区间硬性；拼接点衔接指令由编排层处理 |

## 禁区（违反即废卡重装）

- 永不写入任何哲学词汇（气/魂/合问/以天合天……）——哲学只允许以卡片结构在场
- 永不写入"参考 XX 方法论 / consult 库"之类的指引
- Muse 模式的发散指令只用 [发散卡](发散卡.md)，不在写作卡里叠加"发挥创意"
