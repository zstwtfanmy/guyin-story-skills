> 占位符取数规则见 [README.md](README.md)。

## 组装自查（编排层，终卡出坊前）

- 三类权限缺一不组卡（任务书 §2.2）；一卡一场（承载得住一卡整章），不逐 beat 拆、不逐句预写、不指定感官入口——表达判断权归执笔；
- 因果前情永不砍（超 500 token 按让位序砍范文→禁止→背景）；零哲学、零作者性字面、零指引（细则见 README 组装纪律）。

## 禁区（违反即废卡重装）

- 永不写入哲学词汇（气/魂/合问/以天合天……）与"参考 XX 方法论"类指引；
- 卡壳比较走 [发散卡](发散卡.md)（设计层简案），不在写作卡里叠加"发挥创意"。
