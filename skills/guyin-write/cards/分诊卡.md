# 分诊卡模板（cards/分诊卡.md）

> 章检/审读报警段分诊（任务书 §2.3）：ai-patterns / 章检脚本 editorial 报警不自动成为错误，
> 逐段判断是否对应**真实阅读失败**。单次判断带证据（不做多次投票制造确定性），只看报警段 ±2 行。

---

```
【分诊 {{i}}/{{total}}】
报警：{{报警类型}}（{{报警细节}}）
原文：{{报警段 ±2 行原文}}

单次判断，选 2 必须逐字抄一句原文作证据：

1. 真问题（对应具体阅读失败：词句失真/重复/信息泄漏/事实风险）→ 进改写队列
2. 有功能的正常文本（这个角色/这个题材本来就这样）→ 证据原文：____
3. 拿不准 → 进作者待审清单

只选一个编号。选 2 时必须填证据原文，不填视为选 3。
```

---

## 编排层处置规则

| 判断 | 处置 |
|------|------|
| 1 真问题 | 进改写队列（改写卡 L1 定向改）；同型报警重复出现→回审读找根因，不逐段打地鼠 |
| 2 正常文本 | 静默；证据须逐字摘抄（非概括），编排层可后验——空证据=敷衍，降级选 3 处理；台账回填「不适用」备注位置＋理由 |
| 3 拿不准 | 进作者待审清单（登台账，终态六选一） |

- **一卡一报警**：不把多个报警段塞进一张卡（注意力分配不均，后排被忽略）；
- verify 类报警（如 pov-drift）不走本卡——直接带证据登台账复核；
- 报警计数不是质量结论：报警多但表达成立的样本不因计数被强改；审读未指出阅读失败就不动。
