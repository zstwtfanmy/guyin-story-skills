# 分诊卡模板（cards/分诊卡.md）

> P1 文字视角漏斗化组件。ai-patterns / 章检脚本报警后，报警段不直接进模型全文审查，
> 而是逐段进分诊卡做三选一——低模型只看报警段 ±2 行，不看整章。
> 行为学设计：真问题置顶（低模型位置偏好）→ 选 2 必须给证据（对抗宽容偏差）→
> 「拿不准」合法（有退路时 1/2 判断更诚实）→ 中温 3 票制（§2.5 自一致性投票）。

---

```
【分诊 {{i}}/{{total}}】
报警：{{报警类型}}（{{报警细节}}）
原文：{{报警段 ±2 行原文}}

三选一，选 2 必须抄一句原文作证据：

1. 真问题（构成 AI 腔复读 / 套路句 / 信息泄漏）→ 进改写队列
2. 有功能的正常文本（这个角色 / 这个题材本来就这样）→ 证据原文：____
3. 拿不准 → 进作者待审清单

只选一个编号。选 2 时必须填证据原文，不填视为选 3。
```

---

## 编排层处置规则

| 3 票结果 | 处置 |
|---------|------|
| 一致选 1 | 进改写队列（组装改写卡，方向 = 报警类型对应的改写策略） |
| 一致选 2 | 静默——但检查证据是否抄了原文（空证据 = 敷衍，降级为选 3 处理）；对应待审台账终态「不适用」，回填时备注含原文位置＋判定理由 |
| 一致选 3 | 进作者待审清单 |
| 分歧（2:1 或 1:1:1） | 升级作者——分歧率高说明报警质量差（词表需收紧，见 §4 V4 误报率验证） |

- **中温 3 票制**：同一张分诊卡独立采样 3 次（温度 ~0.7），取多数票；分歧升级作者。
  零温采 3 次 = 同一票抄 3 遍（无意义），必须中温；
- **一卡一报警**：不把多个报警段塞进一张卡（低模型注意力分配不均，后排报警被忽略）；
- 分诊卡不进写章循环主流程——它在 review 文字视角和章检后分诊两个入口使用；
- 选 2 的证据必须是原文逐字摘抄（不是概括），编排层可后验：抄的句子里是否真有功能词。
