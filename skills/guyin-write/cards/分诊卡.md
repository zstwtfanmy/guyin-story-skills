# 报警分诊单（cards/分诊卡.md）——editorial 报警处置时自取

> 可选。ai-patterns 等脚本的 editorial 报警不自动等于错误：逐段判断它是否对应**真实阅读失败**。单次判断带证据，不做多次同模型投票。只看报警段 ±2 行。

## 逐条判断（选 2 须逐字抄一句原文作证）

1. **真问题**（词句失真/重复/信息泄漏/事实风险等具体阅读失败）→ 修订（[改写卡](改写卡.md) L1）；
2. **有功能的正常文本**（这个角色/题材本来就这样；正常心理、长对白、破折号、叙述中引入术语都属此类）→ 证据原文：____；
3. **拿不准** → 登待审台账交用户，「升级作者」是等待态。

## 规则

- 一条报警一判，不把多段塞一起；同型报警反复出现→回全文回看找根因，不逐段打地鼠。
- 选 2 的证据必须逐字摘抄（非概括），回填台账「不适用」：位置＋理由；空证据按 3 处理。
- verify 类报警不走本单：直接带证据登台账复核，是否豁免由用户授权。
- 报警计数不是质量结论：报警多但表达成立的稿子不被强改；回看没指出阅读失败就不动。
- hard/verify 与 editorial 的分类以脚本 handling 为准，不改 severity 名称冒充降级。
