# 摘要卡模板（cards/摘要卡.md）

> 编排层专用：每章拼接落盘后、追踪提交前，组装本卡下发 guyin-checker。
> 开放摘要对低模型 = 废话生成器——字段锚定答案空间 + 原文锚点防敷衍。

---

```
【章摘要 第{{章号}}章】从本章正文填空，每个字段必须抄原文锚点：

新事件（≤3 条，每条：谁+动词+结果）：
① ____（锚点原文：「____」）
② ____（锚点原文：「____」）
③ ____（锚点原文：「____」）

情绪走向（各抄一个词或短语）：从____到____

章尾钩子（抄本章最后一句原文）：「____」

伏笔变动（引用 F 编号，无变动写"无"）：____

出场角色（本章有台词或行动的角色，逗号分隔）：____
```

## 编排层处置规则

| 摘要结果 | 处置 |
|---------|------|
| 每字段有原文锚点 | 卡全文 = delta.result，随 commit 入库 chapter_summaries |
| 任一字段锚点空缺 | 退回重填——空锚点 = 模型在编 |
| 第 10/20/…章 | commit 后触发 10 章聚合（二叉树两两合并） |
| 卷末章 | commit 后触发卷摘要生成（常驻金字塔顶层） |

- **长度契约（D1）**：卡全文 ≈300 字（≤900 UTF-8 字节，delta.result／近章速记／chapter_summaries 同额）。超限删引文冗余、并条事件，不删事实——事实进实体字段，速记只留下章需要知道的；
- **速记与审读分离（D1）**：delta.result 只放事实速记，不塞审读报告/版本史/调用成本——审读全文与版本对照追加 `追踪/运行记录/第NNN章.md`（重提交不覆盖；脚本只重写 `逐章记录/`）；
- 10 章聚合约 1000 字，卷摘要约 500 字常驻；
- 金字塔消费方：review（卷摘要＋近 10 章章摘要＋本章全文 ≈5K 替代全书）、写章读盘、P3 收线审计。
