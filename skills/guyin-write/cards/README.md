# 任务卡组装协议（cards/README.md）

> 编排层唯一组装手册。写作卡是执行层唯一可见物——执行层不知书、不知纲、不知哲学，只见当前场景简报（三类权限）。

## 卡流总图

```
细纲(章) ──编排层组场景简报──▶ [写作卡]（一卡一场，承载得住一卡整章）──▶ guyin-check-beat.js ──┬─hard/verify─▶ [改写卡]
                                                                                            └─pass/editorial─▶ 拼接 ──▶ 完整章审读（SKILL.md 4a）
（卡壳时才走：[发散卡] 设计层简案比较——不进默认卡流）

拼接后摘要路径（每章一次）：
拼接 ──▶ [摘要卡]（checker 填空）──▶ delta.result ──▶ tracking-commit（入库 chapter_summaries）

章检后分诊路径（非写章主流程）：
章检 editorial 报警 ──▶ [分诊卡]（单次判断带证据）──┬─真问题─▶ [改写卡]
                                                   ├─有功能─▶ 静默
                                                   └─拿不准─▶ 作者待审（verify 报警直接登台账复核，不分诊）
```

## 占位符取数表

| 占位符 | 取数来源 | 规则 |
|--------|---------|------|
| {{场景名}}、{{字数目标}} | `大纲/细纲_第XXX章.md` | 场景名从第三组「场景序列」取；字数目标从第一组抄——**章级口径**，一卡一场时写足本场内容即可，不逐场摊配额 |
| {{既定事实}} | 细纲第四组 | 已发生事实/遗留实物处置摘（AC1：兑现或登伏笔，无声消失是禁区） |
| {{知情/保密边界}} | 细纲第四组 | 谁不知道什么；禁止提前释放项 |
| {{锁定结果}} | 细纲第四组 | 用户锁定项注来源；无则整行删 |
| {{禁止}} | 编排层按本章风险点选 | ≤3 条；只装书级明确约定（题材定位/作者性/批次公约译出的禁令），普适审美不作默认；确定性供给（N3）：复读短语（意象台账「最近章 ≥ 当前−5」）＋黑名单逼近限额条目 |
| {{偏执点行}} | `作者性/偏执点.md` | 原样抄录 ≤2 条；未设定则整行省略 |
| {{人物与意图}} | 细纲第二组 | 相关人物各自想要什么、知道什么、凭什么能做——本场涉及者 |
| {{需要成立的体验}} | 细纲第一组「读者承诺」 | 处境与行动，不写情绪词（读者承诺行细则见细纲协议） |
| {{承接}} | 细纲第三组 | 该场起点、前后变化、与下一场承接；末场加章尾落点 |
| {{复沓锚句行}} | 细纲第四组「复沓锚句」 | 须逐字落地的原话一行一条注落点；无则省略 |
| {{前文}} | `正文/` 上一场或上一章结尾 | 章首场贴上一章结尾 **300 字原文** + 文气一行；其余场贴上一场结尾原文——**上一段 100/300 字只是声线锚，不能替代因果前情**（任务书 §2.2）：需要因果时从角色状态、承诺与相关原文按需取材 |
| {{当前状态}} | `追踪/角色状态/*` | 只摘本场相关角色的关键状态 |
| {{声线锚}} | `大纲/批次公约.md` | 引号＋比喻域，≤30 字从公约抄（B1/Y1）；公约缺失先补纲场景建公约 |
| {{范文手感}} | `references/exemplars/`（路由见该库 README，v3-B4） | **场景功能/视角/叙述距离优先，题材文件名只是辅助**；下卡截约 300 字；禁抄内容；同章不重复；无匹配如实报缺口，不伪造已补齐 |
| {{笔法切片}} | 语言纪律/执行层一页纸（仅已建时） | 编排层摘 ≤50 字规格/范文句；无则整槽删、禁整篇下发（Fw-03） |
| {{物证清单行}}（可选） | `追踪/物证台账.md` | 仅推理/查案场贴：在案物证一行列；台账空或非查案场省略（T1） |
| {{场景锚点行}}（可选） | `追踪/场景台账.md` | 本场涉已登记场景时贴：场景名+五感锚点原句；同场景重复出场必带同一锚点物；无登记省略（P4） |
| {{章号}} | 编排层当前写章编号 | 摘要卡组装时填入 |
| 好坏对照例 | exemplars 对照例区或现场构造 | 一对，方向与"问题"精确对齐 |

## 组装纪律（每张终卡出坊前过一遍）

1. **剥净**：模板中所有 `<!-- -->` 注释、说明表格、"编排层"字样全部剥掉——终卡上不能有任何给编排层看的东西；
2. **<500 token**：超了按让位序砍（范文 > 禁止 > 必须发生 > 前后因果——**该场因果动机/信息边界/材料来源永不砍**）；500 token 是**预算口径非充分性证明**——装不下因果时报预算不足拆场或精简取材，不硬塞（C1 实测验证）；
3. **零哲学**：终卡不得出现 气/魂/合问/以天合天/灵气/显影 等词——哲学只允许以卡片结构在场；
3a. **零作者性字面**：终卡禁出现气句/魂档案原文或近似——精神件只以行为描述在场（「结尾落在实物上」✅「结尾要有稳住感」❌）；
4. **零指引**：不得出现"参考/查阅/方法论"类指引；执行层不读书，按权限写；
5. **连续场景**：一卡一场（承载得住一卡整章）；不逐 beat 拆、不逐句预写、不指定感官入口或逐句动作——表达判断权归执笔（任务书 §2.2）；
6. **默认单稿**：多候选须**先与用户约定候选数与成本上限**（任务书 §2.2；整章多候选另走候选隔离协议）。已约定的多候选外选按证据制：机械筛（G4：候选否定强度超本章声明档位出局；含精神件字面出局，H1）+ 三问对比每问引稿件证据（阅读任务落成/人物可信鲜活/符合作者选择——对照气卡，永不下发）；**允许平局/都差/证据不足**；
7. **组卡前查表**：查 `追踪/意象台账.md`（已用域/近三章高频域，顺带取复读短语作 `{{禁止}}` 候选），比喻域避让——当章登记、下章前查表（repetition.js 闭环）；
8. **指令区绝缘**（K1）：细纲「写作指令」区**永不进【这一场】内容通道**——可提炼为 `{{禁止}}`。指令进内容通道＝执行层当人物台词写出来（v3 泄漏机理）；
9. **同章多场**：后续场景使用已选草稿中的变化作为临时上下文，不提前写正式追踪；废弃候选的变化不得混入另一候选（任务书 §2.2）。

## 拼接与落盘

- 场景间衔接由完整章审读（SKILL.md 4a）把关；全过后按序拼章，只查跨场信息重复与事件顺序；
- 落盘后立即提交追踪（`scripts/guyin-tracking-commit.py`），再进章检（见 SKILL.md）。
