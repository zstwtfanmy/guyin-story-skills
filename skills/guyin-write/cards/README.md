# 任务卡组装协议（cards/README.md）

> 编排层唯一组装手册。四张卡是执行层唯一可见物——执行层不知道书、不知道纲、不知道哲学，只知道当前这一张卡。

## 卡流总图

```
细纲(章) ──编排层切 beat──▶ [发散卡]* ──▶ [写作卡] ──▶ guyin-check-beat.js ──┬─blocking─▶ [改写卡]
                                                                              └─pass/advisory─▶ [自检卡] ──┬─过──▶ 拼接
                                                                                                          └─不过─▶ [改写卡] ──▶ 再自检
* 仅 Muse beat（判据见 SKILL.md），阶段三起启用

拼接后摘要路径（每章一次）：
拼接 ──▶ [摘要卡]（checker 零温填空）──▶ delta.result ──▶ tracking-commit（入库 chapter_summaries）

章检后分诊路径（非写章主流程）：
章检脚本报警 ──▶ [分诊卡]（三选一+中温3票制）──┬─真问题─▶ [改写卡]
                                             ├─有功能─▶ 静默
                                             └─拿不准/分歧─▶ 作者待审
```

## 占位符取数表

| 占位符 | 取数来源 | 规则 |
|--------|---------|------|
| {{N}}/{{M}}、{{目标字数}}、{{上限字数}} | 编排层切 beat 的结果 | 按粒度配置档位（密/疏/铺垫分组）；Σ 缺口进密 beat 上限 |
| {{背景}} | `大纲/细纲_第XXX章.md` | 一句话，禁超过 2 句 |
| {{物证清单行}}（可选） | `追踪/物证台账.md`（tracking-commit v6 evidence 实体） | 仅推理/查案章贴在背景行后：本案在案物证一行列（名称+状态+持有，仅本章可用）；台账空或非查案章省略整行（T1 细节密度供给） |
| {{场景锚点行}}（可选） | `追踪/场景台账.md`（tracking-commit v7 scenes 实体） | 本章涉场景且台账非空时，在背景行后贴一行：场景名+五感锚点原句（如「西厢院｜院里有棵歪脖枣树，树底下压着半扇磨盘」）；同场景重复出场必带同一锚点物（防漂移：桌子方位变了/枣树没了）；已变迁场景贴 current 现状行；无登记场景则整行省略（P4） |
| {{前文}} | `正文/` 上一 beat 或上一章结尾 | 章首 beat 贴上一章结尾 **300 字原文** + 文气三行；其余 beat 贴上一 beat **结尾 100 字原文** + 文气一行（低模型读摘要无效） |
| {{必须发生}} | 细纲该 beat 的事件 | ①②③ 编号，每条一个可验收事件 |
| {{禁止}} | 编排层按本章风险点选 | ≤3 条；首选确定性可查的（词表/句式/字数）；确定性供给（N3，docs/07）：① N1 复读短语——`追踪/意象台账.md` 复读短语节中「最近章 ≥ 当前−5」条目（随纪律 7 查表顺带取得，零新步骤）；② 黑名单逼近限额条目——读上一章 ai-patterns 产出；两者并入候选由编排层选，是供给不是替代 |
| {{偏执点行}} | `作者性/偏执点.md` | 原样抄录 ≤2 条；未设定则整行省略 |
| {{范文手感}} | `references/exemplars/{题材}.md` 或 `体感粒度.md`（峰值 beat） | 300 字切片；禁抄内容；同章不重复；峰值 beat 取体感样本时卡面写死「临摹这个分辨率，不临摹这些句子」 |
| {{感官入口}} | 编排层指定（或发散卡胜出方向回填） | 气味/温度/触感/声音/体内感觉五选一，禁"视觉"；可从 `灵感池/` 按感官通道标签取（素材积累后按需唤起，见项目 灵感池/README.md 索引） |
| {{情绪目标}} | 细纲「情绪落点」行 | 一个词（如：憋屈→炸）；取该 beat 覆盖的落点情绪（Q1c） |
| {{人的落点}} | 细纲「情绪落点」行的「人」的落点 | 落在具体角色的反应/选择上（B5）；≤20 字从细纲抄，**空则不组卡** |
| {{规格}} | `大纲/批次公约.md` | 引号＋比喻域＋目={高|低}，≤30 字从公约抄（B1/Y1）；公约缺失先补纲场景建公约 |
| {{笔法切片}} | 语言纪律/执行层一页纸（仅已建时） | 编排层摘 ≤50 字规格/范文句；无则整槽删、禁整篇下发（Fw-03） |
| {{章号}} | 编排层当前写章编号 | 摘要卡组装时填入 |
| 好坏对照例 | `references/exemplars/` 对照例区 或 编排层现场构造 | 一对，方向必须与"问题"精确对齐 |

## 组装纪律（每张终卡出坊前过一遍）

1. **剥净**：模板中所有 `<!-- -->` 注释、说明表格、"编排层"字样全部剥掉——终卡上不能有任何给编排层看的东西；
2. **<500 token**：超了就砍背景与禁止项，砍的顺序：背景第三句 → 范文段换更短的切片 → 禁止项合并；**必须发生与卡尾复述永不砍**；
3. **零哲学**：终卡不得出现 气/魂/合问/以天合天/灵气/显影 等词——哲学只允许以卡片结构在场；
3a. **零作者性字面**：终卡禁出现气句/魂档案语句原文或近似——精神件只以禁令的行为描述在场（「结尾落在实物上」✅；「结尾要有稳住感」❌，那是把精神件翻译成话术，执行层会复读话术）；
4. **零指引**：不得出现"参考/查阅/方法论"类指引；执行层不读书，只填空；
5. **多采样**：情绪峰值 beat 可同卡抽 3-5 版并行；每版独立跑 guyin-check-beat.js + 自检卡，外选判词只存在于编排层报告里，不回流到任何卡片。
6. **超档出局（G4）**：反转/复盘/识破 beat（所在章 G1 档位 ≥1 或 beat 含否定翻转句式）多采样外选前，编排层先机械筛——候选版否定强度超过本章声明档位（全称量词全盘否定/超档金句，判据复用 G1 词表）标「超档」出局，气句再好不选：决绝句在气句维度单调胜出，正是事故放大器。
7. **组卡前查表**：查 `追踪/意象台账.md`（已用域、近三章高频域；顺带取复读短语「最近章 ≥ 当前−5」作 `{{禁止}}` 候选），比喻域选域避让——写完当章登记、下章前查表（repetition.js 章检 blocking 闭环）。
8. **指令区绝缘**（K1）：细纲「写作指令」区**永不进 `{{必须发生}}`**——可提炼为 `{{禁止}}` 或卡尾复述。指令进内容通道＝执行层当人物台词写出来（v3 泄漏机理）。

## 拼接与落盘

- beat 间衔接已由自检卡第 8 题前置把关；beat 全过后按序拼接成章，拼接时只查跨 beat 的信息重复与事件顺序；
- 落盘 `正文/第XXX章_标题.md` 后立即提交追踪（`scripts/guyin-tracking-commit.py`），再进检查脚本环节（见 SKILL.md）。
