# 按需辅助卡（cards/）

> 这些卡是当前会话**自取的思考清单**，不是默认流程，不向任何人下发，没有 token 配额，没有逐 beat 验收。
> 单模型自主执笔架构下，你一个人完成取材、写作、回看、修订与事实提取；觉得某张卡的问题单有用就照着想一遍，没用就不用。卡不产生门——门由检查脚本、授权与账本守。

## 卡单与使用时机

| 卡 | 什么时候值得自取 | 产出落在哪里 |
|---|---|---|
| [写作卡](写作卡.md) | 开写前材料杂、想快速核对锁/事实/承接是否齐 | 只对照检查，不强制成文档；正式冻结在 `R/input.json` |
| [自检卡](自检卡.md) | drafted 全文回看时想要一份问题单 | 回看结论写 `R/review.md`（绑候选哈希） |
| [改写卡](改写卡.md) | 回看发现 L1/L2/L3 问题，组织修订假说 | 修订动作；新版本存 `R/drafts/` |
| [发散卡](发散卡.md) | 真正卡壳，需要比较人物选择/局势后果 | 选定方向直接进入写作；新元素可登灵感台账 |
| [分诊卡](分诊卡.md) | editorial 报警多，判断哪些是真阅读失败 | 真问题→修订；误报→证据；拿不准→待审台账 |
| [摘要卡](摘要卡.md) | reviewed 后从选定稿提取追踪事务 | `R/transaction.json`（schema 以 tracking-transaction.md 为准） |

## 使用纪律

1. **卡不锁剧情**：写作卡的「这一场」来自未锁定假说，成稿可以替换；真正不能动的只有带来源的锁（input.locks 与已发布事实）。
2. **卡不代替全文回看**：自检卡的问题要对着完整成稿回答，不能用脚本分数或摘要代替阅读。
3. **卡不产生配额**：没有固定场次数、字数桶、感官入口、情绪升降或多稿数量；多候选必须先与用户约定数量与费用。
4. **工序提示不进正文**：卡上的方法论语言（含哲学词、分析词）是思考工具，写进正文就是泄漏，由 authority-leak 拦。
5. **修订有停时**：默认至多一轮有假说的实质修订；比较四项（问题消除/新问题/表达损失/读者偏好），无净收益就停，允许平局、都差，纯润色保留旧稿。
6. **事实从选定稿提取**：事务字段照 tracking-transaction.md 真实 schema 填，摘要卡只是防漏清单，不另造状态。
