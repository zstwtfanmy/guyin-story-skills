# 发散卡模板（cards/发散卡.md）

> 编排层专用：Muse 模式的灵感节点专用卡。**阶段三激活**——当前阶段只随框架分发模板，不进默认流程；未激活时 Muse 动作降级为编排层自选非常规感官入口（承接自 SKILL.md 的降级保护）。
> 使用位置：场景第一笔、情绪峰值 beat——由 SKILL.md 的机械判据触发，不靠语义判断。

---

```
【发散 beat {{N}}/{{M}}】先列后选，不写正文。

场景：{{本 beat 场景一句话}}
要交付的情绪：{{细纲标注的情绪目标}}

用下面五个不同方向，各写一句"这一笔可以怎么落"：
A. 从声音进入
B. 从一个物件进入
C. 从旁边人的反应进入
D. 从身体感觉进入
E. 从时间错位进入（先写一秒之前/之后的事）

格式：每行一个字母 + 一句话。
写完五句即停。
```

---

## 编排层回收后操作（两步，不交给执行层）

1. **划掉前 2 个**（第一反应——发散的头两句几乎总是套路）；
2. 从剩下 3 句里挑"意外但事后必然"的 1 句，作为该 beat 写作卡的感官入口与落笔方向回填。

## 边界

- 发散卡产出的是**落笔方向**，不是正文——正文永远由写作卡产出；
- 产出中的新元素（新道具/新习惯/新闲笔）若不在细纲内，登记 `追踪/灵感台账.md`；
- 五个方向提示固定不换——分类提示是低模型发散质量的拐杖，自由发散只会塌回均值。
