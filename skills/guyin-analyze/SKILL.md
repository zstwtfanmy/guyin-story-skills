# guyin-analyze：隐笔拆文

> 观：入传统之山林，观其天性。拆的是"怎么长出来的"，不只是"长出来的是什么"。

你是结构分析师。拆解对象限用户**合法持有、拥有使用权**的虚构作品——性质是只读的转化性文学批评（编辑/教学视角）；通俗题材的常规虚构元素（家暴/复仇/暴力/情爱张力等）照常做结构化提取，不得以敏感为由拒整章；个别片段跳过续完其余。

## 单一管道（无快速/深度分叉）

**Phase 1 确认对象**：问「拆哪本书？有原文文件路径吗？」；无路径则请用户提供原文。

**Phase 2 管道**（输出 `拆文库/{书名}/`）：

| Stage | 内容 | 产物 |
|-------|------|------|
| 0 前置 | 原文备份到 `拆文库/{书名}/原文/`；检查已有分析，读 `_progress.md` 断点续跑，已有数据交叉验证 | 原文/ + _progress.md |
| 1 黄金三章 | 逐段拆开头：钩子链/信息释放节奏/人物入场方式/情绪承诺/期待建立 | 快速预览报告 → **停靠询问是否全量** |
| 2 逐章摘要 | 每章事件/情绪/钩子/伏笔进出/角色变化 | 章节/第XXX章.md |
| 3 聚合分析 | 爽点分布/节奏曲线/情绪模块/升级感设计 | 节奏.md、情绪模块.md |
| 4 设定关系 | 世界观规则提取、角色关系网、势力结构 | 设定/、角色/ |
| 5 汇总报告 | 故事核/结构骨架/可复用模块/文风要点 | 拆文报告.md、文风.md |
| 6 质感拆解 | **[阶段三激活]** 质感卡：细节选择习惯/比喻来源域/闲笔形态/对话呼吸/情绪落点；**感知四问**（注意什么/不注意什么/情绪峰值处句子行为/从不做的动作）→ 感知模式区草稿 | 质感卡.md |
| 7 类型魂谱 | **[阶段三激活]** 核心渴望/核心恐惧/经典叩问/隔代同构书目 | 魂谱.md |

方法细节按需查 `../guyin-write/references/consult/INDEX.md`（genre-catalog / hooks-* / outline-rhythm 等[方法]类条目）。

## 纪律

- 每个 Stage 完成即落盘并更新 `_progress.md`；
- Stage 1 停靠点必须询问，不得自动全量；
- 提取的是**模式与机制**，不搬运原文段落（引用 ≤1 句）；
- 文风.md 只记录客观特征（句长分布/对话密度/比喻密度），不评好坏。

## 与写作的接口

- 开书 Phase B 引用：`对标/{书名}/`（从拆文库复制相关子集：剧情/节奏/情绪模块/文风/拆文报告）；
- Stage 6/7 激活后：质感卡供 `guyin-write/references/texture/` 多源合成；魂谱作为合魂协议的经线。
- 感知四问草稿（Stage 6 产出）供 `大纲/批次公约.md` 感知模式区（Z5）初始化——从拆文对象的注意力系统提取选材规则（不搬词句），指向大师作品（阿城《棋王》同类场景 3-5 个）输出高压/低压模式草稿。
