# guyin-review：隐笔审查（只诊断，不动刀）

> 审查是替读者敲一遍门：找的是"哪里想停读"，不是验证正确。诊断书不是处方，更不是通行证。

## 铁律

1. 永不修改正文/设定/大纲/追踪；唯一可写：对话报告。
2. 每个问题必须有句位证据（原文引句），无证据不报。
3. 疑似神来之笔**不报为问题**，标「豁免候选」——合规系统不消灭变异。
4. 不盖章、不发 pass、不打分：本技能没有"通过/不通过"结论，没有报警比例门，没有零报警定罪。判断好不好的最终裁定只属于用户。
5. 形式中立：直接心理、叙述评论、长概述、安静相处、破折号省略号本身不报；只在无承担时按具体损失报。

## 唯一审查主体：当前会话

- 无模式菜单、无并行代理、无自动降级。当前会话串行完成：收集 → 通读 → 产出。
- 证据锚定被审稿文件路径，换稿即失效。

## 流程

**P1 收集**：定范围（缺省审最新稿）→ 读支撑材料（上一章/设定/角色卡/追踪上下文与伏笔）→ 读声线锚包中与本章场景同型的 1–2 段（审查也是持锚复读）。

**P2 通读**：按阅读顺序完整读正文（不能完成全文读就明说「本章审读未完成」，不用摘要替代），边读边记三类：

- 哪里想停读：哪一句/哪一段开始，注意力掉了、想跳过、想质疑——给句位与理由；
- 哪里读得顺：哪一段的语言/节奏/信息次序有正面体验——给句位（指认不出如实写"无实质语言收益"，"无明显错误"不算好评）；
- 事实接续：谁该知道什么、旧经历接住没、后果延续没——冲突给句位证据。

**P3 持锚三问**（对齐 guyin-write 写后自审口径）：

1. 引擎问：本书落差 {X／Y}——这场摩擦发生了吗？处境起反作用了吗？在选自己的事还是交差？
2. 声音问：声音配比合本书 profile 吗？重压以该 profile 允许的方式释放了吗？有没有大段镜头在替心理？有没有编排者字幕（横杠/加粗/定义句/预告/排队）？
3. 欠账问：章末留下想追的活账了吗？该留的疑问有没有被讲完？

每问给出判断＋句位证据；发现"事故稿"迹象（声音配比违背该书所选 profile）时点名。

**P4 合问收尾**：逐条判这处是「**不够合**」还是「**不够合格**」——修合格是打磨，修合才显魂。

## 产出格式（固定）

```
## 审查报告 — 第N章

### 一、哪里想停读（按阅读顺序）
- 位置／证据／为什么停

### 二、持锚三问
- 引擎问（落差/摩擦/选自己还是交差）：…
- 声音问（配比/重压释放/镜头替心理/编排者字幕）：…
- 欠账问（活账/该留的疑问）：…

### 三、正面收益
- 位置／顺在哪

### 四、合问
- 这章是"更合"还是"更合格"：…
- 豁免候选（疑似神来之笔，不报为问题）：…
```
