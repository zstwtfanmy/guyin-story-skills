# guyin-review：隐笔审查（只诊断，不动刀）

> 显：见者惊犹鬼神之前，先有人替读者敲一遍门。审查是找问题，不是验证正确；诊断书不是处方——本技能一字不改正文/设定/追踪。

## 铁律

1. 永不修改正文/设定/大纲/追踪；唯一可写：对话报告 + 分批 state.md。
2. 每个 finding 必须有句位证据，无证据不报。
3. 疑似神来之笔**不报问题**，标「豁免候选」交五测试（见 guyin-write 文末）——合规系统不消灭变异。
4. 确定性预检只读：对**显式候选**跑章检脚本（经 guyin-write 的 candidate-context 汇总，--project/--chapter/--boundary 齐），结果只作 finding 证据；零扫描/缺件/解析失败是 error，不能写成「不适用」。文字视角报警段进[分诊卡](../guyin-write/cards/分诊卡.md)单次判断，只看报警段 ±2 行；架构视角的完整章读不可省。
5. 审读未完成或主要阅读失败未处置不标合格；用户明示保留失败稿，报告记「用户保留，质量未通过」，不改写成质量认证。

## 唯一审查主体：当前会话

- **没有模式菜单、没有并行审查代理、没有自动降级。** 当前会话串行完成收集与四视角；架构视角的完整章读必做，角色对话可简不可省。
- 报告开头逐字只保留两个 key：`Rubric`（所用基准）与 `Rubric Source`（fanqie/qidian/zhihu/quality-rubric/内置）；不输出模式类 key。
- 发布清单的 `review.mode` 固定填「当前会话全文回看」；审查证据绑被审候选的 SHA-256，换稿即旧审查失效，不为新稿背书。

## 流程

**P1 收集**：定范围（未指定审最新稿）→ 读支撑材料（设定/角色卡/追踪/伏笔；气卡+魂档案备合问，不下发 prompt）→ 跑确定性预检（铁律 4）→ 定 rubric：平台读 `references/rubrics/{fanqie,qidian,zhihu}.md`，通用读 `references/quality-rubric.md`；不可读用内置基准包（文末），注明 Rubric Source。

**P2 四视角**（当前会话串行；P1 漏斗化）：

| 视角 | 执行形态 | 检查项 |
|------|---------|--------|
| 文字 | **漏斗式**：ai-patterns 全扫 → 报警段 ±2 行进[分诊卡](../guyin-write/cards/分诊卡.md) → 只对判为真问题的段深查 | 证据空=拿不准，进待审 |
| 一致性 | **纯脚本**：consistency + narrative-asset + tracking-state 比对 | 实体/数字/时间点冲突；伏笔矛盾按 F 编号精确召回 |
| 架构 | **完整章读 + 作者抽检**：本地可算钩子强度/主线间隔/章尾分布 → **完整读一遍本章**（先只读正文记真实理解，再对照细纲核因果收益/人物是否仅配合剧情/读者为何继续；引前后句，**不得用脚本信号冒充语义阅读**）→ 信号表＋审读记要交作者 | 无法完成全文审读标「本章审读未验收」，不用投票/摘要替代 |
| 角色对话 | 当前会话就候选核 | 声线一致？潜台词？行为合动机？关系尺度匹配阶段？ |

**P3 综合**：合并去重 → severity 排序（S1 主线崩/读者信任崩；S2 明显影响效果；S3 局部；S4 建议）→ 分歧如实呈现，不自动妥协。

**P4 合问收尾**：对照气句与一生之问逐条判 S1/S2——这处是「**不够合**」还是「**不够合格**」？修合格是打磨，修合才是显魂；同时判定豁免候选。

## 统一 Findings Schema（必用）

```yaml
- severity: S1 | S2 | S3 | S4
  category: structure | character | prose | consistency | format
  location: 文件:行号 或 章节/段落
  evidence: "原文证据"
  issue: "问题描述"
  fix: "可执行方向"
  level: L1 段改 | L2 beat 改 | L3 章改   # 对接大修分级
  handling: hard | verify | editorial     # 与脚本处置分类同口径；语义阅读项自定级
  candidate_sha256: "<被审候选完整 SHA-256>"
  source: "当前会话全文回看 | 脚本:<名>@参数 | rubric:<来源>"
```

输出三桶：① **修改清单**（按 level 分组 → 大修场景执行）② **豁免候选**（→ 五测试）③ **AI 味集中区**（→ guyin-deslop）。**hard/verify findings 由写作会话转入 `追踪/待审台账.md`（U1）——只诊断不动刀，产出不无声消失（未终态行阻塞写新章）；editorial 留审读记录，不占审美豁免配额。**

## 内置基准包（rubric 不可读时必用）

- 无明确卖点/只解释无冲突/无钩无期待/情绪平直 ≥S2
- 行为不合动机 S1/S2；设定事实冲突 S1；关系越界无铺垫 S1/S2
- 说明书式对话 ≥S2；AI 腔/陈词/章尾总结体 S2/S3；碎句电报体同级
- 开篇撞题材模板 ≥S3（整体可换 S2）；卡点删掉无损 ≥S3

## 分批审查（整卷/多篇）

维护 `.guyin-review/state.md`（范围/已完/下一批/未解决 findings 摘要/每轮 S1、S2 计数），下批开头读回注入；非分批不创建。**收敛协议**：S1=0 且 S2 连续两轮零新增可附「建议收敛」；同章审查-修复循环默认 R4 停靠，待作者显式续期。
