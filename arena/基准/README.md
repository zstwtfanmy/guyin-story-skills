# Arena 基准（擂台协议）

> 纪律：没有基准的改进都是自我感觉良好。每阶段打一场，胜者成为新基线，封神就是基线滚动的轨迹。

## 规则（对应 docs/02-落地计划.md §6）

| 项 | 规则 |
|----|------|
| 对手 | 挑战者 = 当前框架版本；卫冕者 = 上一版基线（首场 = 原 oh-story-claudecode 框架） |
| 题目 | 下方 3 个固定场景轮换（每场至少 1 个，推荐场景 2） |
| 执行 | 双方执行层**锁同一低模型**（从第一场起就在真实战场打） |
| 盲评维度 | 翻页欲 / 细节留存（10 分钟后记得什么）/ AI 味 / 灵气 / **合问**（这章是更"合"，还是只是更"合格"） |
| 评委 | 作者本人（主）+ 换一个模型当读者（辅）+ 可选朋友 |
| 判定 | 胜者成为新基线，样本与记录落盘 `arena/`，附对战记录（模板见 [../对战记录/模板.md](../对战记录/模板.md)） |
| 频率 | 每阶段至少一场，目标每 2-3 周一场 |

## 首场跑法（阶段一验收，需真实 CLI 环境）

1. 用**原框架**（oh-story-claudecode，`.upstream/` 内）+ 锁定低模型，跑 3 场景 → 样本存 `arena/基准/原框架/`；
2. 用**隐笔**（guyin-skills 本项目）同模型同题跑 → 样本存 `arena/基准/隐笔-vX/`；
3. 盲评（文件名脱敏为 A/B）→ 对战记录落盘；
4. 原框架样本即首任基线。
