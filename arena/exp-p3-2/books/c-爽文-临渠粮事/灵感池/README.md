# 灵感池

> 口述采集落点：AI 提问（例：你见过最穷但讲究的房间？），作者口述两句，AI 整理落盘于此。真实细节自带不符合叙事模式的不规则性——人味指纹，AI 生成不出。只注入不强插。

## 索引协议（P4，素材积累后「按需取」的唤起入口）

每条素材一行，格式固定，组卡时按标签检索：

```markdown
| 标签 | 感官通道 | 场景 | 素材原句 |
|---|---|---|---|
| 穷讲究 | 触感/视觉 | 出租屋 | 搪瓷缸里插着一支百合，缸沿豁了个口 |
```

- **标签**：题材/主题关键词（如 穷讲究、市井、旧物）；
- **感官通道**：气味/温度/触感/声音/体内感觉/视觉——{{感官入口}} 选型时按通道过滤；
- **场景**：适配场景类型（如 出租屋、军营、酒馆）——场景锚点行/发散卡选材时按场景过滤；
- **素材原句**：口述原话，禁概括——与台账锚点同纪律（低模型补全具体名词的能力远强于从抽象生成具体）。

拆文积累（guyin-analyze 产出）转灵感池时按同一格式登记。无匹配素材时正常省略，不强插。
