# 第002章 绳头（上）

赵九成走后的第二天，临渠城下起了细雨。

雨不大，落在运河面上起一层麻子点。陆争天没亮就起了，先去灶房烧了一锅热水，外院学徒该干的活他一样没落下——翻麦、扫地、给二掌柜的茶壶续上水。钱有义从柜房里出来了两回，看了他两回，每回都像有话要说，末了只丢下一句："今日铺子里的账，你少操心。"

陆争应了，心里清楚：二掌柜怕他再出头，把事闹到不可收拾。可柜房怕事，赵九成就专挑怕事的捏。

辰时刚过，老魏披着蓑衣进了侧门，鞋底在门槛上蹭了两下，凑到廊下压低声音："先生，信儿。姓赵的昨日午后去了恒裕，恒裕的吴掌柜当场没敢签，说要等今天东家回信；傍黑去了德昌，德昌李掌柜称病，没见。"

"都没签？"陆争把扫帚靠在墙根。

"没签，可也都没顶。"老魏伸出三根指头，"我听恒裕的小伙计说，吴掌柜今早要去德昌串门。下雨天上什么门，分明是两个掌柜要凑到一块儿商量——他们就怕枪打出头鸟，都在等别人先签，自己跟着签就不算罪。"

陆争点点头。这正是赵九成要的：不用三家都怕，只要三家都不敢第一个硬。

"老魏哥，劳你再跑一趟。"他回屋取了纸笔，就着廊下的天光写了两行字，吹干了墨，"送到恒裕吴掌柜手上，别经旁人。"

老魏不识字，把纸条小心揣进怀里："就说你写的？"

"就说万盛验米的学徒请他看一样东西。"

巳时，恒裕粮行后堂。

吴掌柜是个干瘦老头，胡子修得整齐，捏着陆争那张纸看了半天，又抬眼打量这个浑身湿了半边的学徒："你写的？和籴若成，三家联保，扦样同开同验？"

"是。"陆争站得笔直，"赵百户要的是三家各退一步。他手里的霉米十二车，一家塞四百石，每家都怕独抗；可他怕的也是三家同验——和籴是官面差事，扦样当着三家伙计的面开，好就是好，劣就是劣，没有谁私下里被逼着按印。今日他能塞霉米给我们，明日封仓出了事，三家谁都脱不了干系。联保不是抗差，是把规矩摆到台面上来。"

后堂帘子一响，德昌的李掌柜收着伞进来，显然是被吴掌柜连夜叫过来的。他比吴掌柜胖，进门先呵了口气："这位就是万盛那个把赵九成验退了的小先生？"他自称病，眼睛却亮得很，"吴老哥，路上我想明白了。跟着签霉米，三日后一样是死；可真要联保，万一赵九成恼了，头一个封的是谁的店？"

"谁的店都不用封。"陆争把怀里的油纸包取出来，三盘样米他各留了一小撮，此刻摊在桌上，"三位掌柜只要做一件事：三日后验米，开仓扦样让脚夫和别家的账房都看着。米好，按定额收，谁都不亏理；米劣，当众扦出来的，不是我们三家抗差，是军粮成色不足，该追的是漂没的人。"

吴掌柜捻着胡子不语。李掌柜盯着那三撮米看了半晌，忽然问："你一个学徒，替万盛出头，图什么？"

"图我的月钱不被摊进霉米里。"陆争答得坦然，"也图满师那天，文书上别多一笔烂账。"

两个掌柜对视一眼，都从对方眼里看见了点东西——一个学徒把话挑到了这个份上，他们两个做了半辈子生意的人，再往后缩，往后在临渠城的码头上就抬不起头了。

吴掌柜终于点头："联保可以。但契纸要三家东家、掌柜都画押，光你一个学徒在场不作数。你们万盛东家不在——"

"契书我带回去请二掌柜签，他若不签，今日这话就当我没说过。"陆争心里没底，嘴上没露，"只请二位掌柜给个时辰：今日申时之前，我带万盛的押来；过了申时，二位要另做打算，我也不拦。"

从恒裕出来，雨停了，天还阴着。陆争走得快，没走正街，顺着河沿往回赶。二掌柜那一关，他心里只有三成把握，可眼下没有别的路。
