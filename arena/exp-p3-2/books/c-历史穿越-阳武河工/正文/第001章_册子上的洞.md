# 第001章 册子上的洞

陈默抄了三个月物料册，先抄明白的不是河务，是人怎么吃河。

承平十一年秋，阳武县河工营，秫秸在册八百束，棚里实数不足五百；石灰在册三十石，墙根底下码着的不到二十；铁锅六口，册子新得发亮，伙房里只有四口，其中一口还缺着沿。河工营的人都知道这事，知道和不知道一样——贴书是文吏里最末一等的差事，无品无印，抄录画押都轮不到，他把亏空抄进册子，下一任贴书再把它抄一遍，三年五年，谁也不多问一句。

他前世在设计院画了八年图纸，画到工程师，穿到这副身体里三个月，倒学会了把疑问咽回肚子里。咽归咽，每晚收了册子，他还是把实数另记在一张桑皮纸上，卷细了，塞进铺草深处。

九月十九夜里，秋汛的洪峰先头到了。

雨下到二更，巡堤的梆子声一阵紧过一阵。陈默披着蓑衣，随队走背水坡，手里照例提着灯笼。他这三个月没资格上迎水坡，背水坡这一段，走到哪里有几丛草、哪块护坡石去年冬天换过，他心里比河堤图还清楚。

行至中段，他停住了。

脚下的渗水声不对。背水坡吃水，渗出来的应该是清的；此刻灯笼照下去，坡脚新起的细流浑得发黄，水里带着沙，细细地翻。他蹲下去掬了一把，沙粒沉在掌心，搓一搓，是堤心的壤土。

淘膛了。水已经在堤身里走成一条洞，沙是从自己脚下这一段被一粒一粒搬出来的。

他敲梆子三短一长——这是河工营约好的险工信号。信号刚落，前头两丈远，泥浆无声无息陷下去一个窝，簸箕大，浑水顶着气泡往外涌。背水坡跌窝。

人聚得很快，也很散。河工们不敢动，等官发话；官有两位，到了堤上，先争的不是怎么堵，是谁该站在哪个位置担这份干系。

阳武县丞卢勉是临时驻堤的文官，河堤真决了口，地方官首罪，他的脸在灯笼下泛青；管河主簿钱训才是这段堤的专管，物料、人丁、册子都在他手上，他站得离窝口远半步，这半步的距离陈默看得清清楚楚——真要追责，远半步就是"主簿在堤上调度"和"主簿亲临险段"的分别。

河老周满仓被人从窝棚里叫来。老人在堤上四十年，连蓑衣都披不利索了，听完水情，蹲在窝边抓了把泥搓开，鼻子里哼一声："贯穿洞。抛砖石是催它死，得灌泥浆——外坡打月堤围井，拌黏土浆往下灌，浆走洞眼，淤到哪儿堵到哪儿。封丘那年就是这么救的。"

"要多少物料，多少人？"卢勉急问。

周满仓报了一串：黏土要干、要过筛，秫秸若干，铁锅若干，外坡下水二十丁。

钱训立刻摇头："黏土过筛，等你筛完天都亮了。再说秫秸在册八百束，今日别处险段已领过料，本主簿拨不出这么多。"

陈默一直没说话。他在等这句"拨不出"。

他往前一步，先对着卢勉拱手，又对钱训拱手，把姿态做足了——贴书越职言事，规矩上先要把自己放到最低："二位大人，周老的古法能行，小的有三句补充，都是堤上现成之物，只求主簿下令、河老动手。"

钱训斜眼看他："你抄册子的，也懂堵口？"

"小的不懂堵口，小的只懂册子上都有什么。"陈默不卑不亢，"其一，黏土等不及晒干过筛——伙房有腌菜的粗盐，浆里拌盐，盐化得快，黏土遇盐在井水里散得开、沉得急，不会结成面疙瘩堵在井口。其二，秫秸不必只按埽料整捆投，裹上泥一层一层下，秫秸在水里散成筋，先替泥浆在洞眼里铺一层架子，料能省三成。其三，锅不必非要齐整的，伙房那口缺沿铁锅正好架在月堤边当槽子，浆顺着锅沿贴着水面倾，一条浊线直下井底，不被雨打散。"

堤上一时只剩雨声。

周满仓盯着他，喉头动了两下。老人堵了一辈子堤，盐促沉、秸裹泥这些门道，其实都在历代河工口传的零碎经验里，只是从没有人把三样东西在一刻钟里拼到一处，拼得这样合他一辈子的手感。

"盐能促沉……"老人喃喃重复，忽然一拍大腿，"使得！使得！老汉在封丘那年要是想起这一条，少死两个下水的弟兄！"

卢勉看向钱训。钱训的目光在陈默和那窝浑水之间来回。陈默知道他在算什么：下令堵，堵成了，功是主簿调度有方；堵不成，"听用贴书妄言"这六个字随时可以把他陈默推出去。这买卖对主簿不亏。

"准。"钱训到底吐出一个字，又补了一句给自己留路，"口谕是卢大人的，物料是册子上的，法子若误事，陈默，你自己担着。"

"小的担。"陈默躬身。二十板子和一座决口之间，他没有第二个选法。

人这才像水一样动起来。

周满仓带二十丁扑外坡打桩、垒土袋，月堤在河水里一节一节长出来；陈默不抢指挥，他只盯三样东西：盐秤够不够，秫秸裹泥的层理匀不匀，铁锅倾浆的角度对不对。这些是他的"图纸"，图纸不能自己长腿，得一句一句说进河工的手里：盐多了反苦、散不开，他让每锅只下两捧；秫秸裹泥裹松了，他蹲在雨里重新卷给人看；锅沿倾得太陡浆砸下去惊了井底，他摸出河工递的柴片卡在锅沿下垫平。

填到第三层，物料真的见底了。

"秫秸没了！"管料的河工抱着空账牌子喊。周满仓回身要争，一眼看见钱训的脸色，什么都明白了——在册八百束，实数只有四百多，中间的亏空平日躺在册子里养膘，今夜要整条堤替它偿命。

泥浆一停，井水的漩涡立刻大了，刚淤上的两层泥在晃。

陈默转头看向堤后的窝棚区。那里有河工营一百多号人睡觉隔潮的铺草，也是秫秸把子，也是官物——但册子上另有一条名目，动它，罪名叫"私拆官材"。

他没有自己喊拆。他走到卢勉面前，站在雨水里，把这笔交易明明白白摆出来："卢大人，防汛秫秸实数不足，册子上的亏空，过了今夜自会有人来查。眼下要续上泥浆，只能用窝棚铺草。拆，是为防决口的公调，求大人一句明谕在场众人作证；不拆，这一段堤撑不到四更。"

他把话停在这里，把抉择完完整整还给官。

卢勉的嘴唇哆嗦了一下。这位县丞未必看得懂跌窝，但看得懂"决口首罪"四个字。他转向钱训，声音发颤却很响："传本官府谕：河工营窝棚铺草，全数征用护堤，事后造册补给，造册补给——钱主簿，这句话你也听见了！"

"……听见了。"钱训咬着后槽牙。

铺草成捆抱上堤的时候，天东头已经透出灰白。最后一层泥浆倾下去，背水坡的浑流先是变浅，再是变细，等周满仓把手探进水里试了半天，抽出来，掌心是清的。

洞淤死了。

堤上没有欢呼，河工们横七竖八倒在泥里。卢勉被人扶着，站都站不稳，还在反复看那段刚塌过又被救回来的坡。

钱训是最后一个走过来的。他翻着物料册，翻到拆棚那一页，笔尖悬着，目光落在陈默身上，带着另一种提防：昨夜的亏空，是这个贴书当众逼卢勉点破的；"造册补给"四个字，又是当众落下来的。堤保住了，册子上的旧账却被掀开了一道口子。

"陈默。"主簿缓缓道，"私拆官材的罪名，府谕可以顶。可防汛秫秸实数不足，你一个贴书，夜里口口声声提什么'自会有人来查'——你抄了三个月册子，是不是还抄了些不该抄的东西？"

陈默心里一凛，面上不动："小的只抄大人让抄的数。"

"最好是这样。"钱训合上册子。

卢勉这时却摆了摆手，像没听出主簿话里的刀。他望着上游方向，那里水天相接处一片铅灰："洪峰后日到。昨夜这段，怎么堵的、用什么堵的，只有他全程在锅边。陈默戴罪留堤，后日再上这段——钱主簿，阳武县经不起第二回跌窝。"

这一次，钱训连反驳的余地都没有。堤上所有河工都听见了，是这个贴书守着锅把洞喂死的。真把人拿了，后日洪峰到了，谁下得了这个令？

陈默躬身应命，退下堤来。晨光里，他的窝棚只剩几根架子，铺草全上了堤。周满仓抱着半捆没投完的湿秫秸过来，往他手里一塞："后生，拿这个垫着睡。"又压低嗓子，"你昨夜逼着卢大人喊'造册补给'——这四个字，老汉在堤上四十年，头一回听当官的肯说。"

陈默抱着那捆湿秫秸，回头望了一眼物料房的方向。

后日洪峰。板子和罪名都悬着。册子上那四成亏空，从今夜起不再只是桑皮纸上的一行小字——它已经被几百号河工踩在脚下、抱上过堤。一个无品无印的贴书动不了账，但账自己开始怕人了。

他把桑皮纸在怀里按了按，朝缺沿铁锅走去，想趁天亮，把昨夜每一锅浆的盐数、层理、时辰，一样一样记下来。这些东西，今晚还得再用一次。
