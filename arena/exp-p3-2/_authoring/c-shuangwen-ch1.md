# 第001章 八钱银子的米

一粒米值多少钱，陆争用牙一咬就知道。

齿尖轻轻合上，脆响的是新谷，闷响的是陈米；咬开之后舌根先泛甜的是晒透了的，黏在臼齿上带着土腥的，是受过热又返了潮。这套本事不在账房先生的算盘上，在外院三年的汗里。九月十七，他蹲在万盛粮行的晒场上翻麦，把这粒牙白的新米吐回掌心，心里还在算这个月的账：月钱二百四十文，药铺的参须省了，改抓杏仁和桔梗，能余六十文。

六十文，是他接养母进城的路，又短了一寸。

"陆争！"老魏从码头方向小跑进来，草鞋拍得山响。这汉子是码头脚夫的头儿，肩上扛过的粮袋比陆争吃过的饭还多，上个月二掌柜克扣他们三成扛脚钱，是陆争拿着记了半个月的筹牌数，当着东家的面把账一笔一笔对回来的。老魏从此见他不叫小徒弟，叫先生，"前街过兵车，十二辆，冲着你们万盛来的。车上那口袋，我离着三丈就闻见味儿了——捂过。"

陆争站起身，拍掉膝上的麦芒："什么味儿？"

"捂被窝的味儿。"老魏压低嗓子，"小子，当心，这是拿霉米砸你们招牌来了。"

他话音没落，二掌柜钱有义已经站到了二门底下，酱色绸衫，袖口挽得一丝不苟："开中门。"

中门开，十二辆大车鱼贯进院。为首的军官翻身下马，动作利落，刀鞘上的泥点干得发白——连夜赶过路的人，才顾不上擦刀。陆争没看他的脸，先看他的手：左手虎口一道厚茧，指甲缝里嵌着洗不净的黑，是多年拉纤绳留下的。这人是从河边上熬上来的，不是荫出来的绣花枕头。

"赵百户。"钱有义拱手上前，笑得周全。

"钱二掌柜。"赵九成语气公事公办，马鞭往车上一点，"和籴新米一千二百石，八钱一石，府里的文书，定额在万盛。点袋，过秤，今日入库。"

院里几个学徒互相看了一眼。八钱。今夏好米，一两二钱都抢不到手。

钱有义脸上的笑一寸一寸往后收："赵百户，这价……"

"价是府里定的。"赵九成打断他，从怀里抽出一纸文书晃了晃，没递过去，"漕船过湖漂了三艘，窟窿在本户头上。三日后封仓，本户要交足三千石。临渠城七家粮行，万盛是头一块牌子，头一份，就先照顾你。签，还是要本户回去禀报府台，说万盛抗和籴？"

陆争看见钱有义袖中的手捏紧了。

抗和籴，封店拿人。这六个字砸下来，二掌柜的腰就软了一半。可一千二百石霉米八钱入账，回头官仓发热追下来，签字的人照样吃官司。钱有义的眼珠转了两圈，落在外院学徒身上。

"按规矩，得扦样。"他声音缓下来，"陆争，取扦筒。"

陆争心里跟明镜似的。扦样是学徒的手，好坏是学徒的嘴；真签了字，亏空摊进外院三人的月钱，他连六十文都余不下来。可他也没退，应了声"是"，去仓房取了铜扦筒、白瓷盘，又多拿了一样东西——半尺麻绳。

"军爷。"他在第一辆车正中的麻袋前站定，"小人扦三路，话也说在三路前头：扦出来什么，小人报什么。"

赵九成居高临下看他："报错了呢？"

"报错一个字，小人这只手，以后不碰万盛的米。"

第一扦走袋口。铜筒斜入，旋出，倒在瓷盘上——米粒细长干净，今年的新稻。钱有义的肩松了半分。

第二扦走袋腰。陆争手腕一翻，扦筒在袋心转了半圈才拔，这一筒出来，米就短了、乌了，两粒青霉夹在中间，刺得人眼疼。

第三扦走袋角。这一扦插得最深，他抽出来没急着倒，先闻，再摊：半筒糠粉，几粒米搓在指间，应手而碎。

"盖面。"他把三盘米在车前一字排开，拿麻绳比了比第一袋的袋口，"袋面新米一指厚，是给扦筒预备的；袋腰陈米，返过潮又急火翻晒，潮气封在米心；袋角这些，发过热，磨面喂鸡都不长肉。"他捏起一粒乌米咬开，搁在第二盘边，又碾碎一撮粉，"军爷，这米三日后入封官仓，仓里一捂，发热是整仓的事。到时候查册子，今日扦样的盘，签字的笔，按印的手，一个都跑不掉。"

满院无声。脚夫们放下了肩杠，钱有义的绸衫袖口垂着，一动不动。

赵九成脸上那点军爷的横气反倒收了。他蹲下来，盯着三盘米看了片刻，忽然问："你叫什么？"

"陆争。"

"几年的学徒？"

"三年，还差一年满师。"

"三年练出这张嘴，可惜了当个学徒。"赵九成站起身，声音压得只够车前几人听见，"本户跟你交句实底。漂没三船，赔补是本户头上的刀，三日期限是本户脖子上的绳。你万盛不收，恒裕、德昌总有一家的掌柜怕封店。米总归要脱手，本户今日不强塞——塞进去，三日后烧的是本户自己的手。可定额一千二百石好米，万盛一粒不能少。"

陆争迎着他的目光："好米按好米的规矩，验得过，万盛没有不收的道理。"

"说得轻巧。"赵九成冷笑，"三日之内，临渠城谁能一口气吐出一千二百石不掺水的好米？你家东家下乡收麦，人都不在城里。"

这句话他说得极轻，陆争的心却猛地一沉。东家不在，城里几家粮行的底牌，赵九成竟都摸过了。这人不是来耍横的，是算准了才进门的。

"所以本户把话放这儿。"赵九成翻身上马，马鞭虚虚点了点二掌柜，又点了点陆争，"三日后封仓，本户亲自来验。米足，事了；米不足，封店，第一个拿签字的掌柜，第二个——"他看着陆争，"拿你这张验米的嘴。"

骡车掉头，十二辆车出中门，车辙在晒场边碾出两道深沟。

人群散了。钱有义脸色青白，到底没敢说认栽的话，也没说谢，甩袖进了柜房。老魏凑过来，往陆争怀里塞了个热乎乎的烤红薯："先生，今日这口气，我们扛包的都看见了。"他朝车队离去的方向努努嘴，"我在码头上听得清楚，这姓赵的午后还要跑恒裕和德昌。要真被他各个击破，三日之后，城里就你们一家顶着。"

陆争掰开红薯，递回一半。他怀里还包着那三样扦样，油纸硌着胸口。

东家四日后才回。二掌柜不敢做主收米，也不敢硬顶军爷。恒裕、德昌若是软了，万盛就是露在水面上的最后一块石头。

"老魏哥。"他嚼着红薯，望着运河上密密的桅杆，"你帮我盯个事。赵九成的米，官仓进不去，这两日会往哪儿卸？"

老魏眨眨眼："码头的眼睛多，交给我。"

陆争点头。他还不知道三日后的米从哪里来，但他知道一件事——赵九成的刀是漂没，赵九成的绳是期限。要撑过这三日，不能只跟刀硬碰，得先找到那根绳，握在自己手里。
