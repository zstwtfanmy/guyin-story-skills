# 通用网文内容审查 Rubric

> 用途：当用户未指定番茄、起点、知乎盐言等目标平台时，作为 `/story-review` 的默认小说内容评分标准。它评估的是**故事文本质量**，不是 skill/plugin 实现质量。

## 评分方法

> 总则（任务书 §2.3/§2.4）：句长、标点、短段、破折号、普通词语等表面风格观察**不单独构成 finding**——须关联具体阅读失败（失真/重复/信息不清）才输出；质量以实际阅读体验为准，不以报警计数或预估指标自证。

每项按 PASS / WARN / FAIL 标记，并把 FAIL/WARN 转成统一 Findings Schema：
- 影响主线、角色动机、世界规则或读者信任 → S1
- 明显影响留存、节奏、章节效果或人物可信度 → S2
- 局部质量、格式、措辞、轻微节奏问题 → S3
- 风格建议或可选增强 → S4

## 核心维度

| 维度 | PASS | WARN | FAIL |
|---|---|---|---|
| 核心卖点 | 章节围绕明确卖点推进，读者知道为什么继续看 | 卖点存在但表达弱或被支线稀释 | 看不出本章服务什么卖点或主线 |
| 冲突推进 | 本章有冲突、阻碍、选择或代价；或是一段本身成立的相处/日常（关系与人物在其中变化或维持） | 冲突较轻，或相处有味道但与人物处境关联偏弱 | 大段解释/总结空转；闲聊既无关系信息也无相处趣味，只剩信息复述 |
| 任务卡点（仅评办事卡点场景） | 阻力及回应带来信息、关系、代价、选择或伏笔内容；无此场景标 N/A，不因相处无卡点扣分 | 已写卡点局部空转，须指出具体重复或节奏损失 | 流程堆砌挤掉应有体验，或阻力无因果；须给原文与具体损失，不要求补卡点 |
| 情绪曲线 | 平稳或变化都形成真实的人物体验；安稳相处不必升温或反转 | 局部体验空泛或转折支撑不足，须指出读者在哪失去感受或理解 | 持续空转或突兀转向，使人物感受失真、承接断裂；须指出具体损失，不因情绪平稳判失败 |
| 钩子与期待 | 读者有继续相处或看事态发展的理由，可来自人、关系、处境或悬念；不限定首尾位置 | 继续读的理由尚在但被局部重复或含混削弱，须指出位置与损失 | 既无成立的停留，也无可感的继续理由，须据原文说明何处空转；不因缺固定首尾钩子判失败 |
| 开头新鲜度（仅开篇/前 3 章） | 开局有具体人物/处境切口，不是同题材默认套路 | 有钩子但开局形状与同题材撞车 | 开局是题材默认模板，可整体换到任意同类书（同质化） |
| 角色动机 | 行为符合目标、性格、处境和关系压力 | 局部行为缺少铺垫 | 角色为推动剧情而失真 |
| 对话质量 | 对话有潜台词、信息控制和角色差异 | 有信息堆叠或声音略同质 | 对话像说明书，人人同腔 |
| 设定一致性 | 不违背既有规则、时间线和角色属性 | 有轻微模糊点需补证据 | 与已写设定或前文事实冲突 |
| 文字自然度 | 具体、可感；并能指出本章实质的**正面语言收益**（观察使人亲近、接话有分寸、信息次序改变意味、句段节奏贴合场面） | 偶有套话或抽象总结；或全篇顺畅但指不出一处语言收益 | AI 腔、陈词滥调、总结体明显；"无明显错误"不算 PASS |
| 句长节奏 | 句段随场面与注意力自然变化，长短各得其所 | 局部碎句/电报体或机械长短交替 | 通篇超短句像提纲，或通篇匀质长句读不出重点；不按统一句长规格裁判 |
| 标点节奏 | 标点跟语气、人物声线和情绪功能匹配；`……`/`——` 在真未竟/被截断处合法 | 局部标点单调或略有堆砌 | 通篇句号化、随机堆砌问号感叹号，或把省略号破折号当万能停顿 |
| 具体字数表达校验 | 「这五个字」「短短四字」类表达的字数经核对属实，且有叙事必要 | 字数属实但换成「那几个字」更自然 | 字数与实际不符，或无法确认统计口径 |
| 格式可读性 | 段落按戏剧单元/镜头自然断开，对话独立，无多余空行，主语节奏自然 | 局部段落偏长/偏碎或主语重复略多 | 大段堆叠、机械切段、对话/叙述难读、主语过密 |
| 剧情循环 | 外部线章：目标→阻碍→行动→代价/反馈→新期待闭环清晰；纯相处/过渡章标 N/A，不套此格 | 有循环但缺一环或反馈偏弱 | 外部线章无目标、无阻碍或无反馈，读者不知道局势如何变化 |
| 高潮构建（仅评承担高潮/交锋的片段） | 蓄能与兑现在本章尺度上有层次，代价真实 | 有爆点但蓄能或兑现不足 | 平铺直给、无代价、无兑现或情绪落空；**非高潮章不按"缺高潮/缺反转"判 FAIL** |
| 关系进展 | 互动尺度匹配关系阶段与各自处境；关系维持、原地深化、细微变化都算成立 | 局部变化略快但可补证据 | 突然亲密/信任/敌对，或把关系写成好感度跳档 |
| 伏笔状态 | 伏笔埋设、状态和回收路径可追踪 | 伏笔偏密/偏疏但不影响理解 | 伏笔与设定冲突、断线或造成主线理解混乱 |

## 黄金三问

1. **读者为什么翻下一页？** 如果答不出，至少 S2。
2. **本章改变了什么，或凭什么值得停留？** 外部线章看情节、关系、信息、情绪是否至少改变一项；相处/过渡章可以不改变——但那段相处或人物本身必须读着成立。既无变化也无成立的停留，才至少 S2。
3. **哪个证据支持你的判断？** 没有原文证据的 finding 不输出，改为“证据不足”。

## 发布建议门槛

| 综合情况 | Verdict |
|---|---|
| 无 S1/S2，S3 可快速处理 | APPROVE |
| 有 S2，或 S3 数量多影响阅读 | CONCERNS |
| 有 S1，或核心卖点/动机/规则崩坏 | REJECT |

## 输出要求

- 所有问题必须包含 severity、category、location、evidence、issue、fix。
- 先列 S1/S2，再列 S3/S4。
- 不要只给泛泛评价；每条 finding 必须能指导下一轮修改。
- `consistency` / `factual` 类 finding 的 fix 只写事实统一方向，不写文学创作建议。
