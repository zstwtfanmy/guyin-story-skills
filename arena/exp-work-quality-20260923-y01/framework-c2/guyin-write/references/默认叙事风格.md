# 默认叙事风格（框架默认审美单一来源）

> 本文件是默认文风 profile 的**唯一权威来源**。`SKILL.md` 只保留选择规则与本链接；写章时**只读所选的那一个 profile 定义**，不加载全表，也不加载本书名、全套教材与负面清单。
> 参照作品仅用于选题归因与品质方向研究：运行时只用下列通用叙事与语言特征，**不复刻任何在世作家的独特表达，不复制其人物、桥段、招牌句法**。两套参照不等同，不混成每章固定动作。
> 其余 profile 同样给出可直接加载的定义文本；尚非完成原文研究后的作者风格结论。

## 选择规则（严格按序，不逐章重选）

1. 用户本次明确指定特征或已确认书级 profile：采用它；与既有方向冲突时只确认本次改动范围，不重配全部材料。
2. **历史穿越、架空历史**且主要回报是时代生存/事业/群像：选 `historical-causal`。制度适配优先于附带的“爽文”标签。
3. 明确玄幻、仙侠、推理/悬疑、科幻、竞技、言情等**主题材**：选该题材 profile；副题材只补必要机制，不拼接两套句法。
4. 只说爽文、都市异能/重生逆袭、能力反差日常：选 `relationship-payoff`。
5. “穿越”只是装置，不自动等于历史：穿越修仙选仙侠，穿越恋爱选关系主线；只说穿越、无世界信息时，历史方向暂定并一句告知，用户可改。
6. 主题材完全未知：用 `character-causal` 作有明确特征的临时方向；缺世界/人物信息确实无法写时才提问，不因没有作者名阻断。

**稳定性**：选择随书存到 `设定/题材定位.md ## 叙事风格`；未获用户调整，不因一章打斗就换掉整本文风。仅要求临时试写时，选择只存本 run 的 `input.json`（style 段），不写正式设定。每次 run 把 profile ID、版本与 effective_features 冻结进 input——会话中本库升级不换声线；框架技能库 W 在书根 B 外，profile 不加入书根 baseline。

**加载边界**：只加载所选 profile 的「可加载定义」一段（不变成段长/句长配额）。用户书级文风优先，明确特征覆盖默认但不覆盖事实。作者性素材永远可缺省。对标研究可选：缺合法原文照用本文件特征并标「对标研究未验证」，不伪造切片。effective_features 必须**行动面与人面并取**：人面＝人物体验是否成立，事件内外皆可；关系型不得只冻行动标签，也不把人面误读成必须安排的非剧情时刻。

## 可加载定义（写章时只读所选的一段）

### relationship-payoff / v2

> 从人物眼下在意的事进入故事，让读者既愿意跟这个人相处，也愿意看其如何办事。能力通过具体观察、判断、行动与真实回应显出来，不要连续用旁人认证代替主角贡献；配角按自身利益和关系反应，不为成就主角统一降智。主角在“办事的人”之外还有“过日子的人”：会在小事上较真、自嘲、嘴馋或心软，对身边人有不兑换成剧情收益的反应——可独立成场，也可就在办事当口，不必另腾闲戏。内心不只写战术推演：私人的怕、委屈、得意、牵挂与自欺同样可写；直接展开、转述、自由间接体或物件带出，按本书视角与当段体验选用，不分高低，不统一压成“心想”标记或身体短拍。关系有摩擦与亲疏变化，日常相处、照应与拌嘴本身是阅读回报。幽默来源很宽：立场错位、身份反差、叙述者促狭的比喻（含跨时代影视梗、略带擦边的联想）都算数，书内梗优先——时代约束只管场景里的物件与常识，管不住叙述者的舌头；要求只是自然带出、不堆段子。允许心理、判断、较长对白与叙述调侃，句长和叙述距离随场景自然变化。该兑现时给清楚的行动与结果，冷却场保留人物生活，不把每章都写成“低调—误解—震惊”；节制章末判词，允许场景以动作、半句对白或未解释的物件收尾。这是叙事方向，不预定本章情节（研究状态：对标书原文未验证，以上为通用叙事机制，非作家风格复刻）。

### historical-causal / v1

> 让处境中的人先按生计、身份、利益、恐惧和关系作选择，再让选择进入更大的局势。主角纵有现代知识也受工艺、物资、人员、信用与制度约束；关键办法经过可信过程，不是说出概念就成功。配角有有限信息和自身算盘，不等着被启蒙。钱粮、地理、组织等必要细节放进办事、交易、争执与受阻，不整段讲资料。叙述清楚具体、语词合时代但不堆生僻官话；心理帮助理解选择，幽默来自人物与现实落差。损失与获得会改变后文，既写局势也保留人，不把严肃写成全篇沉重。

### character-causal / v1

> 先让每个人带着具体的所求和处境上场，行动必须碰到真实的人和事的回应，回应再改变他的关系或处境——故事就在这条因果链上走。叙述明白、有具体判断，少用空泛抒情替情节填空。对白要让读者听出身份、亲疏和此刻意图，不同人物说法不同。句长随场景自然，不刻意压成短句节奏。这个方向是给未分类题材的临时底座：先保证“人—行动—回应—变化”成立，等题材清晰后再沿同一规则换更精确的 profile。

### resource-cultivation / v1

> 写修炼先写资源账：每一步进益来自什么代价、风险多大、主角知道多少、不知道什么。机缘不能随手掉落，境界提升要有可看见的获得条件（材料、功法、情报、取舍）。世界规则在人物需要据此判断时讲清楚，和行动长在一起，不开设定课。行动过程要有辨识度——怎么探、怎么藏、怎么换、怎么赌，谨慎是权衡不是反复犹豫的重复内心戏。境界名词只标位置，不替过程：读者看见的是一次次具体抉择，不是一排排升级提示。

### adventure-growth / v1

> 每卷每段给主角一个清楚的外部目标，能力规则前后一致，试炼给出真实反馈（受伤、欠债、结盟、失去），伙伴各有本事与目的。成长体现为可选项变多、能承担的事变大，而非数字重复报涨。动作场面先交代空间、因果和利害，再写重点行动的展开，读者始终知道谁在对谁做什么、成败改变了什么。战利品与突破落在看得见的成果上，不用升级清单注水，也不让伙伴沦为喝彩工具。

### clue-revelation / v1

> 用线索推进调查：每条新证据都改变某人的假设，信息差在读者、主角、涉案者之间分层，期待从“差在哪一层”长出来。危险与谜底的关键节点都有前文可回查依据，不靠揭晓时临时补设定。有限视角保持具体而不晦涩；诡异氛围与调查并行，名词与仪式给出可感知的规则线索，不把术语密度当神秘感，也不靠末章长篇解释收场。

### systems-scifi / v1

> 技术不是布景，是改变人物选项的条件：每种新技术都写清谁受益、谁付代价、组织如何围绕它行动，技术后果与社会后果互相咬合。抽象概念落到一个可感知的行动上——一次操作、一场争执、一笔交易、一次失败。说明文字够用即止，奇观场面也要让人物动机穿得过去，不用大段宣言和设定演讲代替冲突。规模越大，越要写清普通人在系统里的位置与选择。

### pressure-team / v1

> 先把规则、位置与筹码交代清楚：受限条件是什么、队友各自能做什么、误判代价多大。惊险来自选择受限——信息不全、时间不够、规则互克，不是感叹号和“恐怖如斯”的堆叠。队友带各自判断与算盘，协作有摩擦、有交换，不是随用随到的道具。决策让读者跟得住：谁提的、为何采纳、谁反对，事后成败都有后文。

### professional-ensemble / v1

> 写职业场先写专业判断：每个关键操作都让外行也能看懂意图与得失——难在哪、好手凭什么判断、对手怎么反制。团队协作有分工与信息差，对手也有策略和临场调整，局势随比分/战况/项目进展真实变化。对白带身份与位置差异，术语用在操作上并就地讲清，不堆黑话撑专业感；赢要赢得可见，输也要输在具体环节。

### relationship-society / v1

> 感情在亲疏、体面、利益与家族处境的夹缝里长：每一次靠近或退让都同时牵动关系网络与现实利弊，男女双方始终保有自己的判断与目的，不为剧情牺牲主体性。对话本身携带关系信息（称呼、分寸、话外音），心理描写给具体的顾虑与权衡，不做泛化情绪宣告。衣食住行、家计往来的细节参与人物处境与选择，是活的生活而不是器物罗列式的“讲究”。

### intimacy-choice / v1

> 核心动力是亲近与自我保护之间的选择：每一次关系变化都要有共同经历作支撑——一起处理过什么具体的事，而不是误会叠误会。允许人物直说情感，也允许沉默，但拖延必须有具体理由（处境、心结、现实阻碍），不靠“听见一半就跑”之类无理由误会硬撑篇幅。对白自然、相处具体，写现代生活就用现代语感，不默认套用古言腔与端着的修辞。

## 原创对照示意（通用技法短例，非任何作家原文或仿写）

- 失效的能力爽感：“他一眼看穿骗局。所有人都震惊了。”
- 有行动与关系的方向：“伙计把两张送货单并在一起，压住掌柜伸过来的手。‘您先别夸我。两张都签了，明早搬货的还是我。’掌柜看了眼相同的车号，收回了手。”
- 失效的历史质感：“凭借现代知识，他轻松解决了缺粮的问题。”
- 有条件与后果的方向：“仓里有粮，车却归另一营管。那人肯借车，只是不肯借骡子。他把自己的坐骑牵过去，才知道今天送得走粮，明天就得步行去催下一批。”

## 回看校准

- 回看时按本次实际场景指出 profile 在哪些原文位置起效、哪里只剩口号；不要求每章特征全出现。
- 回看同样核对人面：体验在办事之中或之外是否成立；不查"非剧情时刻"配额，不强制冷却章。
- 初稿已符合方向且值得读：不加“文风修复轮”；语言泛化但剧情成立：只处理确有收益的段落；人物/事情本身无趣：先修叙事，不靠句法装饰救。
- 验收至少爽文、历史穿越各有一份经真实读者读过；其余 profile 先做路由与加载测试，未读验收标未验证。有名家参照不等于承诺写到同等水平。
