# 对话设计操作手册

> 写对话场景时按需加载。以下模式与数值是带条件的诊断选项，不是逐句验收或篇幅配额；书级 POV 与已冻结 profile 优先。相处、必要解释与长对白可本身成立，只有具体阅读损失才触发修改。

---

## 决策路由

| 你的对话场景是 | 用这种模式 | 操作 |
|-------------|---------|------|
| 主角碾压/打脸 | 压制模式 | 对方长篇大论 → 主角一字回应 |
| 主角亮底牌/反转 | 反转模式 | 对方嚣张 → 主角一句话事实 → 对方沉默 |
| 关系破裂/心死 | 心死模式 | 对话越回越短：从辩解 → 沉默 → "随意" |
| 日常互动/立人设 | 日常模式 | 写真实接话与相处，不强加冲突，也不禁止独白 |
| 群众震惊/弹幕 | 弹幕模式 | 递进：普通人震惊 → 专业人士分析 → 特殊身份者反应 |
| 信息展示/世界观 | 信息嵌入 | 用角色语气包裹信息，不是机械陈述设定 |
| 情绪拉扯/虐心 | 情绪推动 | 上行下行交替，像拉锯拉升期待 |

### 对话模式选择补充

| 对话类型与常见问题 | 诊断选项 |
|----------|---------|
| 问答式（读着像机械审讯时） | 可改为一方主动说，另一方回应；真在询问、愿意回答的一问一答可保留 |
| 冲突式（礼貌掩盖了应有压力时） | 可从委婉拒绝、命令否定到侮辱选择强度，不必逐级升级，不为加劲扭曲关系 |
| 日常对话（只有信息复述时） | 看是否缺真实接话、熟悉感或相处趣味；不以没有冲突认定为水 |
| 多人对话（指代或立场混乱时） | 理清各人所知与所求，可借信息/情绪/冲突功能定位，但不把人物缩成工具 |

## 对话核心判断

以整场体验判断是否值得保留，不要求每句单独完成任务。可观察：

1. **事态与理解**：信息、解释、选择或结果是否让读者更清楚
2. **期待与停留**：是否愿意继续看事态，或仅愿意多跟这些人相处
3. **人物与关系**：语气、闲聊、重复的熟悉话是否让人感到真实的亲疏与生活

情绪场景可检查承接、偏转、升级或退缩是否可信；不要求每句回应上一句的情绪。故意不接话、各想各的、延后回应都可能成立；只有读者因此误解人物或失去承接时才修，不逐句补动作/心理。

### 常见失效及限定

| 现象 | 何时需要处理 |
|------|------|
| 配角夸主角 | 无自身所知、利益或关系依据，只替主角认证时 |
| 互相解释读者已知信息 | 既无人物理解差异，也无情绪或相处收益，只重复时 |
| 大段说明式对话 | 超出人物知识/说话动机，或重复拖慢当前体验时；必要的完整解释不因长而删 |
| 角色说话方式相似 | 造成身份、立场或指代混淆时；熟人共享用语并非错误 |
| 对话说服人物 | 转变缺可信信息、利害、关系或心理依据时；有依据的说服可保留，不强换突发状况 |
| 情绪偏离预想 | 核对经历与转向依据；自然长出的方向不必回退，失真才修 |

## 权力博弈对话

### 适用条件

有意表现压制或权力反转时，可借长短反差：掌控者话短且冷静，被动者话多且情绪化。这是可选效果，不是身份定律；掌控者长谈、被动者沉默也可能更贴人。下列行数只示意节奏。

### 压制模式

结构：对方长篇大论（3-5 行）→ 主角一字回应。

```
"你以为你是什么东西？我告诉你，这个家轮不到你说话！你嫁进来的那天起就该明白自己的位置。"
"滚。"
```

### 反转模式

结构：对方嚣张（2-3 行）→ 主角亮底牌（1 行事实）→ 对方沉默。

```
"你有什么资格管？这是我家的钱，我想怎么花怎么花。"
"你妈的存折，密码是我的生日。"
```

### 心死模式

结构：对话越回越短，从辩解到沉默到「随意」。

```
"你听我解释，那天不是你想的那样。"
"嗯。"
"真的，我可以证明。"
"随意。"
```

### 操作选项（只在长短反差模式内参考）

- 亮底牌可试一句极短回应（如 10 字以内）；动作按场面需要保留，不为达标删字
- 被压制方可写较长辩解（如 20 字以上），也可沉默；长短不是通过阈值
- 只有场景确实呈现控制权时才借长度标记，不从字数反推谁更强

## 潜台词与议程

### 潜台词选项

- 隐瞒、试探或自我保护时，可让真实动机藏在借口后；坦白、说明与直说愿望同样合法
- 留意人物为自己辩解的方式，不假定所有人都在找借口
- 怀疑台词空泛时才追问动机与说法的差别，不要求每句都有双层设计

### 对话议程

- 可问各人为何进入这场对话：求信息、争利益，也可以只想陪伴或闲聊
- 议程碰撞是张力来源之一，不是所有对话的义务
- 同立场可以协作、确认理解、相互照应或安心相处；只有无体验收益的复述才压缩

### 语气由三要素决定

关系 × 场合 × 目的 = 语气

| 场合 | 特点 | 适合内容 |
|------|------|----------|
| 私人（单对单） | 深入、感情流露透彻 | 内心剖白、密谋、表白 |
| 公众 | 需考虑体面，措辞收敛 | 需要冲击力时可打破（如当众翻脸） |
| 熟人（朋友/同门） | 深度介于两者之间 | 轻松互动和信息交换 |

私密的话在公众场合说才有冲击力。对话中不能完全表达的内容，通过动作、神态、环境补充。

## 情绪推动对话

### 强情绪对话

- 命令式+否定式最能激发读者情绪："我说的还不够清楚吗？"
- 最强话术：打着为你好的幌子，句句不离关心，但句句都是嫌弃、指责、厌恶
- 直接否定比含蓄暗示更伤人

### 情绪连续性

转变要有可信的经历或认识支撑，可以渐变，也可以突然醒悟、强作平静或情绪反复；不按固定梯级验收。稳定的情绪同样可以有体验，不必制造波峰。

### 情绪四步法（承接不清时的诊断选项）

1. 遇到了什么：事件或原有处境
2. 有何感受：可直接写心理，也可由动作、表情、语言带出
3. 是否有需要呈现的思考：心理形式服从书级 POV，不要求显写；没思考也无需补一句“没有思考”
4. 如何回应：行动、言语、沉默或暂不行动是否可信

不要求四步齐全、依次出现或逐句补件；缺的是阅读所需的承接才补，留白或省略不自动算缺陷。

### 对话空转时的可选思路

- 若本来承担期待、爽感或悬念，检查核心驱动力是否真实在场
- 若信息交流本来受阻，让阻碍影响选择，而不是硬加误会
- 可用合理的意外打破预期，不为起伏扭曲人设
- 长对白可本身承载相处、解释或交锋，不必夹在爽点之间让读者“忍受”

## 信息展示与世界观引出

- 信息堆叠读着啰嗦时，可转为情节、心理、旁白、环境或动作；不按对话占比强换形式
- 用角色的语气和立场包裹信息，不是机械陈述设定
- 解释到足以理解当前经历与选择；需要完整前因后果时讲清，不为留白制造含混
- **避免工具化讲解**：核对说者为何讲、能知道多少、听者需要什么。必要且有实际阅读收益的整段解释可保留；压力下的半句话、身体反应与留白只是适用时的选项，不是统一碎片模板

### 信息拉扯示例（以"主角新书起飞了"为例）

| 角色 | 台词 | 功能 |
|------|------|------|
| 甲 | 听说成绩…… | 悬念拉期待 |
| 乙 | 肯定没人看！ | 下行 + 拉期待 |
| 甲 | 听说成绩很不错 | 上行 + 拉期待 |
| 乙 | 首订一万三？ | 展露核心信息 + 达成爽点 |

上行和下行交替，情绪像拉锯不断拉升期待。

## 人物语言差异化

每个角色要有自己的说话方式。对话时经常卡住不知道角色会说什么 → 人设模糊，去总结类似人设的说话方式。

| 差异化维度 | 操作 |
|------------|------|
| 口癖和惯用语 | 可从既有习惯提取，不要求每个主要角色配一个标志词 |
| 说话节奏 | 长篇大论 vs 短句连击 |
| 信息偏好 | 技术型带专业术语，江湖人带切口 |
| 立场习惯 | 留意悲观/乐观/务实等倾向，也允许经历与处境改变说法 |
| 身份影响措辞 | 老者/少年/贵族/市井，身份不同则措辞、自称、敬谦词不同 |
| 性格影响语气 | 智谋型话里有话；鲁莽型想到什么说什么；冷静型措辞精确，偶尔情感外露反而有冲击 |
| 进度影响态度 | 初见/熟悉/对立/亲密，关系阶段不同则语气与信息量不同 |

## 弹幕/群众对话

三大核心作用：剧情推进（透露主角不知道的信息）、增加期待感（悬念、猜测）、情绪渲染（群众震惊/激动/愤怒传染读者）。锦上添花，不代替主线。

### 设计过的弹幕 vs 没设计的

- 没设计：只有"卧槽好厉害"，单调、浪费
- 设计过：普通人震惊 → 专业人士分析 → 特殊身份者反应 → 情感升华

### 操作要点

- 不同人格化语气，不能每条都一个味
- 短小精悍，每条不超过一句话核心信息
- 善用递进：从最初震惊到逐渐认识全貌
- 可出现"反转"角色：看似路人一句话改变所有人认知
- 不用每章都写，关键爽点/燃点/泪点前后集中使用

## 节奏控制

### 大量对话保持节奏

- 不要删掉表现人物性格的语气助词来"精简"
- 对话段落间穿插动作描写、环境变化、心理活动调节节奏
- 紧张段落对话短促，舒缓段落可以长一些
- 关键信息放对话开头或结尾，中间用于拉扯情绪

### 动作和表情处理

- 刻意给每句对话配表情/动作会让行文机械
- 动作和表情在关键转折处使用效果最好，不需要每句都配
- 语气平淡场景（喝茶、散步）用微小动作和沉默体现氛围

### 对话的呼吸感

- 连续对话读着拥挤时，可插入环境或心理“换气”；连贯好读则不机械打断
- 动作、换行、短句可制造停顿，也可让长对白一气说完
- 需要压迫感时可试“你确定？”等短回应，不能替代本来需要的解释

---

## 篇幅控制

### 对话读着冗余时

- 读者已知、且不再带来人物或相处体验的信息可概括：“爱丽丝向安娜讲述了来城里的原因，安娜听后直皱眉头”
- 突发状况只在剧情本来需要时使用，不为缩短对白硬换事件
- 语气词承担声线与节奏，不以删后干瘪倒推必须重写；先找实际重复与停滞

### 对话读着不足时

- 若叙述跳过了值得听见的互动，可展开对白；必要概述或内心叙述不因无对白受罚
- 在场配角可参与交谈，也可只贡献生活与关系，不为凑比例新添人物或强配主线任务

## 以梗填充对话

### 梗式 vs 普通

- 普通："兄弟别灰心，你一步步走到今天我是看着你过来的，这点挫折对于你来说算什么事儿？振作起来！"
- 梗式："兄弟别灰心，我相信你总有人头落地，落地人头，头落地上……卧槽那句话怎么说的来着？兄弟你懂我意思是吧……"
- 梗式用"说不出来但意思到了"的状态制造趣味

### 操作

- 角色与场面适合时，可用梗或俏皮话增加趣味，不要求每段都逗笑
- 重要对话可用梗强化记忆点，普通而准确的话也能留下印象
- 若故事本来围绕一个有趣误会展开，可让梗成为高潮，不为造梗强扭剧情
- **场合与声线**：高压、生死、悲痛或严肃场面不一律禁玩笑；自嘲、苦笑、逞强可能正是此人的应对。核对它是否来自处境、是否冲淡应有分量或让读者出戏；确有损失才删改，不统一替成短冷反应，也不限定只能在安全处幽默

## 质量检查

### 三个诊断入口（不是命中即改）

- [ ] 大量信息交给对白后，是否超出人物所知或使读者难以理解？必要解释可保留
- [ ] 一问一答是否机械，还是此刻真实有效的交流？不因问答形式判错
- [ ] 对白带来的事件或人物变化是否可信？不因依赖对白而否决有效说服与相处

### 按场景选查，不逐项达标

- [ ] 权力博弈（适用时）：控制权是否可感？短长反差仅是工具，不验固定字数或强套模式
- [ ] 潜台词与议程：隐瞒或坦白是否符合处境？同立场能否形成真实协作或陪伴？
- [ ] 人物差异化：身份、语气与指代是否清楚？不要求每句遮名可辨
- [ ] 弹幕（适用时）：是否有真实信息差或不同反应？普通 → 专业 → 特殊身份仅是示例，不强凑三级
- [ ] 场景收益：事态推进、人物理解或安稳相处是否成立？不要求每段剧情前进
- [ ] 篇幅：单次对白占全节 40% 等比例只可提醒检查冗余，不是上限；必要解释、交锋和长谈按实际体验留足篇幅

### 检验对话质量

- 对白是否符合此人此刻的说话方式？口语、正式解释、长篇剖白均可，不统一改成短口语
- 结尾是否自然承接当下体验？可以平稳落下，不必预示节奏变化或补钩子
