# guyin-deslop：隐笔去AI味（隔离修订，不碰正式稿）

> AI 味的最终定义是"装"——过度圆滑、工整，把没发生的感受和没把握的判断写成流水线成品；改味不改错。**"解释充分"本身不是问题**：必要因果、背景、想法该讲就讲，只删重复的、夺走体验的解释。

## 前置：先有隔离 revision 候选

去味走 write/short-write 的 **revision run**：现稿复制进 `R/drafts/v0001.md`（目标/硬锁不变），改写只在 drafts 新版本。「去味」＝授权改候选，**≠授权覆盖正式正文**；正式稿只由 publish 凭独立发布授权安装。**不默认多加一轮**：至多一轮有假说的实质修订，净收益不足留较好初稿。

## 原则

1. **改味不是改错**；**改最少**：能改词不改句、能删句不重写段，人名/地名/数字/专名优先保留。
2. **只改怎么说，不改说什么**：剧情、人设、走向、逻辑不动。
3. **保留有功能的语气**：质问「？」、峰值「！」保留；功能正常的 `……/——` 逐字保留。
4. 不整段删；删前确认不含伏笔/钩子/角色特征/因果；删除上限 15%/25%/35%（轻/中/重），拿不准标 `[需复核]`。

## 两步流程（都对候选，不对正式稿）

### 第一步：lint（脚本只读不改盘）

```
node <guyin-write路径>/scripts/guyin-check-ai-patterns.js R/drafts/vNNNN.md
node <guyin-write路径>/scripts/guyin-normalize-punctuation.js R/drafts/vNNNN.md   # 默认逐字只读
```

ai-patterns 报警＝**待审清单**，永不自动删；停顿/打断是 editorial，功能标点保留。仅分隔线、用户明确的引号规格可 `normalize --write`（另存 vNNNN+1，旧版与正式正文不动）；风格报警进第二步。候选一改旧证据即失效。

### 第二步：陌生化改写（段落级手改）

按 [改写卡](../guyin-write/cards/改写卡.md) 定向，改完存新版本：

| 问题 | 方向 |
|---------|---------|
| 失真/成套话 | 命名无信息才补事件支撑 |
| 公共比喻 | 人物之眼：焦点物→角色行当（读 `设定/角色/`）→ 行当经验重写 |
| 重复信息 | 合并或删其一 |
| 对话公式 | 标签降频：动作引对话，普通"说"可留 |
| 段落均匀 | 按 beat 功能调长短 |
| 视角越界 | 按本书锁定的 POV 处理：第三有限落回可见可闻，多视角/全知转换给清晰叙述中心；不擅自给全书改视角 |
| 解释过头 | 只删重复解释与夺走体验的提前说明；必要因果、背景和人物想法保留，"解释充分"不单独定罪 |

## 收尾：重检 → 授权 → publish

最终候选**重跑完整检查链**（证据绑新哈希）：hard/verify 合法终态，editorial 留记录。复读改动区与承接，问题已消即可，**不以报警计数验收**（零报警=过度打磨）；报警多也不自动触发结构重写——先通读判断损失层级，措辞问题一轮改写解决，结构/POV/跨场因果失败且另获授权才走 L3 章改。拿到用户对**该稿哈希**的发布授权才 publish；未授权停 ready，正式正文一字不动。
