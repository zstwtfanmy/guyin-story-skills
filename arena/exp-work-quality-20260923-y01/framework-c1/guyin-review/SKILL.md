# guyin-review：隐笔审查（只诊断，不动刀）

> 显：见者惊犹鬼神之前，先有人替读者敲一遍门。审查是找问题，不是验证正确；诊断书不是处方——本技能一字不改正文/设定/追踪。

## 铁律

1. 永不修改正文/设定/大纲/追踪；唯一可写：对话报告 + 分批 state.md。
2. 每个 finding 必须有句位证据，无证据不报。
3. 疑似神来之笔**不报**，标「豁免候选」交五测试——合规系统不消灭变异。
4. 确定性预检只读：对**显式候选**经 candidate-context 跑章检（--project/--chapter/--boundary 齐），结果只作证据；零扫描/缺件/解析失败是 error，不能写「不适用」。文字报警段进[分诊卡](../guyin-write/cards/分诊卡.md)只看 ±2 行；架构视角完整章读不可省。
5. 审读未完成或主要阅读失败未处置不标合格；用户明示保留失败稿，报告记「用户保留，质量未通过」，不改写成质量认证。

## 唯一审查主体：当前会话

- **无模式菜单、无并行代理、无自动降级。** 当前会话串行完成收集与四视角；架构完整章读必做，角色对话可简不可省。
- 报告开头只保留两个 key：`Rubric` 与 `Rubric Source`（fanqie/qidian/zhihu/quality-rubric/内置）。
- `review.mode` 固定「当前会话全文回看」；证据绑候选 SHA-256，换稿即失效。

## 流程

**P1 收集**：定范围（缺省审最新稿）→ 读支撑材料（设定/角色卡/追踪/伏笔；气卡魂档案备合问不下发）→ 跑确定性预检（铁律 4）→ 定 rubric：平台读 `references/rubrics/{fanqie,qidian,zhihu}.md`，通用读 `quality-rubric.md`，不可读用内置基准并注明 Rubric Source。

**P2 四视角**（当前会话串行；P1 漏斗化）：

| 视角 | 执行形态 | 检查项 |
|------|---------|--------|
| 文字 | **漏斗式**：ai-patterns 全扫 → 报警段 ±2 行进[分诊卡](../guyin-write/cards/分诊卡.md) → 只对判为真问题的段深查 | 证据空=拿不准，进待审 |
| 一致性 | **脚本＋语义复核**：consistency/narrative-asset/tracking-state 先行，再通读事实归属、知情边界与跨章承接 | 脚本查实体/数字/F 编号；语义查"谁该知道什么、旧经历接住没、后果延续没"，冲突给句位证据 |
| 架构 | **完整章读**：先只读正文记真实理解，再核因果收益/人物是否仅配合剧情/读者为何继续，引前后句；钩子/主线/章尾信号仅辅助，**不得用脚本信号冒充语义阅读** | 无法完成全文读标「本章审读未验收」，不用投票/摘要替代 |
| 角色对话 | 当前会话就候选核 | 声线一致？潜台词？行为合动机？关系尺度匹配阶段？ |

**P3 综合**：合并去重 → severity 排序（S1 主线崩/读者信任崩；S2 明显影响效果；S3 局部；S4 建议）→ 分歧如实呈现，不自动妥协。

**P4 合问收尾**：逐条判这处是「**不够合**」还是「**不够合格**」——修合格是打磨，修合才显魂；并判豁免候选。

## 统一 Findings Schema（必用）

```yaml
- severity: S1 | S2 | S3 | S4
  category: structure | character | prose | consistency | format
  location: 文件:行号 或 章节/段落
  evidence: "原文证据"
  issue: "问题描述"
  fix: "可执行方向"
  level: L1 段改 | L2 beat 改 | L3 章改   # 对接大修分级
  handling: hard | verify | editorial     # 与脚本处置分类同口径；语义阅读项自定级
  candidate_sha256: "<被审候选完整 SHA-256>"
  source: "当前会话全文回看 | 脚本:<名>@参数 | rubric:<来源>"
```

输出三桶：① **修改清单**（按 level 分组）② **豁免候选**（→五测试）③ **AI 味集中区**（→guyin-deslop）。hard/verify findings 由写作会话转 `追踪/待审台账.md`（U1），未终态行阻塞写新章；editorial 留审读记录，不占豁免配额。

## 内置基准包（rubric 不可读时必用）

- 无卖点/只解释无冲突/无钩无期待/情绪平直 ≥S2；行为不合动机、事实冲突、关系越界无铺垫 S1/S2
- 说明书对话 ≥S2；AI 腔/陈词/章尾总结体/碎句电报 S2/S3；开篇撞模板 ≥S3（整体可换 S2）；卡点删了无损 ≥S3
- **形式中立**：直接心理、叙述评论、长概述、安静相处、破折号省略号本身不报；只在无承担时按具体损失定级。
- **正面收益须指认**：报告须指出本章语言/叙述的正面体验及句位（观察、接话分寸、信息次序、节奏）；指认不出如实写"无实质语言收益"，"无明显错误"不算好评。
- 剧作模板只评其适用的高潮/交锋片段；相处或低压章不按"缺高潮"判损。

## 分批审查（整卷/多篇）

维护 `.guyin-review/state.md`（范围/已完/下一批/未解决摘要/S1S2 计数），下批开头读回；非分批不创建。**收敛**：S1=0 且 S2 连续两轮零新增可附「建议收敛」。**预算与 write 对齐**：常规至多一轮有假说修订；"R4"是影响面分级（L1–L3），不是四轮润色额度；结构/POV/跨场因果回炉须另获目标、范围与追加授权，不靠改 run 名续轮。
