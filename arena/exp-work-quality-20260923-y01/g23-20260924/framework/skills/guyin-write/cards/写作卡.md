# 写作辅助清单（cards/写作卡.md）——开写前自取

> 可选。用途：材料杂时快速核对「锁、事实、承接」是否备齐。它不是简报模板，不向谁下发，不规定场次/字数/感官；正式冻结以 `R/input.json` 为准。

## 开写前对照

- **目标**：kind（long/short）、章号/单元、title、mode（append/revision）、篇幅上下界。
- **授权**：写作授权有没有？选稿/发布授权是 null 还是带来源原话？「试写」默认无发布权。
- **不可擅改（只填带来源的）**：
  - 已发布事实与遗留实物处置；
  - exact/semantic/forbidden 锁，每条能指到用户原话或已发布文件；
  - 知情/保密边界、禁止提前释放项。
  - 自己觉得「该保留」的东西不进锁，它只是工作假说。
- **这一章的工作假说（可被成稿替换）**：相关人物各自想要什么、知道什么、凭什么能做；可能成立的体验（处境与行动，不写情绪词）；起点、变化、与下一章的承接。
- **必要材料**：相关前文原文（需要因果时读角色状态、承诺与相关原文，不只读最后 300 字）、本章相关角色状态、书级文风 profile（ID/版本/特征要冻结进 input）。
- **缺料处理**：关键材料不足就停下去补，不伪装正文、不杜撰万能解法。

## 自由与边界

台词、动作细节、节奏、心理、幽默、局部走向、场次与收尾由你决定；未锁定处不必请示。能力要有依据，配角按自己的目的行动，不靠降智制造爽感。
