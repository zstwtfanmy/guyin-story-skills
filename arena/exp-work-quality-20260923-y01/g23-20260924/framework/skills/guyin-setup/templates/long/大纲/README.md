# 大纲

> 卷纲_第X卷.md + 细纲_第NNN章.md，**都是可选规划件**：没有完整细纲也可以起笔，锁与事实从用户原话和已发布正文提取并冻结进 run input。
> 细纲存在时：前三组是工作假说（成稿可替换），第四组才是带来源硬锁；beat 只是节奏标签——细纲文件禁把场景切分写成格式，也禁情节点逐条字数配额。
> 书级叙事方向（profile）不在本目录，记在 `../设定/题材定位.md ## 叙事风格`，定义唯一来源是技能库 `guyin-write/references/默认叙事风格.md`；本目录只放格式约定，不复制审美规则。

## 细纲四组速查（仅当你实际创建/修订完整细纲时适用）

字段定义唯一权威在技能库 [guyin-write/references/细纲协议.md]（本表仅速查，老项目同样读得到）。**没有完整细纲时下列检查一律“不适用”，不造四组过门：**

| 槽位 | 级别 | 一行式要求 |
|------|------|-----------|
| 四组区块 | hard | ①本章可能交付什么（核心事件/阶段位置/读者承诺/收益归属/字数目标/术语锚点；假说）②人为何这样行动（假说）③场景如何承接（假说）④哪些不能擅改（仅带来源硬锁：已发生事实/知情边界/保密项/禁止提前释放/锁定结果/资产档位/复沓锚句）——完整细纲缺组即拦 |
| 读者承诺 | hard | 第一组行存在且非空：写产生体验的处境与行动，不填情绪词不写口号；是方向不是交货合同。ch001-003 且存在完整细纲时行值含开篇入口三件事（当下目标/入口体验/近期回报，opening-retention 查） |
| 字数目标 | hard | 行存在且含数字（单值 T 或区间 X-Y 均合法，全角－～也认）；有细纲时章检下限双口径：区间取下限 X、单值取 T×90%；无细纲时以 run input 冻结的 wordcount 为准。内容撑不起长度修设计，禁止填水 |
| 禁止提前释放 | hard | 行存在（值可「无」）——防「靠卷纲兜底」的隐性放空 |
| 复沓锚句 | hard | 字段行存在（值可「无」）；仅限世界内实体语句，作者性语句禁登记；须一字不差进正文（outline-deliver 查落地，R1） |
| 资产影响档位 | hard | 引用既往章/事件必填（值含 0/1/2）；档 2 须同章补偿声明+作者确认（outline-verdict 仲裁） |
| 术语锚点 | 提醒 | 字段行存在；新术语在对白或叙述中清楚引入即可，不强制对白首现（outline-deliver 查是否真实进入文本） |
| 场景序列 | 硬组内 | 第三组行存在：每场一行起点/意图/行动可能/前后变化/承接；不预写逐句动作，不要求每场反转冲突；单场长对话、安静日常均可成立 |
| 写作指令区 | 无硬门 | 区可以缺（值可「无」，≤5 行）：工序提示收进本区——**区内容禁入正文**（authority-leak 拦）；批次不变量上移批次公约 |
| 执行偏差（检测驱动回填） | 提醒 | 区必须在、值可「无」：变体（假说被替换不违约）/未落实（仅第四组硬锁未兑现才算违约，必含顺延章号）/弃用（硬锁须用户裁决）；ready 章检后按 outline-deliver 检测回填；tracking-commit 提交时缺区/未落实无章号 stderr 提醒不阻断 |

已废除槽位（不再检查，存量不追溯）：章尾钩子五型/实体/承接、场景与对手戏下限、多线节拍（情节安排节）、情绪落点 ≥3、时序自检三查行、契约风险结论行、涉及场景清单、情节点序列与 Σ 配平、黄金三章四留存字段（并入第一组读者承诺）、台词级术语首现强制。`guyin-check-hook-rotation.js` 为旧格式存量细纲兼容工具。

细纲落盘前（仅新建/修订完整细纲时）：`guyin-check-outline-slots.js`（四组齐备+保留行）+ `guyin-check-authority-leak.js`（工序/作者性字面）+ `guyin-check-outline-verdict.js`（资产档位）；ready 对候选跑 `guyin-check-outline-deliver.js`（exact 锚句落地/术语进入文本/跨章签名句归属，R1/K2）＋ `guyin-check-strip.js`（成稿剥离门：多标题/大纲尾巴 hard、工序词泄漏 verify，K3）。工艺词入叙述层字段须括注叙述者措辞（如「社会脸（写成：…）」）。

## 资产影响档位（细纲声明行，引用既往章/事件时必填）

细纲引用既往章节编号或已登记事件名（如「复盘旧局（ch3）」，含「不是A，是B」翻转句与全称量词复盘表述）时，必须有档位声明行——高潮/爽点章兑付给读者的情感是**已支付的资产**，没收（否定前文高潮）必须显式声明并支付代价。落盘前由 `guyin-check-outline-verdict.js` 机械仲裁，缺声明即拦。

| 档 | 定义 | 支付条件 |
|----|------|---------|
| 0 纯叠加 | 既往关键事件定性不变，新信息叠加 | 无 |
| 1 部分动用 | 事件部分维度重估，资产重定价不没收 | 无 |
| 2 全盘否定 | 事件定性被推翻，资产没收 | 同章兑付等值或超值补偿 + 作者确认，缺一阻断 |

- 声明行写法：`资产影响档位：1 部分动用——重估说明一句`（示例：`资产影响档位：1 部分动用——重估拆神那局（ch26-27）：赢是真的，被利用的是专注度`）；档 2 声明行内须写明「补偿」及补偿方式；
- 辅助字段（行动成本/人心节拍等）含限定语（如「认它一半是送的」）而场景序列为全盘表述 → 档位冲突，停作者仲裁，机械判档不替作者定性。
