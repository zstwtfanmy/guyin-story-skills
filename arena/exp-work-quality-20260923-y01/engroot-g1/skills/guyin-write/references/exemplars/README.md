# 范文切片库（references/exemplars/，可选研究资产）

> 2026-09 v4：默认叙事方向由 profile 提供（见 `../默认叙事风格.md`），**本库不再默认注入任何一章**；仅当当前会话主动要找“这种场景怎么写”的手感参照时按需查阅。
> 合法原文研究是可选项，不是开写前置：缺真实切片时照用 profile 明确特征，全程标「对标研究未验证」，不伪造原文切片。

## 取弹路由（v3-B4：功能优先，不是题材文件名优先）

「范文手感」取片按三层匹配，**不以文件名字符串作为唯一确定性路由**：

1. **本场景功能**（对话/动作/氛围/峰值/闲笔——按切片用途标签）；
2. **视角**（POV 与叙述距离：第一/第三有限/全知）；
3. **叙述距离**（贴身感官/中景/概述）。

题材是**辅助条件**：同题材不同场景不匹配不用；跨题材同机制（同场景功能＋相近叙述距离）可用。三层都无匹配 → 不用片：回 profile 定义与当下场景直接写，**不伪造「原文已补齐」**。

规格口径：库存切片 500-1000 字，按需截取功能最相关段；它只作参照，不作每章配额。

## 三参照声明（用户质量参照，如实状态）

《隐杀》《晚明》《铁血残明》**分别**是用户的质量参照——后两者不可合并成一个「历史种田风格」。当前状态：**未完成三书原文对标研究**，未得到其成功公式，本库无三本具名切片（无具名切片 ≠ 无可迁移样本，见「当前库存」表）。对标研究完成前，任何产物不得冒充已提取其机制。

## 对标材料应回答的机制问题（v3-B4，拆文/对标产物的验收问题）

对标材料的价值在**可迁移机制**，不是给范文换书名：

- 能力与生活关系如何共存（主角的日常如何与能力/事业交织）
- 信息差如何产生期待（谁知道什么、读者知道什么、差在哪一层）
- 利益和制度如何限制选择（人物为什么不能直接拿最优解）
- 资源/组织如何形成后果（钱、人、机构的来去如何推动事件）

历史战争类还需：有依据的制度、兵粮、地理与社会经验材料；心理/关系类还需：动机、经历与关系阶段。这些进设定/角色/对标来源，**不靠更多感官描写替代**。

## 采集协议

| 项 | 规则 |
|----|------|
| 来源 | 用户**合法持有**的对标书原文（通常在 `拆文库/{书名}/原文/`，拆文完成后采集）；切片元信息登记拆文库真实路径，`对标/` 若有副本只是手动复制、不自动同步，库存状态以拆文库原件为准；拆文前的默认弹药见下节 |
| 数量 | 每题材 3-5 段，每段 500-1000 字成品切片 |
| 选择标准 | 不是摘抄好句，是**手感样本**：对话场景 / 动作场景 / 氛围铺陈 / 情绪峰值 / 闲笔，各至少 1 段 |
| 切片纪律 | 切片只供当前会话参照节奏（心里有数即可，不复制措辞）；本库随项目保存，**勿公开分发原文切片** |
| 更新 | 完全可选：用户提供合法原文或明确要求研究时才采集；对标书更换时重采；不设开书必采、首批细纲前必补 |

## 文件格式（每题材一份 `{题材}.md`）

```markdown
# {题材} 范文切片库

## 元信息
对标书：《{书名}》（作者）· 采集自 拆文库/{书名}/原文/
采集日期：YYYY-MM-DD · 切片数：N

## 切片
### 切片1：{场景类型}｜{用途标签：开场/对话/动作/氛围/峰值/闲笔}
> {500-1000 字原文切片}

### 切片2：……

## 好坏对照例（改写卡/陌生化取用）

对照只比较**阅读损失**，不建立"直接情绪坏、身体动作好"之类的默认等级：同一个情绪，直陈、转述、动作、环境都可能成立或失效，判据是它有没有属于此人此刻的内容。

### 对照1：抽象情绪如何落地
失效例：{贴情绪词而无个人内容的句子，说明损失在哪}
有效例：{同一处境下，用此人的想法或其行当/经历中的动作把情绪落地的写法，说明为何有效}

### 对照2：公共比喻 → 人物之眼
失效例：{公共比喻句}
有效例：{用角色行当经验重写}

> 注：有效例只是该场景的一种选择，不得读作"凡情绪都必须改写成身体动作"；需要让读者理解人物为何在意时，直接展开心理常常才是对的写法。
```

## 旧仿写切片（保留存档，不再默认注入）

气质三角等作品的**仿写切片**（非原文誊录）：v4 起从“默认弹药”改为按需存档——写章不再自动加载，只有主动查库时才参考。规则：

- 定位是**可选参照**，不是开写前提，也不是对标采集的替代品；用户提供合法原文后可按采集协议补真实切片，真实切片优先；
- 仿写切片只学节奏与镜头；
- **标记不升格（E2）**：无合法原文研究前，仿写切片永远标「仿写」、该书在任何产物里保持「对标未验证」；补到真实切片后才可改标，不得把仿写当原作证据或倒推名作公式。

## 体感粒度（Z6，按需参考）

`体感粒度.md` 按**感觉 × 粒度**（紧张/悲伤/释然，各三种分辨率：粗/中/细）组织，仅在想核对“这场展开到什么粒度”时翻阅：

- 它是创作判断的参照，不是必走步骤；没有 beat/情绪目标配额，不强制峰值取片。
- 学的是动作/身体/环境三层各到什么程度，不抄样本措辞。
