# 作者性引导（可选私人素材采集）

> 2026-09 v4：默认审美由 profile 承担（见 [默认叙事风格.md](默认叙事风格.md)）。本引导**只在用户想提供私人素材时**使用——不阻断开书、不阻断写章、状态诊断不把作者性列为缺件。
> 三原则：**一次只问一件**（不甩问卷）；**问生活不问文学**；**不设任何默认档**——用户不认领的字段一律留空，模型不得代填、不得用作家三角合成、不追讨、不规定回填时间。
> 私人素材写成**倾向**，不写成配额：没有“每章 N 处闲笔/每句 N 字/卷末必刷气句”这类硬指标；句长、段长、闲笔数量永远不是检查项。

## 何时触发

- 用户主动说「定作者性」「填作者性」「聊聊我的口味」；
- 用户想在 profile 之上加入个人表达偏好。
- 开书、状态诊断、写章循环**都不触发**本引导；profile 选定即可起笔。

## 逐件引导（每件独立，可随时停，可全跳过）

### 气卡（气句 / 底色 / 收放倾向）

- 开场：「不聊文风，聊口味——这本书读起来该是什么心情？」
- 用户想不出时可参考 [模板内 参考-气质谱系.md](../../guyin-setup/templates/long/作者性/参考-气质谱系.md) 的启思线索，但**必须用自己的话重说**；说不出就整项留空。
- 落盘到 `气卡.md`，注「（口述定稿 YYYY-MM-DD）」；空着合法。

### 指纹（比喻域 / 镜头等个人偏好）

- 只聊用户真有感觉的参数：熟悉的行当、第一笔喜欢给物还是给脸。
- 闲笔、标点等：用户主动提才记，写“倾向于……”，不给固定处数与字数之类默认数字。
- 落盘到 `指纹.md`。

### 偏执点（用户亲口死守的怪规矩，≤2 条）

- 问法：「有没有想让这本书从头到尾死守的怪规矩？没有也没关系。」
- 只登记用户亲口说出的（哪怕“情绪可直说”“峰值可用长句”）；模型不提供候选项让其圈选。用户规则整条压过默认 profile 的通用倾向，去味与编辑不得越过；与已发布事实冲突时提请用户裁决。
- 落盘到 `偏执点.md`。

### 魂档案（一生之问 / 私人切口）

- **永久没有默认值**，只能从用户身上长出来。
- 「这几年反复在想、绕不开的一个问题？」「你亲身见过、别人编不出来的一个瞬间？」
- 答不出：留空。这是常态，不是缺失，不设回填期限、不章尾提醒。

## 落盘与读取纪律

- 凡口述值注「（口述定稿 YYYY-MM-DD）」；没有“默认档”标注了——模型代填的默认值一律不产生。
- 已落盘的私人素材：写章时作为书级文风的一部分按需参考；profile 特征与私人倾向冲突时，以用户明确认领者优先。
- 作者性文件被正文照抄仍是泄漏（把创作工序语/私人气句写进人物世界），由 authority-leak 检查——文件可选不代表泄漏门关闭。

## 对话样例（参考语气，不是脚本）

> AI：不聊文风，聊口味——这本书读起来该是什么心情？
> 作者：账要算，但不着急那种。
> AI：用你更日常的说法再收一收？
> 作者：账都记着呢，不急着翻。
> AI：（落盘气句：「账都记着呢，不急着翻。」（口述定稿 2026-09-20））其余的底色、句长这些没有想法就都留空，不影响开写。
