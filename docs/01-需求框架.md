# 隐笔 · 需求框架 v0.2

> 本文档定义重铸后的写作框架「隐笔」的需求边界与核心机制。
> 来源：对 oh-story-claudecode 的完整分析 + 五轮设计推演 + 三轮哲学深挖，自包含可独立阅读。
> 魂：以天合天——笔不造文，隐术显天（§4.0）。

---

## 1. 背景与来源

- **上游项目**：[worldwonderer/oh-story-claudecode](https://github.com/worldwonderer/oh-story-claudecode)（5.6k stars），网文写作 skill 包：13 skills + 7 agents + 7 hooks + 100+ 份 references 方法论，核心理念"套路 = 确定性的情绪满足"，流水线为 扫榜 → 拆文 → 写作 → 去AI味 → 审查 → 封面。
- **本地仓库**：zstwtfanmy/oh-story-claudecode（fork，已落后上游约一个月，动工前必须先 sync）。
- **重铸动机**：产出"生硬"。诊断结论：不是 prompt 措辞问题，是结构性问题；修补不可行，需换地基。

## 2. 问题诊断：为什么生硬

生硬不是 bug，是原项目设计哲学的必然产物。六个结构性根源：

| # | 根源 | 表现 | 后果 |
|---|------|------|------|
| 1 | **指令过载** | SKILL.md 649 行；单章 13 步、写前 7 个召回子步骤、14 类上下文 | 模型带宽被"合规"吃掉，文本呈 KPI 完成感 |
| 2 | **参数化风格** | 文风拆成句长/标点参数，题材拆成 32 张腔调卡 | 产出题材均值文风，即"平均风格" |
| 3 | **负面清单去AI味** | 禁用词表 + 句式黑名单 + 脚本扫 blocking | 打地鼠；大量禁令令模型趋向保守，保守即生硬 |
| 4 | **模块拼装** | "用模块组装，不要重新发明" | 模块边界可感知，缺"从人物内部长出来"的有机感 |
| 5 | **一次成稿 + 扫描修补** | 细纲填表 → 一次写完 → 字数验证 → 词级替换 | 没有"写-读-改"过程；结构性生硬后处理去不掉 |
| 6 | **文气断裂** | 写手 agent 只见"本章材料包"，7 agent 各管一段 | 每章重新起笔；无人对"整本书读起来怎么样"负责 |

## 4. 设计哲学

五层一以贯之，从玄到真：**魂 → 纲 → 目 → 法 → 用**。

### 4.0 魂：以天合天

> 作品不是造出来的，是合出来的。一个天是**作者之天**（活过的生命、一生之问、他的真），另一个天是**万物之天**（类型的永恒渴望、世界自生长的天性、人人心里的常情）。作品只存在于两天相合之处——框架的职责不是造文，是**不挡光**。

原典：梓庆削木为鐻，“见者惊犹鬼神”。斋三日忘庆赏爵禄（市场），斋五日忘非誉巧拙（评价），斋七日忘手艺本身（术隐）；而后入山林观天性，“成见鐻”（形态已在，非雕凿所得），“加手焉，不然则已”（轻做，不硬造），“以天合天”。西方同行殊途同归：poiesis 是“让显现”而非制造（海德格尔）；天才的规则不可言明、不可传授（康德）；AI 的哲学学名是 super-fancy——无限重组而无生成（柯勒律治：fancy vs imagination）。

### 4.1 纲：创作哲学十条

每条必须有机制住址，没有住址的理念不进流程：

| # | 理念 | 机制住址 |
|---|---|---|
| 1 | **玄极而真**：挖到最深的不是玄而是真 | 全框架：一切机制只做保真、转真、显真 |
| 2 | **真在内者，神动于外**：动人不是技巧的结果 | 守工灵神四层全部是“不挡光”的不同纯度 |
| 3 | **宁要漏出来的糙，不要表演出的好**：AI 味的最终定义是“装” | 糙感保留（§7.6）；lint 只清确定性错误 |
| 4 | **作品是镜子不是工厂**：共鸣是被唤醒的 | 口述采集（§7.5）给镜子加水银 |
| 5 | **伟大是必然分泌物**：作品是生命被穿透后的分泌物 | 选择即作者性；框架一滴不浪费地接上作者的生命 |
| 6 | **魂×皮，永恒为体时代为门**：迎合时代的与时代同朽 | 魂档案（§7.7）；十年测试（§7.7） |
| 7 | **类型即仪式，经纬合魂**：类型是永恒渴望的容器 | 类型魂谱 × 作者魂档案（§7.7） |
| 8 | **气不可造，只可养**：魂×世界=气 | 气的三栖息地（§7.4）；永不下发任务卡 |
| 9 | **豁免是生殖道**：合规系统消灭变异，进化系统保护有利变异 | 豁免机制（§7.8）；checker 永不自动删 |
| 10 | **选择即显影，隐笔无形**：魂从一次次选择里显影 | 多采样外选 + 合问判词（§7.8 / 02 §6） |

### 4.2 目：工程哲学四条（十条的工程投影）

1. **框架智能替代模型智能**——“隐术显天”的工程表述：低模型是工人不是作家，作家的智力住在框架和任务卡里。执行层永远不接触全局。
2. **从合规工厂到作家工作台**——“不挡光”的工程表述：约束管下限，示范和过程管上限。确定性规则交给脚本，模糊性文采交给范例和重写。
3. **确定性管下限，发散性管上限，台账让灵感变资产**——“养”的工程表述：细纲骨架保持确定，beat 内部开放灵感；灵感产物登记台账、可转正进细纲形成复利。
4. **选择即作者性（curation is authorship）**——“必然分泌物”的工程表述：AI 生产方差，作者做选择（选质感源、定偏执点、挑灵感、口述真经验）。作者不需要写作功力，需要活过 + 品味。

### 4.3 法：康德红线

> 天才的规则不可言明、不可传授（《判断力批判》§47）。**能显式化的是工艺，不能显式化的是天才。**

军规“技巧显式化”止步于工层（L1，§8 对照表全部属于工层）；灵、神两层（L2/L3）只**养**（气、台账、魂谱）、只**选**（外选、合问）、只**豁免**（五测试），永不显式化。oh-story 的哲学死因恰在此：它试图把天才也工艺化（参数化文风、32 张腔调卡）。

### 4.4 用：操作化身（双语制）

魂语言给人读，操作化身给编排层执行——**每个魂概念必须成对出生**，缺操作化身的理念不进流程（进流程即成标语）。低模型对哲学 100% 隐形、100% 在场：它从不读到哲学词语，但它填的每张卡都是哲学的蒸馏——范文=观，就近禁令=斋，细纲=合，好坏对照例=显。

| 魂语言 | 操作化身（编排层直接执行，无需理解） |
|---|---|
| 以天合天 / 合问 | 三形态是非题：外选“哪版更接近气句” / 细纲“推进事件还是加深追问” / 验收“更合，还是只是更合格” |
| 气 | 气卡三字段：气句一句 + 底色（暖/冷/涩）+ 收放；开书口述生成，每 N 卷复述刷新 |
| 魂档案 | 固定字段：一生之问 / 私人切口 / 历次气句 / 回响收编 |
| 类型魂谱 | 固定字段：核心渴望 / 核心恐惧 / 经典叩问 / 隔代同构书目 |
| 豁免 | 五测试是非题（§7.8）+ 四步流程 + 台账字段 |
| 同魂不同皮 | 封神盲评问卷：“三本书是否同一人所写？他一直在写什么？” |
| 十年测试 | 剥离清单（梗/热词/即时情绪/套路 → 中性替换）+ 复测细节留存 |

## 5. 硬约束：低模型执行层

**执行层锁定 deepseek-flash 级入门模型**（商业可行性：日更数千字，高级模型成本不成立）。低模型行为特性及应对：

| 低模型特性 | 应对军规 |
|-----------|---------|
| 长上下文利用率差（lost in the middle） | 就近约束，卡尾复述关键禁令 |
| 多指令遵循弱，10 条只能稳定执行前 2-3 条 | 单轮单职责，一次只写一个 beat |
| 隐式推理弱 | 机械判据替代语义判断；技巧显式化（见 §8） |
| 发散质量低但可用 | 5选1带分类提示；多采样外选 |
| 开放自评必敷衍 | 是非题自检卡，逐项答并附句位 |
| 长输出指令漂移 | 输出单位 ≤1500 字，章由 beat 拼接 |
| 上下文内事实保持差 | 外部状态一切：每步落盘、下一步读盘 |
| 模仿与补全远强于创造 | 填空优于生成；示例即规范（few-shot 是最大杠杆） |
| 便宜 | 多抽 3-5 次外部挑优——"量弥补质"是灵气的低配实现通道 |

### 编排/执行分离架构

```
编排层（主会话 / 强模型 / 框架逻辑）
  拆任务 · 组装任务卡 · 维护状态 · 判定模式 · 验收
        │  只下发"当前这一张卡"
        ▼
执行层（deepseek-flash）
  填空式写作，一次一个 beat，永不见全局
```

## 6. 总体架构：四层 + Arena

| 层 | 工序 | 名称 | 目标 | 核心机制 |
|----|------|------|------|---------|
| L0 | 斋 | 守（底线层） | 不翻车 | 删掉一切毁真之物：文件状态分层 + 护栏 hook + 一致性 checker |
| L1 | 观 | 工（工艺层） | 不生硬 | 入传统观天性：范文教学、声线连续、重写回路、两遍生成 |
| L2 | 合 | 灵（灵性层） | 有灵气 | 以天合天：六个灵感装置、Craft/Muse 双模式、灵感台账、养气 |
| L3 | 显 | 神（作者性层） | 有人味有辨识度 | 真动于外：魂档案、质感供弹、作者指纹、偏执点、口述采集、糙感保留、豁免 |
| — | — | Arena | 节奏载体 | 每阶段一场擂台（判词：合问），基线滚动 |

## 7. 核心机制规格

### 7.1 弱模型军规十条

1. **单轮单职责**：一次只写一个 beat（500-1500 字），不一次写整章。
2. **填空优于生成**：能续写/改写就不从零写。
3. **示例即规范**：每张任务卡带一段约 300 字范文片段，规则不如一个好例子。
4. **就近约束**：关键禁令贴着任务放，卡尾复述一遍。
5. **机械判据**：模式切换、检查、触发全部用章节号/细纲标签等可计算条件。
6. **是非题自检**：逐项答是/否并附句位，禁止开放式"你觉得如何"。
7. **外部状态一切**：每步产出落盘固定格式，下一步读盘，不依赖对话记忆。
8. **短输出单位**：章 = N 个 beat 拼接，由编排层组装，拼接点可插衔接指令。
9. **防敷衍**：硬字数下限 + 逐 beat 输出 + 禁止"此处省略"。
10. **多采样外选**：便宜就多抽 3-5 次，由框架/作者挑最好的（判词：合问——哪版更接近气句，见 §4.4 / §7.7）。

> **康德红线**：军规 3「示例即规范」与技巧显式化（§8）止步于工层（L1）；灵、神两层只养、只选、只豁免（§4.3）。

### 7.2 任务卡体系（执行层唯一可见物）

四类卡，每张 <500 token，由编排层按流程组装下发。

**写作卡**（beat 级执行实体）样例：

```
【写 beat 12/23】目标 600 字
背景：林父在书房写退婚书。前一个 beat：他刚摔了茶碗。
必须发生：① 笔尖抖，写坏姓氏 ② 门外传来脚步声他吹灭了灯
禁止：心理独白超过 2 句；出现"他意识到/仿佛/般"
范文手感（模仿节奏，禁抄内容）：
> 老周把烟摁在茶杯里，没人说话。灯芯结了花，噼一声。
---
从"感官细节"进入（墨味/手温/灯影选一个），写 600-700 字。
再复述：不许出现"他意识到/仿佛/般"；心理独白 ≤2 句。
```

**自检卡**（编排层回收前必跑）样例：

```
逐项回答，答"否"必须附句子位置：
1. 是否出现：第X章/细纲/伏笔/读者？（是/否）
2. 是否连续 4 句以上对话无动作插入？（是/否）
3. 心理独白是否 ≤2 句？（是/否）
```

**发散卡**（Muse 模式的灵感节点）与**改写卡**（段落级定向重写：原段+具体问题+改写方向+一对好坏对照例）形态同理，详见落地计划阶段三。

### 7.3 工艺层（L1）

| 机制 | 规格 |
|------|------|
| **范文教学** | 每题材 3-5 段 500-1000 字成品片段（可从对标书原文切片），"像这样写"取代参数化卡 |
| **声线连续** | 写第 N 章注入**上一章结尾 300 字原文直接贴卡**（低模型读摘要无效），另附文气三行：结尾节奏/情绪余韵/悬置张力 |
| **重写回路** | 成稿 → 自检卡 + 编排层标问题 → **段落级定向改写卡**（不是词级替换）；分级执行控制成本：只重写关键 beat |
| **两遍生成** | 草稿卡（快）→ 改写卡（编辑视角），粒度随执行层模型自适应 |

### 7.4 灵性层（L2）

**六个灵感装置**（ Muse 模式启用，Craft 保留闲笔配额）：

| 装置 | 操作 | 插入点 |
|------|------|--------|
| 5选1发散收敛 | 列 5 种写法（带分类提示：从声音/物件/旁人反应/身体感觉/时间错位各一），划掉前 2 个"第一反应"，从剩余选"意外但事后必然"的 | 场景第一笔、情绪峰值 beat |
| 感官骰子 | 场景第一笔强制抽一个非视觉通道（气味/温度/触感/声音/体内感觉） | 每场景开头 |
| 物件前史 | 挑一个道具写 3 行不出场的前史，正文只取一笔 | 有道具的 beat |
| 角色两问 | 填空"他此刻最想说什么但绝不肯说 / 最不想发生的下一秒"，答案只许渗进潜台词与动作 | 对话场景 |
| 闲笔配额 | 每章 1 处 50-150 字不服务情节的闲笔，唯一要求"有味道" | 章尾余韵（Craft 也保留） |
| 人物之眼比喻 | 焦点物是__ → 角色干过什么行当（读角色卡）→ 用该行当经验写一句形容 | 改写卡内置 |

**Craft/Muse 双模式**（机械判据，无语义判断）：

```
Muse 自动升档（满足任一）：
- 细纲标签含：高潮 / 反转 / 情绪峰值
- 章节位置：第 1-3 章（黄金三章）、卷首章、卷末章、大高潮章
- 关系线关键节点：告白 / 决裂 / 死别 / 重逢
- 用户显式指令："这章要出彩" 等
降档保护：连续 Muse ≤3 章自动回落 Craft
```

**灵感台账**：`追踪/灵感台账.md` 固定格式登记装置产出的细纲外新元素（新道具/新习惯/新闲笔），下批细纲生成时决定是否转正——灵感从消费变资产，形成伏笔级复利。

**气的三栖息地**（魂×世界=气；气不可造只可养，操作化身见 §4.4）：

1. **选择器的隐函数**——多采样外选时问“哪版更接近气句”，气生成偏好，不生成文本；
2. **细纲生成的情绪底色**——气影响节拍的情绪色温（暖/冷/涩），不决定事件；
3. **豁免审判的第四票**——神来之笔必须与气同向方可豁免（§7.8 共振测试）。

气永不下发任务卡（气一被执行就死，即腔调卡 2.0）；每 N 卷作者口述复述一次气句（气随作品生长），历史版本存魂档案。

### 7.5 质感供弹（L3）

**供弹原则：拆"怎么长出来的"，不是拆"长出来的是什么"。** 好细节不可搬运，生成好细节的习惯可以提取。

| 机制 | 规格 |
|------|------|
| **质感拆解** | 拆文管道新增 Stage，从对标书提取**质感卡**：细节选择习惯（镜头总落在哪）/ 比喻来源域（从作者哪个经验池捞）/ 闲笔形态（多长、放哪、什么味道）/ 对话呼吸（话轮长度、打断率、答非所问频率）/ 情绪落点（峰值时收还是放）。产出全新句子但带同样手感，不构成抄袭 |
| **多源合成** | 3-5 本同题材书质感卡加权混合 + 每本开卷随机扰动。单源模仿=换皮；多源混合=新分布，书书不同味 |
| **口述采集** | 经验访谈模式：AI 问（"你见过最穷但讲究的房间？"），作者说两句，AI 整理入灵感池。真实细节自带不符合叙事模式的不规则性——这是人味指纹，AI 生成不出 |

### 7.6 作者性层（L3）

| 机制 | 规格 |
|------|------|
| **作者指纹** | 开书时随机/选定一组掌纹参数（比喻域/镜头习惯/闲笔频率/标点癖好），写入每张写作卡，全书一致、书书不同 |
| **偏执点** | 开书时定 ≤2 条全书非理性一致规则（如"所有暴力场面后必须接一个吃的细节""主角永远不解释自己"）。**一致的偏执 = 最强人味信号**；每张卡物理重复 |
| **糙感保留** | 重写指令从"改到最好"改为"宁留三分糙，不磨十分滑"；语法松但语感活的句子明确保护；lint 只清确定性错误。**打磨本身就是 AI 味来源之一** |
| **多采样外选** | 低模型经济学红利：同一 beat 抽 3-5 版由作者/框架挑优，选择权沉淀为作者性 |

### 7.7 合魂协议（L3）

**本书之魂 = 类型之魂为经 × 作者之魂为纬。** 纯类型之魂是合格商品（有共鸣无辨识），纯作者之魂是自嗨（有辨识无入口）；经纬相乘，皮是类型的皮，魂是作者加永恒的魂——用只有“我”经历过的方式，说出人人心里都有的东西。

| 资产 | 层 | 内容（固定字段） | 生命周期 |
|------|----|------|---------|
| **类型魂谱**（公共） | 经 | 核心渴望 / 核心恐惧 / 经典叩问 / 隔代同构书目（修仙之问 ↔ 浮士德之问，赘婿翻身 ↔ 基督山伯爵） | 拆文管道新增输出，跨书积累复用 |
| **作者魂档案**（私有） | 纬 | 一生之问 / 私人切口（通向一生之问的独家经验路径）/ 历次气句 / 回响收编（读者读出而作者未写、反复出现者判定收录） | 跨书不变，逐书生长；作品大于作者 |

**十年测试**（“永恒为体”的验收化身）：剥离时代性元素（梗 / 热词 / 即时情绪 / 平台套路 → 中性替换）后，复测细节留存——剩下的含量，就是魂的含量。Arena 测门的质量，十年测试测室的容量。

### 7.8 神来之笔豁免（L2/L3 之间）

合规系统消灭一切变异，进化系统保护有利变异。豁免不是容错，是**世界自生长的生殖道**：神来之笔被消化后应长出设定，而非留下补丁。**铁律：checker 报警永不自动删，一律拦为“待审”。**

五测试（是非题，附句位；作者主判，强模型可代行初筛）：

| # | 测试 | 问法 | 拦截什么 |
|---|------|------|---------|
| 1 | 击中测试 | 读完是否有生理反应（想划线 / 想读给人听 / 停下重读） | 无感的越界 = 噪音 |
| 2 | 删疼测试 | 删掉此段，书会不会疼 | 可有可无的炫技 |
| 3 | 不可替换测试 | 重写对照实验：同模型按常规细纲重写此段，若重写版“更合格但更平”，豁免成立 | 用实验替代“是否独特”的语义判断 |
| 4 | 共振测试 | 违反的是设定一致性，服从的是更高的真实——是否与本书之气同向、是否加深一生之问 | 与魂无关的失控 |
| 5 | 消化测试（事后 ≤N 章） | 设定回写后，世界是长出新东西（新伏笔/新分支），还是只打补丁 | 假神来之笔 |

流程四步：拦为待审 → 五测试 → 登记豁免台账（违反了什么 / 为什么值 / 代价）→ ≤N 章内设定回写消化。限额每卷 ≤2 处——稀缺保重，滥用的豁免等于没有豁免。豁免台账即世界自生长的年轮。

## 10. 决策补记（v0.3，2026-08-18）

1. **短篇线立项**：guyin-short-write / guyin-short-analyze。模板 = 内涵三件（情节节点/情绪曲线/反转表）× 方向层（时间线/伏笔/追踪）——内涵定「这篇是什么」，方向管「别写飞」；以 skills/guyin-setup/templates/short/ delta 叠加于 templates/long/（v0.4 起随 guyin-setup 技能分发）。短篇豁免限额每篇 ≤1 处。
2. **guyin-review 独立**：对抗式审查独立成技。只诊断不动刀；findings 带 level 字段（L1/L2/L3）与写作大修场景契约对齐——review 的输出即 write 大修的输入。「合问」由此获得日常住址（P4：这章更合，还是只是更合格）。
3. **import 预留（暂不做）**：逆向导入半成品书，方向定为 **analyze 加模式**（产物落写作项目结构（guyin-setup 模板）而非 拆文库/），后期视 analyze 实际效果启动；届时 guyin-analyze / guyin-short-analyze 各加一个导入分支即可，不立新技能。
4. **扫榜不做**：忘庆赏爵禄。选题不由市场扫描决定——开书 Phase B 以「**魂谱对表**」替代：候选题材列核心渴望/核心恐惧/经典叩问（阶段三前编排层按常识列，阶段三后读拆文魂谱产物），与作者魂档案（一生之问/私人切口）对表，选共振最强者；对标书从既有阅读与拆文库选定。市场热度只作 Arena 参考曲线，不进创作决策。
