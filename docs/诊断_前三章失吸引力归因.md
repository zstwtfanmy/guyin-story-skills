# 诊断：前三章为什么没有吸引力（框架 vs 模型 归因）

> 诊断时间：2026-09-11｜范围：ch001-003 正文 + 细纲 + 执行层 + 作者性 + 十章评估 + 全部章检台账
> 缘起：作者反馈——前三章没有吸引力、主角出场啥都没交代、内容很干、对话没有新意、主角很木。

---

## 一、结论（一句话）

**这不是模型没写好，是模型把框架要求的写对了。**

ch001 正文与 `作者性/语体样张.md` 几乎**逐句对应**（是"扩写"不是"重写"）。执行层没有发挥失误，它交出的正是框架指定的成品。**成品本身就是问题所在。**

### 责任归属

| 层 | 占比 | 性质 |
|---|---|---|
| **框架 · 设计选择**（三不写 / 对话签名 / 零解密 / 爽点排布） | **决定性（约 70%）** | 主动选择，非疏忽 |
| **执行层 · 工艺**（AI 指纹 / 逻辑错 / 照抄 / 空转） | 约 20% | 影响"糙"，不影响"不好看" |
| **框架 · 评估机制**（纸面分 / 无读者回路 / 无吸引力维度） | 约 10% | 导致问题**无法被提前发现** |

> **最关键的一条**：框架的问题不是"设计得不好"，而是**把"200 章不崩"的工程标准，用在了"第一章要好看"的场合**。

## 二、四个症状的逐条溯源

### 症状 1：主角很木

| 项 | 内容 |
|---|---|
| **直接制造者** | `执行层一页纸` 七条硬禁令 #2：**「不许写心理活动。写动作、写物、写他说了什么。不写他在想什么」** |
| **加重者** | `语言纪律` §0：叙述距离「**贴身但不进入**：可写感官、动作、走神；**不可写他的判断与命名**」 |
| **文本实测** | ch001 沉默类叙述 10 处／2910 中文字（"他没答"1／"他没说话"1／"他没接"1／"他什么都没说"1／"没人接"3／"不说话"3） |
| **为什么必然** | 9 岁身体 + 47 岁灵魂，本书最大戏剧张力**全部在内心**（他要演小孩、他记得所有人的结局）。框架把内心全禁了，主角只剩"嗯／哦／没答"——**"木"是这一条禁令的数学结果** |
| **反证** | 样张把"木"**作为正面技法肯定**：「他不知道怎么应对大人的热情——**不写他尴尬**」。正文=样张=目标 |

### 症状 2：对话没有新意

| 项 | 内容 |
|---|---|
| **直接制造者** | `语言纪律` §4 对话签名：**主角≤15 字**、小满≤10 字、老爸≤8 字；「主角**几乎不问问题**──他"知道"，这是他的病」 |
| **加重者** | §4.5：「**对话允许、鼓励俗套**……甚至要故意用**最没信息量**的话」；§6：「**问号只出现在"会问的人"嘴里**」 |
| **文本实测** | ch001 60 条对话／ch002 58 条／ch003 116 条，**中位数 4 字**，平均 5-6 字，最长 18-40 字 |
| **为什么必然** | 60 条对话、中位 4 字、无问句——**这是"应答块"，不是对话**。没有问句就没有追问—抵抗—翻盘的动力，也就没有交锋、没有新意。**对话的功能被纪律规定死了** |

### 症状 3：内容很干

| 项 | 内容 |
|---|---|
| **直接制造者** | 细纲把每个 beat 标成「**密 200 / 疏 80**」（字数配额）；执行层把它翻译成了**换行频率** |
| **文本实测** | 均段 **21/20/15 字**；≤12 字段占比 **46%/46%/53%**（ch003 达 183 段、ch004 188 段／63%） |
| **加重者** | ch002 上学路**连续 8 段纯景物**（乒乓球台／窗玻璃／黑板报／杨树／邮筒／冰棍摊／操场／早点摊）——为凑"疏 150"而做的**素材罗列**，不经过人物视线；去 AI 味轮删除破折号后，场景转换失去视觉信号，只剩空行 |
| **为什么必然** | "干"不是因为缺形容词，是因为**景物与人无关、段落与段落之间没有叙述流**。文本不是叙述，是短句堆叠 |
| **★框架已知** | `待审台账` ch003 行：`overcompressed-prose-tic：叙述段 62%≤15 字`，处置＝**豁免**，理由「饭桌对峙章短镜头为**有意节奏，与前两章一致**」<br>→ **发现了，判定为风格。** |

### 症状 4：没吸引力 / 主角出场啥都没交代

| 项 | 内容 |
|---|---|
| **直接制造者** | `细纲_第001章`：**「本章唯一解密位：无」** |
| **同源** | 三章累计「禁止提前释放」＝回穿机制／三世死因／小满身份／锚点规则／主角身手来源／那句没听完的话 |
| **爽点排布** | ch001「**不给大爽，只给一次微打脸 + 一次外部认证**」；`隐杀式爽点` 7 次暴起，**第 1 次排在 ch007** |
| **结果** | 前三章＝望诊认证（冷）＋ 专业小爽（冷）＋ 智性打脸（冷）。**三次全是冷的认证，没有一次体温过激** |
| **钩子距离** | 最大的三个悬念分别压到 **ch088／ch107／ch183** |
| **★关键** | 读者说"没交代"——**这不是执行失误，这是设计判决**。网文开篇硬需求是"三章内给出 身份+能力来源+当下目标+威胁"，而框架**主动禁止了这四样** |

## 三、与《隐杀》的对照：顺序用反了

`隐杀式爽点.md` 提炼的 6 条机制（温暴比／扮猪吃老虎／分镜慢写／不舔／邪恶真挚／配角智商在线）**是准的**。问题在**使用的顺序**：

| # | 病灶 | 说明 |
|---|---|---|
| 1 | **"扮猪吃老虎"被用在"读者还没见过老虎"的时候** | 爽感来自**落差**；落差需要先立"他其实是老虎"。前三章只立了"他会看手"，没立"他曾经是谁" |
| 2 | **"温暴比"的"温"被实现成了"环境质感"，而不是"人物魅力"** | 公式是「暴起冲击力＝前面安静的章数 × **日常的温度**」，关键变量是读者对**这个人**的喜爱度。读者留在《隐杀》第一页，不是"2007 年还原得真像"，是"这小子有点意思" |
| 3 | **沉默的性质错了** | 《隐杀》主角"不解释"是**性格**（他解释得很好，只是不肯）；本书"不解释"是**纪律**（他不能解释，因为解释就要暴露设定）。**同是沉默，前者是魅力，后者是失语** |
| 4 | **开篇给的要素不同** | 《隐杀》开篇给"处境+目标+对手"；本书开篇给"谜题+环境+人品认证" |
| 5 | **卷纲与执行层直接打架** | `卷纲_第1卷` 承诺调性：「**轻快喜剧为主，释放为底；老灵魂 + 嬉皮笑脸**」<br>`执行层一页纸` 却规定：「**主角不搞笑**。他只是认真地说真话。**笑的是别人**」<br>→ 后果：**主角三章里没有一次展露人格的机会**。`待审台账` 已记录：「**气句"玩世不恭中，总有那么一丝深刻"前三章未落地**」 |

> **一句话**：这不是"隐杀式"写错了，是**只学了《隐杀》的姿态，没学它建立姿态的过程**。

来源：`追踪/待审台账.md`（前三章共 30+ 条），四类：

### ⚠️ 需要你确认的事实点

`待审台账` 全部条目标注为 **`review(solo)`**，说明写这三章时是 **solo 降级模式**。
且 `.codex/agents/guyin-beat-writer.toml` 的 `model = "deepseek-chat"` **是注释掉的**（原文：「当前 Codex 版本若支持 per-agent 模型字段，取消下一行注释」）。

→ **"低模型执行层"很可能从未启用，前三章是主会话（最强模型）亲手写的。**
→ 若成立，则"模型不行"这一支基本可排除；剩下的是框架 + 主会话忠实执行框架。

## 五、评估机制为什么没拦住（约 10%，但危害最大）

| 事实 | 说明 |
|---|---|
| **十轮评估 9.6 分** | `执行层一页纸` §六 自述：「**忘了评分——九轮评估全是纸面分**」 |
| **三维风险全中** | 第十轮预判：「会不会憋死／装乖成不成立／是勾人还是文艺腔」——三个全中，且评估自己写「再写 20 个 md 也回答不了，写一章全知道」；**写完了，没人回来回答** |
| **检测维度缺一项** | 30+ 条章检报警，**零条**关于"吸引力／追读" |
| **读者回路为空** | `追踪/读者信号.md` 至今是**只有表头的空表**；作者是这本书的第一个真读者 |
| **状态门已失效** | `待审台账` 规定"未终态行存在即阻塞写新章"，但台账里多条 ch001-003 行仍为待审，正文已写到 ch008 |

> **根本缺陷**：整套体系能检测**"对不对版"**，不能检测**"好不好看"**。

## 六、改法（按性价比排序）

### A. 立刻可做，不动结构（治"干"与"木"的物理层）

| # | 动作 | 目标 |
|---|---|---|
| A1 | 给前三章开**"三不写"的局部豁免**：允许写"他知道"级的半句（限知视角本就承认「他不知道」是最值钱句式，把它的反面放出来）。把"他没答"升级为"他知道答了也没用"这种量级 | ch001 沉默类 10 处 → **压到 3 处以内** |
| A2 | **碎段合并**：把≤12 字段落从 46% 压到 25% 以下，均段 21 → **32-40** | 纯技术活，不改内容一字 |
| A3 | ch002 上学路 8 段纯景物的**每一段挂上他的视线/判断**（他看，是因为他在跟记忆对账） | 把"清单"变成"眼睛" |

### B. 结构微调（治"没吸引力"）

| # | 动作 |
|---|---|
| B1 | **把 ch007 的刘虎打脸提前**（或 ch001 补一次"体温暴起"级动作）——让前三章至少有一次"热"的 |
| B2 | **给主角一个当下目标**（不需要解释来源）：ch001 就明确"这一世要把老爸的病改过来"或"要找到东郊那个厂子的人"。**目标不需要理由，读者需要方向**——现在读者只拿到一个谜题 |

### C. 补"人物魅力场"（治"不想跟着他"）

- 气卡要求「**玩世不恭中，总有那么一丝深刻**」，`待审台账` 已记录该气句**前三章未落地**。
- 补一场"老灵魂看穿大人把戏时那一瞬的不耐烦／玩世不恭"。
- **以卷纲的"轻快喜剧 + 老灵魂嬉皮笑脸"为准，不是以"主角不搞笑"为准**——这两条必须二选一，现在是互相打架。

### D. 流程（防复发）

| # | 动作 |
|---|---|
| D1 | 给状态门加**"吸引力门"**：前三章必须做一次真人试读，把结果填进 `追踪/读者信号.md`（现在是空表） |
| D2 | **把"评估"从纸面分改成样本分**：每三章抽一段给一个没看过设定的人读，只问一句"**想不想看下一章**" |
| D3 | 章检体系增补一个维度：**追读风险**（现全部维度都是合规维度） |

## 七、要你拍板的三件事

1. **责任判断你认不认**：框架为主因（70%），模型只占工艺层（20%），评估机制占 10%。
2. **改法走哪一档**：只做 A（低风险、治标）／A+B（推荐）／A+B+C（要动黄金三章设计）。
3. **确认执行层事实**：前三章实际是 solo（主会话）还是低模型 agent 写的？（这决定"模型"这一支要不要继续查）
