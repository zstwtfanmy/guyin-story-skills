## 一、先回答你的问题：内心戏是不是又被砍掉了？

**未见统一禁止主角心理描写的硬门；样稿的私人感受展开不足，软挤压是需要检验的机制假说。**

1. v4 写作入口将“心理”列为创作自由——[作者性引导.md](../skills/guyin-write/references/作者性引导.md)、[SKILL.md 不变式 3](../skills/guyin-write/SKILL.md) 可核对；[批次公约.md](../skills/guyin-setup/templates/long/大纲/批次公约.md) 也写了“心理句数……不作硬指标”。这不等于所有参考材料和 POV 条款都已没有限制性导向；第三人称有限下的配角内心权限另见 §三与 §9.4。
2. 原通读记录的阅读损失是：内心多承担读人、推演和算账，私人的情感、欲望、自我评价或记忆展开不足，情绪常在身体短拍后转入判断。**三次修订**：撤回“九成九”的伪精确比例及“少到接近没有”的计数推论；§二统计的是显性标记，不是全部内心。参照原文显示，应关注心理内容与人物处境的联系，而不是要求多写“心想”。
3. **A 直写的显性标记也稀疏**（原记录中 A 爽文 1 处、A 历史 1 处），提示事实卡密度与模型默认写法值得优先检验，但不能由 A/C 同少推出框架无影响，也不能由 C 更少就直接归因框架。**三次修订**：这批样本不能测出各因素贡献，§五改为待验证的机制链。

一句话：**需要补的不是心理词配额，而是人在事件中的体验、所求与相互回应；它们可以发生在办事过程中，也可以暂时不服务外部目标。**

读出三件事：

- **显性心理标记 A/C 同低**——只能说明此项计数未显示明显区分，不能据此排除框架影响，也不等于全部内心密度同低；

- **C 的警句密度高于 A，但"约 3 倍"只在爽文方向成立**（7/5/8 vs 2）；历史方向恰好相反（A 3 vs C 1）。二次修订：原"约 3 倍"以单组样本推倍数证据不足（A 每类 n=1）；成立的判断是"**C 爽文每场景用判词封口的手势明显**"，不推广到历史方向。

## 三、实验时的三层风险及后续处置

> **三次修订**：本节保留实验状态与排查线索；不再以“都还活着”概括已在 §八修改的环节，也不把原文抽读当成这些机制已经造成样稿问题的实验证明。

### 第 1 层：被冻结的不是完整 profile，而是三句偏行动面的标签

- [默认叙事风格.md](../skills/guyin-write/references/默认叙事风格.md) L73 的 relationship-payoff 定义（当时 v1）有两面：**行动面**（能力经行动兑现、配角有算盘、不堆众人震惊）和**人面**（允许心理与较长对白、幽默与亲疏变化、冷却场保留人物生活、句长随场景自然变化）。二次修订指出人面定义较薄；**三次修订**：这可能使取用偏向行动面，但不能推出冻结时丢失人面“几乎必然”。
- C 运行实际冻结进 [input.json](../arena/exp-p3-2/books/c-爽文-临渠粮事/.guyin/work/exp-ch1/input.json) 的 `effective_features` 只有："能力经行动兑现／关系让能力有分量／对手有自己的算盘"——**三句均偏行动面，未明确带入人物日常感受与相处体验**。历史书同理，冻结的是"利益身份资源与制度限制选择／细节进交易行动争执／组织变化与代价进入后文"。
- 事实卡的审美行（[facts-shuangwen.md](../arena/exp-p3-2/shared/facts-shuangwen.md) L8）也只有："能力靠具体行动兑现……对手有自己的算盘……代价落到具体人身上。"
- **三次修订**：可确认的是这次实验快照偏行动面，不是模型只能写外部任务。冻结机制本身只要求实际特征进 input，具体标签由实验驱动脚本选择；v1 定义偏薄、实验取舍和最终写法是不同环节，不能合并为一个已经证实的原因。v2 定义升级与两面并取规则已实施（§8.1、§8.2），其效果仍待验证。

### 第 2 层：POV 条款与心理/情绪混合计数可能诱发保守写法

- 实验部署书 [批次公约.md](../arena/exp-p3-2/books/c-爽文-临渠粮事/大纲/批次公约.md) L13 是生效行："第三有限（视角）；**对手/配角内心禁直写，每章 ≤1 处**且须外部可见锚"，由 [guyin-check-ai-patterns.js](../skills/guyin-write/scripts/guyin-check-ai-patterns.js) 的 pov-drift（verify 级）执行。二次修订：机制比文中所述更软——pov-drift 只在**非 POV 主语的心理动词命中 ≥2 处**才报（1 处静默），且只覆盖心想/觉得/暗自等显式心理词，脚本明确不拦深层自由间接体（"自由间接引语的深层形态归走查/review"）；批次公约本身是可选格式件。这是视角约定及词面巡检，不是主角心理禁令；模板后续变动见 §8.4。
- 实验期 [guyin-check-beat.js](../skills/guyin-write/scripts/guyin-check-beat.js) 的 PSYCH_VERBS 把心想/暗道/思忖/觉得与愤怒/恐惧/绝望等**情绪直名词**一起计数，口径注释是"直接命名情绪＝告知而非展示"。它是 editorial、不定罪。**三次修订**：若执行者把建议误当成必须清零的指标，可能偏向身体反应而回避心理展开；目前没有证据证明模型实际作出了这种取舍。2026-09-21 已把两表分账，见 §8.3。
- 原通读记录指出，样稿反复使用“心里一沉/一凛/一凉”“咬住牙”“喉结动了动”等短拍后转入判断，配角多经主角的观察呈现。**三次修订**：这些是文本观察，不能直接证明由巡检或 POV 条款造成。《隐杀》第三节确有多名配角内在信息及主角看不见的反应（§9.2），但这是本节的叙述权限，不是全书视角频率结论，也不等于严格有限视角写不出鲜活配角。身体反应是否空泛，还要看它是否承接具体经历、是否有停留与后续回应。

### 第 3 层：负责全文阅读判断的环节在实验记录中空转

- §5.2 drafted 要求全文回看回答三件事："实际读到什么、最该留什么、**主要阅读损失是什么**"；§3.6 要求指出 profile 在哪些原文位置起效、"哪里只剩口号"。
- 实际三章的 review.md 是驱动脚本写死的同一句："按 relationship-payoff 通读：行动兑现、信息位与钩子成立。"（[run-experiment.js](../arena/exp-p3-2/run-experiment.js) L189–192，核查文档 D-1）——**这正是规格明令禁止的"以符合设计自证好读"**。
- 12 项机器检查（[check-evidence.json](../arena/exp-p3-2/books/c-爽文-临渠粮事/.guyin/work/exp-ch1/check-evidence.json)）全是正确性门：工序残留、叠字、重复、伏笔 ID、字数、视角越界……**没有一项、也按设计不该有一项，能问"这个人活不活、这一章除了事还有没有人"**。于是：机器门把住了"不出错"，人的阅读门空转，"平"字无人报。

## 四、和《隐杀》那一路的阅读品质，差距具体在哪

任务书选《隐杀》《赘婿》作 relationship-payoff 的品质参照，参照的是“日常关系与能力反差”等通用机制。**三次修订**：本节原有样稿判断与本轮原文补证分开看；已抽读《隐杀》楔子及前三节、《铁血残明》前三章（§九），未读《赘婿》。以下不是两部参照书的全书风格结论，也不是照搬人物、桥段或句法的指令。

### 1. 主角的内心偏于“战术脑”，“私人自我”展开不足

原通读记录中，陆争的内心常落在局势推演，如“这人不是来耍横的，是算准了才进门的”；养母与学徒处境则常通过月钱、药钱和满师期限进入叙述。陈默的感受也常在身体短拍后转入方案、交易和留后路。**三次修订**：这些材料支持“私人感受展开不足”的编辑判断，不支持“完全没有牵挂”。为养母算药钱本身就可以是关心，问题在于文字是否让这种关心获得了具体体验，而不只是交代风险数字。

本轮《隐杀》开篇的具体例证是：过去的受控生活，使家明对新生、名字、上学和陪伴产生不同感受；他珍惜自由，又嫌孩子的活动烦（§9.2）。这里不只多了一段心理，而是让读者理解同一个人为何既珍惜又不耐烦。这些日常仍承接他的核心愿望，不能概括为“不服务情节”才有价值。

### 2. 关系回应较单一，照顾常与任务供给合并

老魏在三章中的主要表现是报信、送吃食、接应和盯梢。原通读记录的疑点不在于他帮忙太多，而在于他自己的顾虑、需要和对陆争的具体回应展开较少；红薯、酱牛肉也很快并入情报或得失结算。**三次修订**：照顾本身可以建立关系，不把“帮助主角”直接判成工具人，也不要求两人必须有一场脱离和籴事件的闲戏。

参照原文提供了两条不同路径：灵静保护家明，也会管课堂纪律、拉他参加活动；庞丁协助少爷，却还记着自己的积蓄被抢（§9.2–9.3）。关系的区别来自各自的尺度与经历，不只来自共同目标。笑意计数不能证明有无幽默，是否有相处趣味仍须读对白与回应。

### 3. 配角的反应偏于职位功能，个人处境的区别不足

钱有义的自保、吴掌柜的谨慎、李掌柜的精明、周大使的前程顾虑，都有处境依据。原通读记录认为，这些反应较少进一步显露人物自己的相处经验和关切；赵九成的期限压力、河工痕迹及问名字的动作较具体，但对虎口茧的解释又迅速归入算账判断。**三次修订**：不再以“必须做出职位之外的反应”作为真人标准，也不要求每个身体细节都在后文转成行为回收。

《铁血残明》母亲的顾家与顾面子、父亲对药材的坚持，都没有脱离家庭身份，却显示了不同选择依据；《隐杀》中的配角还各有误读与顾虑。POV 权限影响信息呈现方式，但不能直接判定它是样稿扁平的原因，更不能把允许的“≤1 处”当成必须填满的心理配额。

### 4. 外部事件持续密集，人物消化经历的空间较少

- ch1：当众验米逼退军官（外部对决）
- ch2：串联两家掌柜、夜路被殴、发现私囤（连续协商、危机与发现）
- ch3：点闸、封仓、赔补，末尾再接“满师被悬”的压力

**三次修订**：原判断中的“三高潮”“没有一个低压槽”不是按统一标准测出的结论；这里保留的是外部进程密集、感受和关系回应停留偏短的编辑观察。《隐杀》在高压脱身后展开重生日常，《铁血残明》则把家庭情感放进药铺危机和退婚争执（§9.2–9.3）。可留低压段，也可在正在办的事里展开人，不能断言亲密感只来自无事日常，更不应改成冷却章配额。

### 5. 金句腔：反复提炼意义是否提前替读者封口

举几处 C 爽文的章内封口句："六十文，是他接养母进城的路，又短了一寸。""要撑过这三日，不能只跟刀硬碰，得先找到那根绳，握在自己手里。""契纸是柜上的功劳，事情却是学徒的本事。""一个无品无印的贴书动不了账，但账自己开始怕人了。"（历史 C）

**三次修订·2026-09-22**：保留“样稿反复以判断句收束”的编辑观察，撤回“每个段落都被要求如此”的机制断言及无统一口径的“低一半”。需要检查的是这些收束是否反复替读者解释意义、抹平人物余味，而不是“作者显形”本身有错。《铁血残明》第3章大量使用显眼的叙述调侃，同时以对白、照应和态度变化形成阅读趣味（§9.3）；不能把少旁白、少解释、少金句当成人物细腻的统一处方。

### 6. 关系字段一直存在，但实验三章未记录关系变化

实验三章事务里 `character_snapshots.relationships` 全部落的是 `[]`（[run-experiment.js](../arena/exp-p3-2/run-experiment.js) L131），`next_chapter_commitments` 全是外部目标（凑米、盯炭行、查东家）。这是该次实验的记录取舍；schema 本身允许登记关系与知情，[tracking-transaction.md](../skills/guyin-write/references/consult/tracking-transaction.md) 示例也填写了关系。

**三次修订**：直接撤回“世界模型没给关系留格”“闲相处在事实体系中无法发生”及“作者因此没有动力写关系”的断言，不再只把更正附在旧结论之后。二次修订已补入闲相处、摩擦与亲疏变化的登记引导（§8.5）；但一次相处也可以显露或维持已有关系，不必总生成新状态。关系记账是否推动写法、空字段是否对应正文损失，均须另行验证，不能靠强制填表补人物。

## 五、待验证的机制链（排查优先级，不是已测出的贡献排序）

### 10.2 两条方向分开，不合成一种“细腻网文腔”

下表是 §九已读开篇支持的设计取向，不是全书统计；Y、T 是本任务的研究代号，不新增路由器或作家仿写模式。

| 层面 | Y：关系日常与能力反差（参照《隐杀》已读部分） | T：市井人物与现实因果（参照《铁血残明》已读部分） |
|---|---|---|
| 阅读中心 | 过去经历使寻常生活变得值得珍惜；看这个人怎样接受陪伴，又嫌麻烦 | 生计、尊严、私心、责任互相牵扯；看各人怎样在具体社会处境里周旋 |
| 选材与注意 | 熟人举动、个人偏好、别人以为的小事与自己感受的差别；能力可以退到背景 | 谁出钱、谁丢脸、谁记旧账、谁担后果；劳动、物件与身体状态进入争执，不变成资料陈列 |
| 心理与对白 | 想过的生活与眼前的不耐烦可以并存；关心与管束错位，主角不必每次解释自己 | 自我标榜与实际行为可能有落差；旁人记得自己的损失，话会被误解、顶回或岔开，主角不总控场 |
| 句段与时间 | 反复日常可概述，认出愿望或接受照顾时可以停留；急事与日常的语速不同，不全篇短句 | 足够背景让人明白争执，再把交锋写开；从多人喧闹转向一个人的担忧，叙述速度跟着重心变化 |
| 叙述者 | 可以解释、直接写感受、温和调侃；不把“细腻”缩成含蓄和沉默 | 可以明显评论、反讽、调侃；滑稽不抹去损失，不把“历史厚重”写成人人严肃说公文 |
| 情绪落点 | 感受可以迟到，关系可以未说破；生活之所以重要来自这个人的经历 | 赢了口角未必安心，解决眼前事未必解除家计压力；好笑与难堪可以同场成立 |

两条方向共享因果与人物自主性，但不是给同一段话换题材名。历史向遇到军政、兵粮、行军等超出开篇证据的场景，须先补对应原文与专业材料；不拿母子吵架的写法包办战事，也不把《晚明》自动并为已验证参照。

### 10.3 从“应当有人”落实到句段选择

这些是读原文和成稿诊断时的观察工具，**不要求写前逐段填表，也不按顺序逐项往正文里塞**。每轮只处理主导阅读损失；有些段落仅交代事情就足够。

| 现稿疑点 | 实际可采取的写作或修订动作 | 怎样判断有效，而不是补装饰 |
|---|---|---|
| 有感官细节，却换个人也能看见同样东西 | 从此人的经验和当下关切选择注意对象、评价用词；已有具体信息够用时删掉泛化感官铺陈 | 读者能解释为什么偏偏是这个人注意它；不靠每段写职业比喻冒充个性 |
| 身体一紧就进入算计 | 在需要的地方容纳感受、个人解释、记忆或自我辩解；也允许事情发生时来不及想、过后才懂 | 变化有具体处境依据，不只是把“害怕”扩写成更长的同义句；不强制完整情绪链 |
| 人人接话准确、说完立刻达成共识 | 让回应受旧事、顾虑和对关系的理解影响；允许听错重点、停顿、反问、做事中断对话 | 话语改变了双方理解或显露相处分寸；不是人为加口吃、语气词和没意义闲聊 |
| 每件事同样展开、每段同样收束 | 重复流程可概述；重要回应写成可经历的过程；背景在读者需要时给足 | 读者能分辨哪里值得停、哪里该向前；不是规定长短句比例或删光说明 |
| 抽象名词与判词替人物得出结论 | 改清动作对象、指代和具体得失；只在解释确有新信息或叙述趣味时保留评论 | 不必靠段末点评才知道刚才发生了什么；保留本来有效的直陈、概括和幽默 |
| 每次关系出现都是发任务 | 让既有经历影响当前回应，保留一次相处本身的价值；无需另外发明一个“生活爱好” | 配角不是遗忘上一场损失的工具；帮忙、拒绝、维持关系都能成立 |

研究时每个例证只记一条短链：**原文位置 → 具体选择 → 造成的阅读效果 → 换到新人物时可迁移什么 → 什么不能迁移。** 例如，§9.2 的名字确认并不是“用一个物件写温暖”的通用公式，而是经历、身份与愿望共同改变了一个普通名字的分量；§9.3 的母亲转低声也不是“吵架后必温柔”，而是说话对象变化带出另一层顾虑。

### 10.4 可直接试用的两段候选方向（尚未落库）

只为后续实验提供可执行起点，不声称这两段已经有效。生成上下文只放共有事实、所选的一段、确需承接的前文与真实授权；不塞本文全篇、两套方向或作者书名。原文研究另作取证，不逐句映射到新稿。这是提示与编辑方法的校准，**不是模型权重训练**。

**Y 候选定义（对应 `relationship-payoff` 的实验覆盖）**

> 从人物当下在意的生活进入，让经历影响其注意、好恶和对人的理解；能力是这个人的一部分，不必每场都拿来证明。想法可以直接写，也可以由叙述者转述或融入人物语气，选择最能让人理解当时体验的方式。关心、嫌麻烦、得意与牵挂可以并存，不必立即说透或换成下一步计划。熟人按各自的尺度回应，亲近不等于总是理解，主角也可能会错意。重复日常可概述，关键的相处和感受允许停留；急事把行动写清，事后让生活按人物处境继续。对白与叙述都可以有幽默，不为逗笑削弱别人，不用固定误解或旁人赞叹证明能力。选具体而属于此人的细节，句段随事情与注意变化，不用段末判词反复解释意义；相处本身可以是回报，不要求安排无关主线的闲戏。

**T 候选定义（对应 `historical-causal` 的实验覆盖）**

> 从具体生活与社会处境写人：同一笔开销、一次承诺或一场争执，在各人眼里有不同的分量。生计、责任、面子、私心和旧交情可以同时影响选择；有知识有本事也可能误判气氛、碰到办不成的事。让人按自己所知接话，保留岔开、顶回、含糊和改变语气的可能，不把对白写成轮流汇报方案。背景讲到足以理解眼前得失，重点交锋展开，重复工序略过；物资、信用、人员与制度要实际限制办法，不能只点名。语词按时代、人物来源和叙述层次区分，不堆官话，也不把所有现代说法一刀切禁掉。可以用叙述评论和落差产生幽默，但人的损失、关切和后续影响不因此消失。动作与心理都可直写，让具体经验承载感情，不把历史写成账本，也不靠满篇沉重冒充厚实。

**冻结方式**：基线 Y=`relationship-payoff/v2`、T=`historical-causal/v1`；候选实验沿用其基础 ID/版本，将实际选用的一段完整作为 `effective_features` 的一个字符串元素（该字段是非空字符串数组，不是单个字符串），`selection_basis=user-selected` 仅在后续用户确实授权采用该候选方向时填写。实验记录另记“基础版本＋实际候选段的完整文本与哈希”，不把它冒称已发布的 v3/v2，不新增 `input.json` 未定义字段。未获此授权，不启动候选实验。

### 10.6 试写设计：先少量校准，再用新内容验证

**共同控制**：每个配对使用相同事实、人物背景、篇幅区间、POV、模型版本、可见材料与修订预算；可调生成参数也相同，界面不可控项如实记录，不假称随机种子已固定。C0 读当前完整 profile，C1 只把它替换为候选方向；不让 C1 多得剧情答案或更多次重写。二者都不能看到对方稿件；新会话仅导入允许的输入，不继承本会话全文。

**留出隔离也约束调参者**：E0 的完整章 brief 由用户或不参与 E2 调参的独立会话准备并封存；参与提示校准的会话不得提前见过题目内容，只知道测试范围与迁移条件。已经暴露的材料降为校准题，不能靠之后“不再读取”恢复独立性。只需会话和文件可见范围隔离，不建设新的多代理系统。

- **E2 最小批次**：每方向三类短场景——生活相处、目标受阻的交锋、事件后的反应；各以 C0/C1 写一份，合计十二份短稿。每份建议 1000–1800 汉字，成对同区间；这是实验容量，不是日后正文配额。每稿至多一次有明确损失假说的修订，保留初稿，未明显变好就用初稿。
- **E3 留出验证**：每方向两个不同完整章 brief，均含足以观察人物与事件的内容；C0/C1 各一稿，两方向合计八份完整章。篇幅在 E0 统一，例如 2500–3500 汉字；不能把校准场景换人名当新题。其中一章须承担预定迁移：在该路线适用范围内，更换社会环境、关系类型或压力来源，并说明与校准题的实质区别，不只换道具。E3 开始后不再改提示；若据失败调整了提示，已读的留出题均变校准材料，重新准备未暴露测试。
- **E5 连续性验证**：每方向一条新的三章链，使用 E3 选定的同一方案，包含相处和压力变化的机会，但不规定哪章必须冷却、反转或高潮；按 §10.8 明确它是未发表样稿链还是获另行授权的沙盒发布链。评价整段承接，不只看三段最好看的文字。
- **结果不是选秀**：按完整批次报告，不丢失败稿，不把最佳一次当稳定能力。C0 已经同样接近且 C1 无净收益时，保留较轻的 C0，按 E4 的无需改动分支继续核验实际加载与三章承接。

E0 中每份 brief 只需足以理解处境：世界与时间、谁在场及其关系、眼前难题、已知事实/真实锁、必要前情、篇幅与POV。人物过去与愿望可以作为已设定背景，但不预写每个人的心理、反应和结局；确实未设定的部分留给执笔者，不要求用户交私人经历或人物问卷。

### 10.7 “接近”如何验收：原文锚、匿名对照、真人裁决

**先定标尺再看候选。** E0 登记以下默认验收约定供用户确认；允许在开测前调整，不允许见到分数后降低门槛。原文锚从 E1 已读材料选取，按场景功能、叙述权限、前情依赖与篇幅匹配，给足双方理解所需的短前情。不能拿名作的情感峰值对一个纯过渡段，也不能借《隐杀》的标准替《铁血残明》评分。

| 维度 | 读者实际判断什么 |
|---|---|
| Q1 人物体验 | 能否理解此人为什么在意，感受是否由经历与当下处境生长，而不是贴心理标签 |
| Q2 关系与对白 | 别人的回应是否有自己的依据，对话能否显露关系和误读，而非轮流替作者解题 |
| Q3 文笔与节奏 | 注意对象、措辞、句段、概述和展开是否自然有效；不是“形容词多”“短句多”或“没有心理词” |
| Q4 阅读牵引 | 本场读得下去、愿意接着看；既不为赶事牺牲体验，也不因补内心而原地重复 |
| S 方向辨识 | Y 的日常愿望与能力/关系是否共存，或 T 的生活处境、交锋与实际后果是否互相作用；不是靠校园/官名/粗口等题材标签认方向 |

每维采用文字锚定的 0–4 档：0=未成立，1=明显机械或断裂，2=部分成立但与对应原文仍有明显距离，3=有差距但阅读体验已接近，4=本次局部阅读体验相当或更好。**这些是项目验收约定，不是客观文学分数，更不是“达到作者水平百分之几”。**

验收由用户与至少一名非执笔的真实读者分别给出；读者不足时可先用独立会话作编辑预审，但状态只能是“待真人验收”。先隐藏 C0/C1 标签、随机顺序独立阅读，再看匹配原文锚校准距离；熟悉原书的人可能识别原文，应记录，不能冒称完全双盲。读者给出能定位的优点、最主要损失及继续阅读意愿，不先展示方案的自我解释或作者自评分。

**默认过门条件**：

1. E2 只判断方向是否值得继续，不宣布目标已达；E3 选定的同一方案（C0 或 C1）在两份完整章中，用户在 Q1–Q4、S 均评至少 3，独立读者无仍评 0–2 的未解决差距，且二者都愿继续读。分歧保留，回到具体段落核对，不用平均分盖住短板。
2. E5 按整条三章链再次满足上述标准，并能指出关系经历如何影响后章、各章语气为何仍属于同一作品；一章闪光、后章退化不能过门。E3 预定的迁移情境也必须通过，缺测不能标 §10.1 的③；这里的迁移仅指已登记的题材/情境变化，不代表所有题材通用。测试集未涉及的能力标“未测”，不借这些分数覆盖战场、长线布局等未验证维度。
3. 事实、专业前提、授权、已选 POV 或承接存在实质错误时，先解决这些问题；不靠漂亮文字抵销。直接心理、叙述评论、日常闲相处与篇章留白本身不是错误。
4. 两方向单独结论。只满足 Y 不得宣称 T 也完成；两者都满足也只说明当前模型、已测条件下接近，不自动保证换模型、换题材或长篇后段的效果。

### 10.8 接入现有流程，不为文学验收另造一套系统

**POV 先选清楚**：新实验故事若要研究叙述者评论及多个角色的内在信息，E0 可在获准的实验范围内明示 `视角规格：POV=多视角`，并约定转换有可辨认的叙述中心、不在一句内无标识跳头脑；C0/C1 使用同一约定。这不是原书全部叙述方式的复刻。既有书锁定第三有限时继续遵守，用可见回应和主角理解呈现别人；要比较另一视角另开实验，不能一边改 POV 一边把效果归因于文风提示。现有脚本对多视角静默，**语义视角验收仍由全文审读承担**。

**隔离约定**：后续实验新建 `arena/exp-prose-quality-<批次ID>/`（拟建，本轮不创建），不覆盖 `arena/exp-p3-2/`。只需执行记录、原文定位/分析、冻结输入、版本稿与评读证据；保留已有文件结构，不额外做一套 schema。E2/E3 可使用普通隔离文本作提示对照，必须标“文笔实验，未走完整框架协议”，不伪造 session、transaction 或 ready。

### 10.9 不达标时怎么改，何时停止无效加规则

每轮记录“哪段不好读 → 一个主要假说 → 最小修改 → 新稿是否净改善”，不是要求展示模型思维过程。单稿默认至多一次实质修订；需要再次调提示时另开有编号的实验轮，不在同一稿上无限抛光。累计两轮同类调整仍无可见净收益，就暂停该路线并做下表对应定位，而不是宣布通过或继续堆提示。

| 失败形态 | 下一步动作 | 不做什么 |
|---|---|---|
| 更符合条目但更呆板 | 去掉此次新增且无收益的指令，保留更好的初稿；复核是否把诊断表全塞进生成上下文 | 不增心理次数、笑点次数或冷却章配额 |
| 人物动机清楚，句段仍像报告 | 固定事实和情节，只试一个语言假说，例如注意对象或对白回应；按 Q3 与具体原文位置判断 | 不再重填一套人物小传，不靠加形容词救 |
| 短场景好，完整章差 | 查输出预算、场景取舍、概述/展开和视角承接；必要时减少过细的事件指定，再重新对照 | 不把模型截断当成无文笔，不借延长一倍篇幅冒充公平提升 |
| 完整章好，连续章退化 | 核对实际读到的上文、人物知情与关系经历，候选分支是否混用；修承接输入后重测 | 不把所有关系硬塞进新台账，不靠加钩子遮掩遗忘 |
| Y 有效、T 仍空泛 | 补真正影响该场景的生活/行业/制度材料，区分人物认识与已核实事实 | 不继续增加通用感官细节，不拿时代名词或粗口补气质 |
| 原文气质不同，但新稿好读 | 分别记 Q 与 S；若用户喜欢原创口吻，明确是否调整目标，否则仍按原目标检验 | 不为了“像”而改写原书桥段，不暗中降低风格目标 |
| C0、C1 在足够材料与输出预算下均明显欠缺 | 经用户选择，可用另一可用模型在同条件下做小样校验，或转人工编辑路线；列明当前条件不支持的项 | 不在框架里自动切模型，不把未尝试的模型称为更好，不承诺再加一条规则就能达标 |

原文事实支持写法可行，不证明某个模型具备这种能力；换模型能否改善也须新证据。若用户不授权额外模型、材料或人工投入，保留未达标结论和可用成果，不冒报完成。
