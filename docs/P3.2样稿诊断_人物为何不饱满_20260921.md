## 一、先回答你的问题：内心戏是不是又被砍掉了？

**硬砍：没有。软挤没：有，而且是三层叠加。**

1. v4 权威文件里已经**不存在**"禁止/限制心理描写"的硬条款——[作者性引导.md](../skills/guyin-write/references/作者性引导.md)、[SKILL.md 不变式 3](../skills/guyin-write/SKILL.md) 明确把"心理"列为创作自由，部署书的[批次公约.md](../skills/guyin-setup/templates/long/大纲/批次公约.md) L21 也写了"心理句数……不作硬指标"。旧禁令"心理活动不超过 2 段"只残留在已标 `[降级]`、不随章加载的 anti-ai-writing.md 里。
2. 但样稿里的内心戏**确实少到接近没有**：六个样本平均每千汉字只有约 1 处显性心理标记，而且仅有的内心活动**九成九是战术计算**（读人、推演、算账），不是情感、欲望、自我评价或私人记忆。情绪几乎全部被压成一个身体动作（"心里一沉""咬住牙"）后立刻转入判断。
3. 更关键的反证：**A 直写条件同样稀疏**（A 爽文 1 处、A 历史 1 处）。如果只有 C 少，那是框架砍的；A/C 都少，说明主因在 A/C 共用的东西——**事实卡（brief）的事件密度＋这批模型在高压剧情 brief 下的默认写法**；框架侧的边际问题是把已经很窄的东西执行得更紧、更工整、更不敢停顿（证据见第四节）。

一句话：**不是谁删了内心戏，是从 brief 到 profile 冻结形态到质检口径的整条链上，没有给"人"留槽位，只给"事"留了槽位。**

- **内心密度 A/C 同低**——框架不是区分项；

## 三、软挤压的三层机制（都还活着）

### 第 1 层：被冻结的不是 profile，是三句行动侧标语

- [默认叙事风格.md](../skills/guyin-write/references/默认叙事风格.md) L73 的 relationship-payoff 定义（当时 v1）有两面：**行动面**（能力经行动兑现、配角有算盘、不堆众人震惊）和**人面**（允许心理与较长对白、幽默与亲疏变化、冷却场保留人物生活、句长随场景自然变化）。二次修订：v1 的人面只有这一句，且不含"主角有非任务时刻/私人自我/关系闲相处"等具体机制——从这样的定义里冻结特征，只剩行动面几乎是必然。
- C 运行实际冻结进 [input.json](../arena/exp-p3-2/books/c-爽文-临渠粮事/.guyin/work/exp-ch1/input.json) 的 `effective_features` 只有："能力经行动兑现／关系让能力有分量／对手有自己的算盘"——**三句全是行动面，"人"的半句没进冻结特征**。历史书同理，冻结的是"利益身份资源与制度限制选择／细节进交易行动争执／组织变化与代价进入后文"。
- 事实卡的审美行（[facts-shuangwen.md](../arena/exp-p3-2/shared/facts-shuangwen.md) L8）也只有："能力靠具体行动兑现……对手有自己的算盘……代价落到具体人身上。"
- 结果：模型在 C 条件下能稳定引用的方向，是一份**纯外部、纯任务、纯交易**的美学。恢复不换声线的设计是对的，但冻结时就只冻了半张 profile。二次修订（2026-09-21）：冻结机制本身只要求"实际特征"进 input，行动面标签是实验驱动脚本选的——更准确的归因是 **v1 定义的人面本就薄弱，冻结只是如实搬运**。修复＝定义升级 v2＋冻结并取两面的新规则，已实施（§八.1、§八.2）。

### 第 2 层：POV 硬规＋情绪词巡检，把"往里写"的路收窄成一条

- 部署书 [批次公约.md](../skills/guyin-setup/templates/long/大纲/批次公约.md) L13 是生效行："第三有限（视角）；**对手/配角内心禁直写，每章 ≤1 处**且须外部可见锚"，由 [guyin-check-ai-patterns.js](../skills/guyin-write/scripts/guyin-check-ai-patterns.js) 的 pov-drift（verify 级）执行。二次修订：机制比文中所述更软——pov-drift 只在**非 POV 主语的心理动词命中 ≥2 处**才报（1 处静默），且只覆盖心想/觉得/暗自等显式心理词，脚本明确不拦深层自由间接体（"自由间接引语的深层形态归走查/review"）；批次公约本身是可选格式件。软导向存在，但"锁"的强度被高估了。
- [guyin-check-beat.js](../skills/guyin-write/scripts/guyin-check-beat.js) L87 的 PSYCH_VERBS 把心想/暗道/思忖/觉得与愤怒/恐惧/绝望等**情绪直名词**一起计数，口径注释是"直接命名情绪＝告知而非展示"。它是 editorial、不定罪——但在一个"检查要全绿、报警要处置"的运行环境里，模型学到的安全写法就是：**主角的情绪不外说、只做身体反应；配角的内心一律不进**。（二次修订：2026-09-21 已把两表分账，见 §八.3。）
- 文本后果完全可验：六个样本里情绪高频表现为"心里一沉/一凛/一凉""咬住牙""喉结动了动"——一个 tic 一拍，然后立即回到判断。配角则全员是"被主角观察和算计的对象"，没有一个场景允许读者在配角的意识里停留。《隐杀》式的生动，很大一块恰恰来自叙述频繁地在不同人的立场、脾气和小心思之间进出。二次修订：把"质感锁没"全部归给 ≤1 锁过强——身体 tic 化更直接的来源是 mono-count 情绪直名词巡检与模型安全写法（本层上一条），POV 锁是加码不是主因。

### 第 3 层：唯一负责"好不好读"的环节在实验里根本没有运行

- §5.2 drafted 要求全文回看回答三件事："实际读到什么、最该留什么、**主要阅读损失是什么**"；§3.6 要求指出 profile 在哪些原文位置起效、"哪里只剩口号"。
- 实际三章的 review.md 是驱动脚本写死的同一句："按 relationship-payoff 通读：行动兑现、信息位与钩子成立。"（[run-experiment.js](../arena/exp-p3-2/run-experiment.js) L189–192，核查文档 D-1）——**这正是规格明令禁止的"以符合设计自证好读"**。
- 12 项机器检查（[check-evidence.json](../arena/exp-p3-2/books/c-爽文-临渠粮事/.guyin/work/exp-ch1/check-evidence.json)）全是正确性门：工序残留、叠字、重复、伏笔 ID、字数、视角越界……**没有一项、也按设计不该有一项，能问"这个人活不活、这一章除了事还有没有人"**。于是：机器门把住了"不出错"，人的阅读门空转，"平"字无人报。

## 四、和《隐杀》那一路的阅读品质，差距具体在哪

任务书选《隐杀》《赘婿》作 relationship-payoff 的品质参照，参照的是"日常关系与能力反差"这组**通用机制**（不是仿写句法）。拿这组机制逐条对照样稿：

### 1. 主角的内心只有"战术脑"，没有"私人自我"

陆争的心理活动几乎全部是局势推演："扦样是学徒的手，好坏是学徒的嘴""这人不是来耍横的，是算准了才进门的""刀是他的……绳头在炭行"。他十七岁、养母咳血、还差一年满师——但这个身份只在两处以**账本数字**出现（"月钱二百四十文……能余六十文""药钱也没少"），随即换算成剧情筹码。全篇没有一处他作为少年人的自得、委屈、害怕、嘴馋、对城里某样东西的喜欢或对某个人的非利益牵挂。陈默同理：恐惧只出现一拍（"心里一凛"），剩下全是方案、交易和留后路。

《隐杀》一路让读者愿意跟着走的核心，是主角在"办事的人"之外始终有一个"过日子的人"：会在无关生死的小事上较真、会自嘲、会对身边人的蠢和温柔有即时的、不服务于情节的反应。我们的主角下了战场没有生活。

### 2. 关系全是功能件，没有摩擦力和烟火气

老魏是三章里唯一的"关系"，但他是一个**完美工具**：送情报（ch1 闻声报信）、给温暖（烤红薯）、救命（带人接应黑棍）、盯梢（数炭行袋数）、看护（ch3 送酱牛肉）。他没有自己的麻烦、脾气、与陆争的摩擦或亲疏变化过程——每一次出现都恰好携带剧情所需的资源。陆争与他之间没有一场"不推进和籴事件"的戏。而红薯、酱牛肉这两个仅有的生活道具，也都在同一段落内被征用为情报或结算（"米保住了，工钱保住了，药钱也没少。值。"）。

profile 写的是"幽默从彼此立场和理解差异里产生，不强插段子"——不是要插科打诨，而是要两个人物有**立场差**。三章 C 爽文笑意计数 0/0/1，关系始终处于"同志＋资源"的单频上。

### 3. 配角是"位置上的反应函数"，不是带着自己日子上场的人

钱有义＝怯懦贪功（每次出场都青白着脸甩袖）；吴掌柜＝谨慎（捻胡子）；李掌柜＝精明（眼睛亮）；周大使＝前程自保。他们在场景里做出的反应完全可由其职位预测，**没有一个反应出乎职位逻辑之外**——而人之所以是人，恰恰在于偶尔不按职位出牌。赵九成是全篇最立体的（期限压头、有拉纤出身的虎口茧、会蹲下来问名字），但"虎口茧"这个观察被读出之后只用于一句判断"这样的人算账比谁都精"，再无行为回收——细节立了档，没有变成人。

第 2 层的 POV 锁在这里是帮凶：配角连"≤1 处"的主观时刻都没拿到，读者永远只能从陆争的算计里认识他们。

### 4. 三章三高潮，没有一个低压槽；每章都是任务通报会

- ch1：当众验米逼退军官（外部对决高潮）
- ch2：串联两家掌柜（政治操作）＋夜路被殴（人身危机）＋发现私囤（罪证反转）——一章塞三个高潮
- ch3：当众点闸、封仓决战、逼对手市价赔补，末尾再压一个"满师被悬"的钩子

profile 明写"冷却场保留人物生活，不把每章都写成低调—误解—震惊"。实际是章章升温、章章留钩、章章解决一个外部目标。连续三章没有一个夜晚是无事的，没有一场戏允许人物不办事。读者的神经一直被拉紧，反而对主角"熟不起来"——亲密感来自日常，不来自第三次看他漂亮地赢。

### 5. 金句腔：作者站在每一场的出口等着盖章

举几处 C 爽文的章内封口句："六十文，是他接养母进城的路，又短了一寸。""要撑过这三日，不能只跟刀硬碰，得先找到那根绳，握在自己手里。""契纸是柜上的功劳，事情却是学徒的本事。""一个无品无印的贴书动不了账，但账自己开始怕人了。"（历史 C）

单看都漂亮，密度高了就是同一种手势：**每个段落都被要求提炼出一个可摘抄的判断**。真实的人在真实处境里不会每隔四百字说出一句判词。A 爽文的结尾（"天塌下来，也得先有人拿根棍子撑住第一寸"）也有此习癖但频率低一半。这不是文风成熟，是"作者显形"——读者读到的不是粮店学徒，是一个知道自己正在写好句子的作者。

### 6. 追踪世界模型只装得下"事"，"关系变化"字段三章全空

实验三章事务里 `character_snapshots.relationships` 全部落的是 `[]`（[run-experiment.js](../arena/exp-p3-2/run-experiment.js) L131），`next_chapter_commitments` 全是外部目标（凑米、盯炭行、查东家）。schema 本身允许登记关系与知情，但**作者在操作中没有任何动力去写它**：一章若只写了陆争和老魏的一场闲相处，delta.result 填不出新结果、commitments 留空、章末没有钩子——它在事实体系里"没有发生"。

这是比任何禁令都强的塑形：**被记账的世界才会被认真写**。世界模型给事件、伏笔、物证、地理、承诺都留了格子，没给"一次改变了关系的晚饭"留格子，作者自然只写能落账的东西。二次修订：这句话不准确——schema 的 `relationships` 格子一直存在（[tracking-transaction.md](../skills/guyin-write/references/consult/tracking-transaction.md) 示例快照里就填了两条关系），缺的是**引导作者使用它的明文**（何时算"实际改变的关系"、闲相处算不算）。该引导已补进 tracking-transaction.md L176 与 guyin-write SKILL.md 发布段（§八.5）。

## 五、根因链（按贡献排序）

```
事实卡 100% 剧情占满（必达事件×4–5＋硬结果×3＋悬念钩；篇幅实际仅约 2000–2700 汉字）
   └─ 场景预算被事件吃光，结构上没有"非任务时刻"（A/C 共同主因）
        └─ profile 在 C 侧只冻结了行动面三标签，人面（心理/幽默/亲疏/冷却场）未进冻结特征
             └─ POV 配角内心 ≤1（verify）＋情绪名词 mono-count（editorial）的软导向
                  └─ 情绪外化为身体 tic、配角对象化、判词封口成为安全写法
                       └─ 全文回看空转（实验硬编码字符串），主要阅读损失无人记录
                            └─ 连续三章章章高潮；世界模型无关系格 → 人物最终只剩功能轮廓
```

对应 §10.2 的处置表，当前样本命中的正是两行：**"风格方向有了但剧情无趣→回人物所求、回应与后果"**（这里的"无趣"是指人无趣，事件其实过密）与**"首章好、后续空转→查状态、profile 快照、人物知情和承接"**。

二次修订（2026-09-21）：链上各环强度已重新校准——"brief 事件密度"（A/C 共同主因）与"回看空转"（实验硬编码）维持原判；"profile 只冻行动面"改为"v1 定义人面本就薄弱，冻结只是如实搬运"；"POV 锁"降为软导向加码（≥2 处才报、深层自由间接体不拦）。"POV 锁"与"mono-count"两环已于本次修订分账/放宽（§八.3、§八.4）。

## 六、为什么现在还不能拿这批样本判 C 路径的输赢

1. **A/C 同会话连续产出**（§10.1 要求独立新会话；进度文件已自认）：同一支笔用同一套腔调写了六遍，连"盖面米"的道具和虎口茧细节都两版共享——模型在写 C 时脑中已有刚写完的 A。这组样本只能说明"这套 brief＋这个模型会写成这样"，**不能分离模型基线与框架影响**。
2. **brief 过细导致必然收敛**：事实卡规定了必达事件、解法三招、章末钩方向，留给两版的变量主要是句法。拿一份电影分镜级的 brief 测"谁更会讲故事"，测的只是执行工艺。
3. **C 的阅读关是假的**（硬编码 review），而 A 没有任何关——两边流程不对称，比较的不是"自由直写 vs 新路径"，是"自由直写 vs 走完机械链但没人读稿"。
4. 所以你现在的感觉（"和《隐杀》差距大、人物不饱满不生动"）**作为读者印象成立且与量化吻合**，但"差距是框架造成的"这一归因目前不成立；可证实的归因是：brief 的事件密度为首要因素，框架侧"定义薄弱＋软导向＋空转回看"为次要加码因素（二次修订：其中冻结归因与 POV 锁强度已按 §三修正，但"次要加码"的结论不变）。
