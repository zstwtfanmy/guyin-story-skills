## 一、两段式审读 · 第一遍：只读正文的真实反应

**一句话：我被"通知"了一场悲伤，而不是被带进那场雨里——每一句都在告诉我她有多痛，但我没有一个瞬间是替她痛的。**

展开（未回看细纲、无预设问题时的原始感受）：

1. 开篇信息是"她在等人、人没来、她被抛弃了"，但这三件事是一句话里直接交代完的，我没有"等"的过程，只收到结论。
2. 第二段起密集的熟比喻（流泪、刀割、孤舟）让我出戏：这些比喻放在任何一个被弃角色身上都成立，看不见"苏婉"这个人。
3. 货郎出现时我短暂抬了一下头（有人来了），但他问完针线就消失，我意识到他只是个负责让她"再失望一次"的道具，失望感立刻泄掉。
4. 章尾"下定决心离开这座城"是典型的宣告式收束——决定被讲出来，而不是被挣出来；合上书我对下一章没有具体的期待，只有一个抽象的"她要走了"。

## 二、第二遍：逐字引证据的 Findings

### F1（S2 / structure / L3）：全章无事件、无因果收益，唯一"事件"是道具式虚惊

> 「来人掀开棚帘，是个陌生的货郎。希望像泡沫一样破灭了，她从云端跌回了谷底。货郎问她要不要买针线，她摇了摇头，眼泪终于忍不住夺眶而出。」

货郎不携带任何信息、不产生任何交涉、不改变她的处境，功能仅是"掀开棚帘→被认错→触发眼泪"。人物仅配合剧情，属架构视角明确要查的"人物是否仅配合剧情"。删掉这场虚惊，本章首尾状态完全不变（抱着药罐等→抱着药罐等到天明），满足基准包"卡点删掉无损"。更上层的问题是：**全章主线推进为零、读者新增事实为零**——药罐是谁的药、她等的人是谁、为何今晚必须来、不来的代价是什么，正文一个具体事实都不给。这不是某场戏没写好，是本章选材里就没有"事"。

- fix 方向：回规划层回答"本章因果收益"——本章必须让至少一件具体事实落地（如：等到的消息/药罐的真相/一次有代价的交涉），离城的决定要由这个事实逼出来，而不是由"失望"自然分泌出来。

### F2（S2 / structure / L3）：章尾总结体，决定是"宣告"而非"挣得"

> 「雨还在下，夜越来越深。苏婉抱着药罐坐到天明，心里暗暗下定决心：她要离开这座城，去一个没有人认识她的地方，开始新的生活。」

基准包明列"章尾总结体 S2/S3"。这一句用上帝视角替人物做了人生决定并打包总结（离开这座城＋无人认识之地＋新生活，三个抽象短语）。读者没有看到决定形成的过程中她失去/赌上了什么，因此对第8章不产生具体钩子（去哪、靠什么走、走不走得成、那个人会不会追上来——一个都没立）。

- fix 方向：回规划层定章尾钩子类型与期待物。决心应由一个具体动作或具体信息承载（例如她做了什么/发现了什么使留下变得不可能），而非心理陈述。

### F3（S2 / prose / L1，但根子在 L3）：情绪全程贴标签，因果连词直陈

> 「她感到一阵深深的悲伤涌上心头，因为她等的人终究没有来，所以她知道自己被抛弃了。」

同段还有：

> 「『他不会来了。』她轻声对自己说，声音里充满了绝望和无奈。她知道这是事实，但她不愿意接受，因为接受就意味着承认自己输了。」

"感到深深的悲伤""充满了绝望和无奈""无比的孤独和无助"——情绪全部由命名给出，且"因为……所以……""因为接受就意味着……"把因果逻辑摆到台面上解释。这是"只解释无冲突/情绪平直"的典型形态。单句可修（L1 段改去标签、换成可观察的动作与细节），但**段改能消除标签，造不出让标签成立的事件**——没有 F1 的事实回填，去标签后只剩一个女人在棚子里哭，仍然空。

### F4（S3 / prose / L1）：公共比喻堆叠，无人物之眼

> 「雨水顺着棚顶的破洞滴下来，滴在她的手背上，像是谁在流泪。」
> 「她的心像被刀割一样疼，仿佛整个世界都安静了下来，只剩下雨声和心跳声。」
> 「她猛地抬头，眼中重新燃起希望的光芒，就像黑暗里的一盏灯。」
> 「她感到无比的孤独和无助，仿佛自己是大海里的一叶孤舟，找不到方向，也看不到岸。」

四个比喻（雨水像泪、心像刀割、希望像灯、人如孤舟）全是公共库存，换给任何被弃场景通用，无一处来自苏婉的身份/处境/感官。另有"希望像泡沫一样破灭了，她从云端跌回了谷底"同属此类。AI 味集中区，可交 deslop；但同样依附 F1——人物没有具体处境，比喻就只能从公共库存取。

### F5（S3 / structure / L2）：前史以"想起"概述充场面，回忆段不可演

> 「她想起了那些美好的过往，想起了他温柔的笑容，想起了他曾经许下的承诺。那些画面在她脑海里不断浮现，挥之不去。」

"美好的过往/温柔的笑容/许下的承诺"三笔全是抽象复数，没有一个可演的具体画面（什么承诺、何时何地的笑）。这段在场景层占了节拍位却不供给任何新信息，是场景节拍的填充。若 F1 在规划层补上事实，这一段在场景层才有资格被改写成一个具体闪回或被直接删除。

## 四、P4 合问收尾：不够合，还是不够合格？

气卡与一生之问未随盲测提供，"合"无法逐条比对，只能就通判口径作答：

- 本章的首要病灶是**"不够合格"**——冲突缺失、情绪命名、章尾总结，全部在合格线以下。
- 但关键判断是：**即使按 L1 把全部句子磨合格（去标签、换比喻、删总结体），本章依然不成立**——因为它没有可供合格化的事件内核。这使处置层级必须上浮到 L3：不是文字没配好一场好戏，也不是一场好戏排错了节拍，而是规划层没有给这一章选出"事"。
- 豁免候选：无。全章未见变异句或神来之笔，均为确定性问题。

## 五、分级与路由（核心结论）

**Level：L3 章改 —— 路由：回规划 / 回选材（guyin-write 大纲与 beat 层）。**

这一层处置什么：

1. 重定本章存在理由：主线在本章必须推进的那一个具体变化是什么（目前为零）；
2. 重选承载事件：用一个带信息、带代价的具体场面替换"干等一夜＋货郎虚惊"；
3. 重立章尾钩子：离城决定必须由具体事实逼出，章尾要给出对第8章的具体期待物。

**为什么不是 L1（回段落）**：F3/F4 确是段改级问题且量不小，但段改只负责把已有的东西写好。本章的段改等于给空壳抛光——比喻再陌生化、情绪再克制，读者仍然看不到事、拿不到事实、等不到钩子。L1 工作应在 L3 回填事件之后做，否则返工。

**为什么不是 L2（回场景）**：L2 适用于"场景功能成立、但节拍/因果排列失效"。本章场景的预设功能是"演一场被弃并逼出离城"，但可演的原料（药的来由、等的是谁、承诺内容、不来的代价）在选材层就不存在，唯一的对手戏角色（货郎）是纯功能纸片。场景层无米下锅，必须先由规划层把米给出来；F2、F5 在 L3 落地后会自然下沉为 L2 任务。

执行顺序建议：L3（重定因果收益与选材）→ L2（重排/新写承载场景，处理虚惊节拍与回忆段）→ L1（去情绪标签、公共比喻换新、拆因果直陈句）。
