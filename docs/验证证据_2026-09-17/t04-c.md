# 第7章 雨棚

雨又下起来了。苏婉缩在棚子最里面，抱着那只冷掉的药罐。她感到一阵深深的悲伤涌上心头，因为她等的人终究没有来，所以她知道自己被抛弃了。

雨水顺着棚顶的破洞滴下来，滴在她的手背上，像是谁在流泪。她的心像被刀割一样疼，仿佛整个世界都安静了下来，只剩下雨声和心跳声。她想起了那些美好的过往，想起了他温柔的笑容，想起了他曾经许下的承诺。那些画面在她脑海里不断浮现，挥之不去。

「他不会来了。」她轻声对自己说，声音里充满了绝望和无奈。她知道这是事实，但她不愿意接受，因为接受就意味着承认自己输了。

棚外忽然传来脚步声。她猛地抬头，眼中重新燃起希望的光芒，就像黑暗里的一盏灯。来人越来越近，她的心跳越来越快，几乎要从嗓子眼里跳出来。她告诉自己，一定是他，一定是他回心转意了。

来人掀开棚帘，是个陌生的货郎。希望像泡沫一样破灭了，她从云端跌回了谷底。货郎问她要不要买针线，她摇了摇头，眼泪终于忍不住夺眶而出。她感到无比的孤独和无助，仿佛自己是大海里的一叶孤舟，找不到方向，也看不到岸。

雨还在下，夜越来越深。苏婉抱着药罐坐到天明，心里暗暗下定决心：她要离开这座城，去一个没有人认识她的地方，开始新的生活。
