# 第21章 祠堂

祠堂的门一早就开了。林氏跪在蒲团上，把那本账册从包袱里取出来，用油纸又裹了一层。今天是冬至，族里各房的长辈都要到祠堂行礼，丈夫的死，她要在今天当着全族问个明白。

昨夜她没合眼。账册上的数目她对了三遍：修河的赈银经了公中的手，入帐三百四十两，发到河工手里的只有九十两。丈夫是那年腊月死在堤上的——尸身送回来时，手里还攥着半张领银的条子。她把条子缝在账册封皮里，缝到天亮。

午时前，族老们陆续到了。三老爷走在最前，目光从她跪着的身上扫过去，像扫过一张多余的椅子。她听见自己心跳得很重，手心全是汗，账册的边角被捏出了深色的印子。

礼行到一半，三老爷忽然咳了一声，管祠的钱二叔便走过来，低声说三爷请她到西厢房说话，「族里长辈都在，家里的事，不必惊动列祖列宗」。她跪着没动。钱二叔又说了一遍，声音更低：「你公公的身子，也经不住当众闹。」

后来的事是秋菊讲给她听的。她到底还是去了西厢。三老爷当着几位长辈的面查了账，说赈银的事是河工房的旧吏做的手脚，人已经拿问，追不回的银子由公中补到河工名册上去；她丈夫那条子上的数目，也算在补款里。族里念她年轻守节，拨二十两银子给她立节孝的牌坊。

秋菊说这些的时候，天已经黑透了。林氏坐在灯下，把账册重新摊开，那半张条子还在封皮里，纸边磨得起了毛。她想，原来她在蒲团上跪了一上午，那句话到底没有当着祖宗的面问出口。灯花爆了一下，她伸手去挑，挑了很久。
