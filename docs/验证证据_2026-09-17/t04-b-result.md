## 一、真实阅读反应（两段式·第一段：只读正文，不核对）

读着胸口发闷：一个寡妇抱着账册在祠堂跪了一上午，要当着全族问丈夫的死，结果被几句话请进厢房，出来时案子已结、人已被二十两银子和一座节孝牌坊买下。结尾灯花一爆、她挑了很久，很有力，余味是凉的。但闷里隔了一层——全章最该看到的那场戏（她怎么被请进去、怎么被当场定案），是天黑后由丫鬟秋菊转述给她的，我没有亲眼看见她失守的那一刻。

## 二、Findings（每条先引原文，再判断）

### F1 — S2 / structure / L2（核心场景转述化，决定性转折落在场外）

> 「后来的事是秋菊讲给她听的。她到底还是去了西厢。三老爷当着几位长辈的面查了账，说赈银的事是河工房的旧吏做的手脚，人已经拿问，追不回的银子由公中补到河工名册上去；她丈夫那条子上的数目，也算在补款里。族里念她年轻守节，拨二十两银子给她立节孝的牌坊。」

全章的戏剧核心是「她要当众问 → 她没能问出口」。开篇明确立约：

> 「丈夫的死，她要在今天当着全族问个明白。」

但这个约定的兑付方式是：冲突被钱二叔两次低语移出场域后，西厢里的交锋——查账、定调（旧吏顶罪）、补偿封口（二十两节孝牌坊）——整段以秋菊事后转述、一句到底的概述完成。读者在场的只有跪蒲团和事后独坐灯下，唯独不在「她被瓦解」的现场。权力碾压发生在幕后，压迫感被叙述距离稀释：三老爷由此至终只有一声咳嗽和一个扫过的眼神，他真正出手的段落里没有身体、没有语气、没有当面的她。

- fix 方向（L2 场景改，不涉及重选事件）：把西厢这一 beat 拉回林氏视角实写——哪怕仍维持「不公然掀桌」的结局，也要让读者亲历她进门、被让座、账册被翻开、罪名被一句话派给死人/旧吏、牌坊二十两被推到面前的全过程；或者反向处理：若坚持省略西厢（见豁免候选），则必须把「她跨出祠堂那道门」的瞬间做实，用她自己身体里的感受替代信息转述。

### F2 — S2 / character / L2（关键决定无动机过程：从不动到去西厢，中间是空的）

> 「她跪着没动。钱二叔又说了一遍，声音更低：『你公公的身子，也经不住当众闹。』」
> 「后来的事是秋菊讲给她听的。她到底还是去了西厢。」

第一次请，她「跪着没动」；第二次请，杠杆只有一句「公公的身子经不住」——然后直接是「到底还是去了」。她为什么起身？是被公公的病拿住、被长辈在场的阵势压住、跪到力竭，还是自己心里那口气先泄了？这个决定是本章人物弧线的转轴（从问案者变成被安排者），却发生在两段之间的空白里。读者无法判断她是被胁迫、被孝道绑架还是主动软化，结尾「那句话到底没有当着祖宗的面问出口」的自责分量因此失去着力点——不知道她在哪一步松手，就无法替她疼。

- fix 方向：随 F1 同一场景处置，补出她起身前的内在一瞬（哪怕只是一个动作：看了一眼公公的位置、膝盖离开蒲团时的感觉）。L2 而非 L1：补的不是句子，是一个节拍的心理动作。

### F3 — S3 / consistency / L1（条子从未出示，三老爷却核对了「条子上的数目」）

> 「她把条子缝在账册封皮里，缝到天亮。」
> 「她丈夫那条子上的数目，也算在补款里。」
> 「那半张条子还在封皮里，纸边磨得起了毛。」

条子是她手里的硬证（丈夫尸身手里攥着的半张领银条），她连夜缝进封皮，章末仍在封皮里——意味着她从未把条子出示给三老爷。那么西厢查账时，三老爷据何说出「她丈夫那条子上的数目」并将其计入补款？若他只查了账册（入账三百四十两、实发九十两），他知道的应是账册数字，无从核验一张他没见过的条子的数目。除非她口头报过数目——但正文无此一笔。证据链在此处悬空，属于可被读者抓住的叙事资产前后口径问题。

- fix 方向（L1 段改，半句可修）：要么在西厢段补半句「她报了条子上的数目」之类交代；要么把三老爷的口径改为只对账册、不碰条子（后者更冷，也更合他糊弄了事的做派）；并复核章末条子仍在封皮里这一资产状态与后续追踪是否一致。

### F4 — S4 / prose / L1（心跳手心为熟套，属打磨项）

> 「她听见自己心跳得很重，手心全是汗，账册的边角被捏出了深色的印子。」

后半句（账册边角捏出深色印子）具体、好；前半句「心跳得很重，手心全是汗」是紧张反应的公共写法，与本章其他句子（「像扫过一张多余的椅子」「灯花爆了一下，她伸手去挑，挑了很久」）的陌生化质地不在一个水准上。不影响效果，记录备查。

### F5 — S4 / structure（章尾为情绪余韵型，无外部前拉力）

> 「灯花爆了一下，她伸手去挑，挑了很久。」

结尾作为情绪意象成立，且账册、条子两件证物仍在林氏手中，构成潜伏笔；但章面没有任何指向下一章的外部张力（补款是否真到河工名册？牌坊接不接？三老爷知不知道条子的存在？）。短章可接受，仅记录：若平台节奏要求章尾钩，此章偏弱。

## 三、豁免候选（存疑不报死，交五测试）

- **F1 的「西厢整体省略」可能是有意手法而非失手**：让最关键的处置发生在场外、由丫鬟转述，恰是林氏被彻底排除在自己案件之外的形式对应——她连亲历对质的资格都没有，只能听别人讲自己的事如何被了结；且结尾「那句话到底没有当着祖宗的面问出口」直接把「缺席」点成了主题。若五测试认定该省略稳定服务于「人被礼数吃掉」的表达，F1 可降级或豁免；但 F2（她起身那一步的内在空白）即使保留省略也仍需补，豁免不覆盖它。

## 四、AI 味集中区

无集中区。全章语言干净、时代质感统一，无说明书式对话、无章尾总结体、无碎句电报体；唯一熟套见 F4，单句级，不必整篇 deslop。

## 五、Level 分级与路由

**主路由：L2——回场景层（beat 改）。**

- 这一层处置什么：西厢这一个 beat 的呈现方式——把「被秋菊转述的概述」改为「林氏在场的场景」（或保留省略但补实她跨出门槛、被定案时的亲身体验），同时在此场景内补出她从「跪着没动」到起身的动机一瞬（F1+F2 合并处置）。
- 为什么不是 L3（回规划/选材层）：本章选材与因果链成立——祠堂当众立约、权势以「公公身体+长辈在场」把冲突移出公共场域、旧吏顶罪、公款补名册、二十两牌坊封口，起承转合闭环，开篇「要问个明白」与结尾「到底没有问出口」构成完整反讽，证物（账册+条子）留存可供后续。没有需要回炉重选事件、重排因果的规划级缺陷。
- 为什么不是 L1（回段落层）：本章段落文字本身质量在线，比喻与结尾均有水准；核心缺陷是**一场该有的戏整体缺席**，字句打磨补不回读者对「失守瞬间」的体验。L1 仅用于捎带修复 F3（条子数目口径，半句可修）与 F4（熟套句，可改可不改）。

处置顺序建议：先做 L2 场景重写（F1/F2），再在改后场景里就地消掉 F3 的口径矛盾；F4/F5 不阻塞。
