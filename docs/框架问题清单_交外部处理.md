# 追影 · 框架问题清单（交外部模型处理）

> **文档性质**：**框架改动工单**，不是文本润色建议。
> **前提**：前一阶段结论已确认——前三章失吸引力，**主因在框架的设计选择**，不在执行模型的水平。
> （证据另见 `诊断_前三章失吸引力归因.md`；本文不重复论证，只列问题与改动。）
>
> **给处理者的读法**：
> 1. 每个问题都带**框架原文出处**（文件:行/字段），改动前先核对原文，不要凭本文转述动手；
> 2. 分四部分：**F＝框架作出的选择**、**S＝框架自身机制缺陷**、**C＝纪律冲突**、**H＝历史遗留**；
> 3. 第五部分是**已排好的工单**，可直接按批次派发；第四部分（C）里的冲突**必须先解**，否则任何改动都会撞上另一条纪律；
> 4. **本文只动框架文件，不许动 `正文/`**。正文要动，走另一条流程（先拷 `正文/_archive/`）。

# 第一部分 · 框架"决定"的问题（P0 · 症状的直接来源）

> 这一部分的问题性质相同：**框架主动做出了某个设计选择，该选择在开篇场景下必然产出坏结果。**
> 它们不是"没做好"，是"做对了但方向错"。**改这一部分＝改设计决策，需要作者拍板。**

## F-01 「三不写 + 贴身不进入」必然产出失语主角

| 项 | 内容 |
|---|---|
| **现象** | 主角全章只有"嗯／哦／没答／他没说话"，读者读成"木" |
| **框架原文** | `大纲/执行层一页纸.md` 七条硬禁令 #2：「**不许写心理活动。**写动作、写物、写他说了什么。**不写他在想什么**」<br>`作者性/语言纪律.md` §0：「叙述距离：**贴身但不进入**——可写他的感官、动作、走神；**不可写他的判断与命名**」<br>`作者性/语体样张.md`：「他不知道怎么应对大人的热情——**不写他尴尬**」（被列为正面技法） |
| **为什么是必然** | 主角的设定是 **9 岁身体 + 三世记忆**。本书最大的戏剧张力**全部在内心**：他知道所有人的结局、他要在小孩的身份里演戏、他与周围每一个人之间都存在巨大信息差。<br>框架把"内心"整块禁掉，只留动作和台词；而台词又被 F-02 压到 4 个字的均值——**主角只剩"不回应"这一个表达手段**。 |
| **文本实测** | ch001 沉默类叙述 10 处／2910 中文字。全三章"他没答／他没说话／他没接／他什么都没说／没人接"共约 20 处 |
| **改动建议** | **开"前三章豁免区"**：前三章允许写"他知道"级的半句判断（限知视角本就承认「**他不知道**」是最值钱句式，把它的反面放出来）。<br>推荐表述：允许 `他知道……` / `他知道自己答不了` / `他知道这件事在几年后会……`，**禁止情绪词与成语**。<br>落点：`语言纪律.md` §0 增例外条；`执行层一页纸.md` 禁令 #2 加"前三章除外"；`语体样张.md` §三 反例 1 重写 |

## F-02 对话被三条纪律同时压死，必然"没有新意"

| 项 | 内容 |
|---|---|
| **现象** | 60-116 条对话，中位 4 字，读者"一句都没记住" |
| **框架原文** | ① `语言纪律.md` §4 对话签名：**主角 ≤15 字**、小满 ≤10 字、老爸 ≤8 字；「**几乎不问问题**」<br>② `语言纪律.md` §4.5：「对话**允许、鼓励俗套**……甚至要**故意用最没信息量的话**」<br>③ `语言纪律.md` §6：「**问号只出现在"会问的人"嘴里**」；`指纹.md` 同步登记<br>④ `执行层一页纸.md` 场景速查·对话：「**俗。短。他几乎不问问题**」 |
| **为什么是必然** | 三条纪律**指向同一个方向**：删除对话的信息量。<br>无问句 = 无追问—抵抗—翻盘的动力；无信息量 = 对话不承担性格或冲突；字数上限 = 无长句可承载机锋。<br>**结果：对话只剩"氛围音"功能**，而开篇的对话必须承担"交代人物"的功能。 |
| **文本实测** | ch001 60 条／ch002 58 条／ch003 116 条；中位 4 字；平均 5-6 字；最长 18-40 字；问号 13/14/19 个（其中主角发出的极少） |
| **改动建议** | 分离**两个场景**的对话规则：<br>· **信息场（前三章、打脸场、对手场）**：解禁"质问—抵抗—翻盘"对话结构，允许主角问句；上限提到 ≤30 字；<br>· **日常场**：保留现有的"俗、短、不解释"。<br>落点：`语言纪律.md` §4 拆为"日常对话签名"与"信息场对话签名"两栏 |

## F-03 「密/疏」用字数定义节奏 → 必然被实现为换行频率

| 项 | 内容 |
|---|---|
| **现象** | 均段 21 字、≤12 字段占 46-53%、一章 135-188 段。读者觉得"干"、"像在念提纲" |
| **框架原文** | `大纲/细纲分级与模板.md` §二 硬约束 3：「情节点必须标疏/密——**密＝慢写分镜（≥200 字），疏＝快推（≤150 字）**」<br>`细纲_第001章.md`：每个情节点后跟【密 200】【疏 80】等标记 |
| **为什么是框架问题** | 「密/疏」本来是**节奏概念**（信息密度／镜头速度／情绪强度），但框架给它的**唯一操作定义是"字数"**。<br>字数配额**不约束"这段怎么写"**，只约束"这段写多长"。执行层要满足"≥200 字"，最容易的实现就是把内容摊成更多短行；要满足"≤150 字"，就是砍句子。<br>**框架用错误的量纲定义了节奏。** |
| **旁证** | `待审台账` 已抓到 `overcompressed-prose-tic：叙述段 62%≤15 字`，但处置为**豁免**，理由"饭桌对峙章短镜头为**有意节奏，与前两章一致**"——**发现了，判成了风格** |
| **改动建议** | 给「密/疏」补**三级操作定义**（不给字数）：<br>· **密**＝一个动作拆成 4-6 个感官层次（视线→重心→呼吸→接触→结果→声音后到），段内**必须有一个 ≥40 字的连续段**；<br>· **中**＝正常叙述；<br>· **疏**＝一句一事，**但仍须成段（≥25 字）**，不许拆成单句行。<br>另加硬约束：**单章 ≤15 字段落不得超过 25%**（现为 46-63%）。<br>落点：`细纲分级与模板.md` §二 约束 3 重写；全部 A/B 级细纲的字数标记替换为层级标记 |

## F-04 黄金三章「零解密 + 不给大爽」→ 必然"主角出场啥都没交代"

| 项 | 内容 |
|---|---|
| **现象** | 读者读完三章不知道：他是谁、为什么这样、他要干什么、谁挡着他 |
| **框架原文** | `细纲_第001章.md`：「**本章唯一解密位：无**」<br>`细纲_第001章.md`：「本章禁止提前释放：**回穿机制／三世死因／小满身份／锚点规则／主角身手来源／那句没听完的话**」<br>`细纲_第001章.md`：「节奏标记：蓄力——**本章不给大爽，只给一次微打脸 + 一次医生的外部认证**」<br>`卷纲_第1卷.md` §禁止提前释放（本卷）：三世死亡原因／记忆觉醒与回穿机制／陈小满真实身份／锚点规则／主角身手的来源 |
| **为什么是必然** | 网文开篇的硬需求是**四件事**：身份（我是谁）／能力来源（我凭什么）／当下目标（我要干什么）／威胁（谁挡着）。<br>框架把前两件列进"禁止释放"，第三件从未定义，第四件（舅舅）在 ch001 只出现了一次隔门的声音。<br>→ **四件全空。** 读者拿到的只有一个谜题。 |
| **关键判断** | 这是**有意选择**，不是疏忽。但"不解释设定"与"不交代人物"是两件事：<br>**可以不解释"为什么回穿"，但必须交代"他要做什么"。** 现在两者一起被禁了。 |
| **改动建议** | 拆开"设定保密"与"人物交代"：<br>· **保留保密**：回穿机制／三世死因／小满身份／锚点规则／身手来源 —— 一律不解释；<br>· **解禁交代**：给主角一个**当下目标**（不需要理由）。建议 ch001 明写"他这一世要把老爸的病改过来"，或"他要找到东郊那家厂子的人"。<br>· 给能力一个**可指认但不解释**的底牌：不是"他会看病"，而是"他知道接下来会发生什么"（可只给一次实证，不给来源）。<br>落点：`细纲_第001章.md` 新增"本章必须交代的三件事"字段；`卷纲_第1卷.md` §禁止提前释放 拆为"设定保密"与"人物交代"两栏 |

| 项 | 内容 |
|---|---|
| **现象** | 每个钩子都要等很久，读者手里没有任何"马上会兑现"的东西 |
| **框架原文** | `开篇钩子设计.md`：三个答案**全书不给**；第四个（那句话）在 **ch088**；`追踪/伏笔.md`：F22 槐树 → ch107；F1 那杯水 → ch194；倒叙钩子 → ch183<br>`隐杀式爽点.md` §二：全书 7 次暴起，**第 1 次在 ch007** |

## F-06 卷纲承诺"喜剧／嬉皮笑脸"，执行层规定"主角不搞笑" → 主角无魅力场

| 项 | 内容 |
|---|---|
| **现象** | 三章读完，读者对主角的认知只有"会看手、话少、家里穷"。**没有一条是"我想跟着他"的理由** |
| **框架原文** | `卷纲_第1卷.md` §基本信息：「**调性：轻快喜剧为主，释放为底；老灵魂 + 嬉皮笑脸**」<br>`执行层一页纸.md` 禁令 #5：「**主角不搞笑。**他只是认真地说真话。**笑的是别人**」<br>`语言纪律.md` §4.5 纪律 1：同上 |
| **为什么是必然** | 这条对立是**全书唯一一处卷级调性与执行级禁令直接矛盾**。<br>执行层永远以后者为准（它在"只看这一页"里），于是"轻快喜剧"在前三章**零落地**。<br>`待审台账` 已记录：「**气句"玩世不恭中，总有那么一丝深刻"前三章未落地**」 |
| **改动建议** | **以卷纲为准**，改写执行层表述：<br>· 原来："主角不搞笑" → 改为：**"主角是全书最认真的那个人；他的好笑来自'他说的每句话都是真的，而没人信'；他不抖机灵，但允许他有一次不耐烦、一次玩世不恭的短句"**；<br>· 在前三章指定**至少一处"人格魅力场"**（建议 ch002 或 ch003）：让读者看到他"老灵魂"的那一瞬——不是笑话，是他对大人世界的**漫不经心**。<br>落点：`执行层一页纸.md` 禁令 #5；`语言纪律.md` §4.5 纪律 1；`细纲_第002/003章.md` 写作指令区 |

## F-07 「扮猪吃老虎」被用在"读者还没见过老虎"的时候

| 项 | 内容 |
|---|---|
| **现象** | 主角的克制、沉默、不解释，读者读成"迟钝"而不是"深藏" |
| **框架原文** | `隐杀式爽点.md` §三 H2 装乖：「本书主角是 9 岁的身体 + 三世记忆，**天然就是扮猪吃老虎的最佳载体——他不需要装成熟，他只需要不装**」<br>`隐杀式爽点.md` §三：全书姿态「永远是'被叫去的'」「赢了挨骂不辩解」「功劳永远推给别人」 |
| **为什么是框架问题** | 「扮猪吃老虎」的爽感**全部来自落差**。落差需要**两个端点**：读者知道他是老虎 + 看见他被当成猪。<br>本书前三章只建立了"猪"（九岁小孩），**没有建立"老虎"**（他曾经是谁、他能做什么）。→ 反差的一端是空的，**读者看到的只是一个沉默的小孩**。<br>更关键：`隐杀式爽点.md` 描述的是**已完成态的主角姿态**（威信已建立之后的从容）。**框架把这个"姿态"当成了开篇的"写法"。** |
| **改动建议** | 在 `隐杀式爽点.md` §三 加一段"**姿态的时序前提**"：<br>· 装乖／不解释／不炫技，均**只适用于读者已见过底牌的阶段**（建议自 ch007 起）；<br>· **黄金三章属于"立底牌期"**，此阶段主角必须至少有一次"泄露"——让读者看见他藏了什么（可以是不解释，但**必须让读者知道"这里有东西可藏"**）。<br>落点：`隐杀式爽点.md` §三 新增"时序前提"节；`执行层一页纸.md` 场景速查·打脸段同步 |

## F-08 全书的"减负"讨论都站在 200 章的资产负债表上，没有一次站在"刚点开第一章的读者"的位置

| 项 | 内容 |
|---|---|
| **现象** | 每一轮都在优化"全书配比"，但没有任何一份文件对"读者读完前三章应该获得什么"做过独立定义 |
| **框架证据** | `细纲_第001章.md` 的减负结论是"本章只承担两件事：**这孩子有本事**、**这家很穷且被人看不起**"——这是**全书坐标系里的两件事**，不是**读者前三千字里的两件事**。<br>`评估_第九轮.md` §六 ch001 超载的解法是从"六件事减到四件事"，标准仍是"钩子太多读者会疲"，**不是"读者需要知道什么"**。<br>`细纲分级与模板.md` 判 A 级的标准：「**这一章写砸了，全书会不会塌**」——全书的视角。 |
| **为什么是核心问题** | 这是**元问题**：框架的全部质量判断都采用"全书工程视角"，而开篇的唯一裁判是**"一个陌生人愿不愿意读下去"**。<br>两种视角的优化方向经常相反：工程视角要求"别浪费伏笔、别提前释放、保持配额"；读者视角要求"马上给我一个我在乎的人、一件我在乎的事"。 |
| **改动建议** | 新建一份 **`大纲/开篇留存标准.md`**（或并入 `开篇钩子设计.md` 独立成节），定义"前三章读者的获得清单"，建议采用：<br>① 三章内必须让读者获得：**一个可指认的能力实证 + 一个当下目标 + 一次情绪热度（热或怒或笑） + 一次"我猜对了"**；<br>② 每条都必须能**在正文里被指出来**，否则视为未达标；<br>③ 与全书配额冲突时，**前三章优先**。<br>落点：新建文件 + `执行层一页纸.md` 增"开篇三条"。 |

# 第二部分 · 框架自身的机制缺陷（P1 · 结构层）

> 这一部分不是"选择错了"，是**框架缺少某个机制**，导致问题无法被发现或无法被解决。

---

## S-01 迭代方向是"加规则"，不是"验证"：11 轮框架 + 10 轮评估，正文样本 0

| 项 | 内容 |
|---|---|
| **证据** | `评估_第二轮.md` … `评估_第十轮.md`，共十轮，全部标注"**设计层评分**"、"正文仍 0 章，一切未验证"<br>`执行层一页纸.md` §六 自述：「**忘了评分——九轮评估全是纸面分**」<br>`框架就绪度排查_v11.md`：「工程从"设计完备但不可执行"变成了"前五章可执行"」 |
| **后果** | 设计分从 4.7 一路涨到 9.6，**而正文直到第十章才写出**。所有"读者会怎样"的判断都未经样本检验。<br>**框架的迭代动力来自"发现还缺什么"，而不是"发现写出来不对"。** |
| **改动建议** | 立一条流程纪律：**此后任何一轮框架改动，必须先有一章正文样本作为依据**。<br>即：**样本 > 论证**。无样本的改动只能做"补缺"（缺资料），不能做"提分"（说更好）。 |

## S-02 没有读者回路

| 项 | 内容 |
|---|---|
