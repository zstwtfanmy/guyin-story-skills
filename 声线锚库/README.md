# 声线锚库（仓库根标准位置）

> 定位：私人临摹用的原文切片默认存放位。写前读锚（示范>规则），写后持锚自审四问。
> 本机私有资产：除本 README 外，本目录内容不入 git、不随技能包分发、不随产物传播。
> 用途边界：只迁移声音，不迁移内容——不整句搬移、不连续复用原文独特词组；学声音机制不学情绪基调。

## 目录结构

```
声线锚库/{书或文章名}/
├── 00_README.md      # 来源（合法持书文件＋sha256 前缀）、场景标签表、边界说明
└── NN_场景名.md      # 500-1000 字原文切片，首行带一行场景标签
```

技能侧引用的是锚库根，按书名路由：找 `声线锚库/{书名}/`。目录或对应书不存在时向用户索要，不空跑声线、不代找盗版源。

## 扩充协议

1. 新增一本书或一篇文章＝新建 `声线锚库/{名称}/` 子目录，格式同上；技能侧无需改动。
2. 来源必须是用户合法持有或合法取得的文本；切片 4-6 段、每段 500-1000 字，覆盖该书实际会遇到的场景类型（开场/对话/动作/氛围/峰值/闲笔），每段附一行场景标签。
3. 同书切片一次不必凑齐：首章只需 3-4 段即可起步，后续按需补。
4. 书积累出用户认可的本书章节（≥3 章）后，该书锚包降级为"声音漂移时回炉"用，日常声线以本书自己的正文为准（出帖）。
