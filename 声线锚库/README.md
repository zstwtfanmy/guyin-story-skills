# 声线锚库（仓库根标准位置）

> 定位：私人临摹用的原文切片默认存放位。写前读锚（示范>规则），写后持锚自审三问（引擎/声音/欠账）。
> 解析协议：先读本书 `设定/题材定位.md` 的 profile ID，再查本库 `REGISTRY.md` 定位锚目录 `声线锚库/{profile}/{锚书}/`；锚缺失时按 profile 文字继续，不跨 profile 借锚。
> 本机私有资产：除 README 与 REGISTRY 外，本目录内容不入 git、不随技能包分发、不随产物传播。
> 用途边界（贴近度听实际使用人的，分两档）：默认档只迁移声音不迁移内容——不整句搬移、不连续复用原文独特词组，学声音机制不学情绪基调；使用人明确要求「仿写／贴近锚书／对标某段／可以借原句」即进仿写档，句式、措辞、独特词组、桥段处理都允许仿，仿到什么程度以使用人原话为准，不以防抄为由自行往回收。

## 目录结构

```
声线锚库/
├── README.md          # 注册制规则、法律边界、出帖
├── REGISTRY.md        # profile → 锚书 → 覆盖场景/来源/状态
└── {profile}/
    └── {锚书}/
        ├── 00_README.md   # 来源（合法持书文件＋sha256 前缀）、场景标签表、边界说明
        └── NN_场景名.md   # 500-1000 字原文切片，首行带一行场景标签
```

技能侧引用的是锚库根，经 REGISTRY 按本书 profile 解析；目录或对应锚不存在时向用户索要，不空跑声线、不代找盗版源。

## 扩充协议（注册制）

1. 新增锚书＝REGISTRY 对应 profile 行填锚书/场景/来源 sha 前缀、状态改「就位」，同时新建 `声线锚库/{profile}/{锚书}/` 子目录，格式同上；技能侧无需改动。
2. 注册键是 profile 不是题材标签：锚只服务同一读者回报结构的书；新 profile 无锚时状态标「待建」，不借其他 profile 的锚。
3. 来源必须是用户合法持有或合法取得的文本；切片 4-6 段、每段 500-1000 字，覆盖该书实际会遇到的场景类型（开场/对话/动作/氛围/峰值/闲笔），每段附一行场景标签。
4. 同书切片一次不必凑齐：首章只需 3-4 段即可起步，后续按需补。
5. 书积累出用户认可的本书章节（≥3 章）后，该书锚包降级为"声音漂移时回炉"用，日常声线以本书自己的正文为准（出帖）。
